# GitBook setup / GitBook 接入

- [English setup and maintenance guide](en/GITBOOK_SETUP.md)
- [中文接入与维护说明](zh/GITBOOK_SETUP.md)

The root configuration presents both editions in one GitBook space. For native language variants, connect zh/ and en/ to separate spaces and configure them as variants of one site. GitHub Pages is the currently configured publishing route; its deployment does not connect a GitBook account.

根配置在一个 GitBook 空间中展示双语目录。使用原生语言变体时，分别将 zh/ 与 en/ 连接到两个空间并加入同一站点。当前已配置的发布方式为 GitHub Pages，Pages 部署不会自动绑定 GitBook 账号。
