# Shared component registry / 共享组件登记

- [English component index](../en/architecture/README.md)
- [中文组件索引](../zh/architecture/README.md)

The JSON registries in this directory are shared by both editions. Component IDs retain the same meaning in either language; translated descriptions do not create additional components.

本目录的 JSON 登记由两种语言共用；组件 ID 含义不随语言变化，翻译描述不增加组件数量。
