## 1. 结论：扩展成模型家族，共享机制与接口，按任务决定共享权重 <a href="#section-001" id="section-001"></a>

SGD-Net 已有 SSM、图传播、动态树、误差反馈与结构投影；07、08 号文档也已经提出 SGD-Fold、SGD-Design、SGD-Science-Core、SGD-Scientist。当前最缺的是领域状态定义、可训练目标、可信数据、约束适用条件和独立验证。增加名称不能补足这些缺口。

建议沿用 **SGD-Science-Core** 作为共用机制库，保留 **SGD-Net-TC** 为物理交互研究分支，增加分子、细胞、材料、神经时序的领域配置。共享首先发生在数据协议、时间更新、图操作、误差记录与预算调度；权重共享必须由迁移实验决定。现阶段不建议从零训练覆盖全部领域的统一大模型。

世界模型在这里指条件状态演化预测器。物理 AI 在其外增加估计、规划、控制与执行；AI 制药是从候选到功能验证的多阶段研发流程；AI 生物涉及不同尺度的系统与干预；材料研究还包含周期结构、工艺和表征。它们的问题范围不同，不能由同一个视频预测目标覆盖。

## 2. 必需的十项扩展 <a href="#section-002" id="section-002"></a>

| 编号 | 扩展 | 需要增加的模型能力或接口 | 第一项验收 |
|---|---|---|---|
| E01 | 有类型的科学状态 | 实体、物理量、单位、坐标系、样本/本体、测量时间、条件与来源；分开实体图、假设图和执行图 | 单位/身份错配可检出，缺失输入不被解释成零 |
| E02 | 多模态观测模型 | 图像、序列、谱图、组学、触觉等专用编码器与掩码；按实体绑定 | 缺模态与跨批次测试，单模态强基线对照 |
| E03 | 概率状态与多时间尺度 | 条件转移、观测似然、异步更新、切换/连续动力学、多步滚动 | 预测分布校准与长时漂移；不能仅报单步 MSE |
| E04 | 领域物理/生物结构 | 等变性、周期边界、能量/力、反应计量、耗散或事件约束，按领域选择 | 数值一致性和独立参考计算，而非只看训练约束损失 |
| E05 | 多尺度状态迁移 | 原子—残基、网格层级、细胞—组织等映射及读出一致性 | 细化后物理量误差与成本曲线；不要求所有尺度可逆 |
| E06 | 干预与域迁移 | 干预类型、对象、暴露时间、环境、物种/细胞/本体条件；显式缺失和混杂假设 | 真正留出干预/域；预测关联与因果效应分开评估 |
| E07 | 条件生成与逆向设计 | 目标属性、可行域、候选多样性、成本与多目标排序 | 独立验证器和前瞻性候选评估，检查代理模型被利用 |
| E08 | 多保真误差与预算 | 区分计算不足、观测不足、模型偏差、随机噪声；选择细化、补观测或调用工具 | 同等总成本下优于固定预算/随机/规则策略 |
| E09 | 实验记忆与证据闭环 | 原始数据引用、版本、批次、阴性结果、重复、盲测、设备反馈 | 全流程可回放，实验质量相当时比较效率 |
| E10 | 领域适配及交付 | 分域训练头/适配器、校准集、数据许可证、模型卡、冻结测试与部署轨迹 | 多种子结果、域外退化曲线、资源测量和可复现实验 |

E01—E03、E08—E10 是共用基础；E04—E07 的数学形式与数据随领域变化。不是所有应用都需要全部模块：小样本实验排序可先用高斯过程和规则系统，不必部署整套神经架构。

### 2.1 统一状态接口不等于统一物理语义 <a href="#section-003" id="section-003"></a>

建议将一次观测记为

$$
o_k=(\mathrm{entity},\mathrm{modality},t_k,y_k,\mathrm{unit},\mathrm{mask},\mathrm{domain},\mathrm{source}).
$$

领域上下文包含本体参数或样本条件；控制量记为 $$u$$，环境量记为 $$c$$。基础预测接口为

$$
p_{\theta,d}(x_{t+\Delta},o_{t+\Delta}\mid o_{\leq t},u_{t:t+\Delta},c,d),
$$

其中 $$d$$ 是领域配置，$$x$$ 是任务所需状态，不必是完全可观测真值。该式是建模目标，不表示使用条件数据就识别了干预效应。模型需要通过训练学习参数，也需要与观测噪声模型配套。

生物样本的测量时间、生成模型的去噪步、数值求解器迭代和实验批次顺序必须分开。横截面单细胞数据即使有伪时间，也不能直接充当同一细胞真实纵向轨迹；序列位置同样不是物理时间。

### 2.2 对旧设计需要校准的五处关键表述 <a href="#section-004" id="section-004"></a>

1. SSM 的状态变化量只能是启发式信号；应使用可观测创新、参考解差异或经过验证的误差估计，不能把未知未来真值放进在线残差。
2. 去噪过程是生成算法的计算路径，不天然是分子动力学；对其施加耗散约束不自动赋予真实动力学语义。
3. 谱半径、状态范数和 Lyapunov 候选函数需要适用条件；它们不能单独保证跨任务物理正确、在线学习不遗忘或科学结论成立。
4. 投影和局部再生成会改变样本分布，可能破坏全局结构；必须检验全局一致性与分布偏差，不能只报告局部 clash 减少。
5. 科学假设的证据状态与设备动作的允许执行状态分开。运行时批准一次动作不等于验证了药效或机制；真实实验不能通过数据库回滚撤销。

## 3. 世界模型与物理 AI：在 TC 上补概率动力学与求解器协同 <a href="#section-005" id="section-005"></a>

SGD-Net-TC 已提出三图、接触预测、记忆迁移和本体条件动作。进一步扩展需要：从单点预测变为可校准的未来分布；对遮挡和未观测状态维护不确定性；处理多步误差、接触切换和外部扰动；把可计算的物理部分交给适当求解器，将神经模块用于未知项或修正项。

建议首先区分两条模型路径：操作任务采用短时接触/状态模型与局部控制；连续场任务采用网格/粒子或神经算子及边界条件。NeuralGCM 已展示动力学核心与学习模块结合的先例，说明混合路线值得对照，但其气候领域结果不支持直接外推到机器人。[^S01]

训练需同时检查一步、开环多步和闭环表现。教师强制下的低误差可能掩盖滚动失效；规划器可能主动找到模型漏洞。用独立环境评价候选，并记录模型拒绝、回退和任务失败。控制时限内应预留观测对齐、检查、提交和失效处置预算。

对于已知保守力部分，可以定义标量势能 $$E_\theta$$，从 $$F=-\nabla_x E_\theta$$ 得力；摩擦、驱动、热浴与碰撞等另建项。不能把全部真实系统强行设为能量恒定，也不能以位置误差小代替接触力正确。

首个任务建议继续使用 TC 的跨手型短时操作。连续介质、长时开放世界和通用语义规划应作为单独任务增补，不纳入第一版通过条件。

## 4. AI 制药：从结构增强扩展到候选—功能—实验链 <a href="#section-006" id="section-006"></a>

近期定位宜为已有模型的增强器与候选评估器。AlphaFold 3 面向生物分子相互作用结构预测；Boltz-2 官方工件包含结构与亲和力相关能力。它们适合作为接入源与基线，而非由 SGD-Net 从零重建全部表征。[^S02][^S03]

| 子任务 | 必须新增 | 可训练输出与验证 |
|---|---|---|
| 分子与复合物表征 | 原子/残基类型、键级、立体化学、质子化/电荷、构象和环境条件 | 几何、界面与构象质量；蛋白家族/序列相似性和配体骨架隔离 |
| 动态与相互作用 | 构象集合、能量/力或物理工具接口、多保真误差 | 与独立结构/模拟/实验对照；采样步不等于物理时间 |
| 候选排序 | 按任务定义亲和力、选择性、功能、开发性等不同预测头 | 分终点训练和校准；不将结构置信度当药效标签 |
| 逆向设计 | 受约束候选生成、多目标优化、候选多样性 | 检查新颖性、域外偏差与独立实验表现 |
| 实验更新 | assay、实验体系、批次、定量单位、阴性结果与检测限 | 留出批次/时间和前瞻性验证；单独处理删失测量 |

小分子亲和力模型不能未经验证就作为抗体功能评价器。结合、受体激活、细胞表型、体内暴露和疾病获益是不同终点，所需数据也不同。药代、毒性和免疫相关性质应以专用模型或实验接口补齐，不能靠扩大同一评分头覆盖。

第一版建议选择“固定任务域的结构/功能候选排序与不确定性评估”，确认是否比成熟模型加简单重排序有收益。加入全部 ADMET、全新蛋白生成与全流程临床外推会使验证失焦。

## 5. AI 生物：从图关联扩展到条件扰动与群体分布 <a href="#section-007" id="section-007"></a>

推荐设立独立的细胞/组织配置：输入细胞类型、基因型、实验条件、组学计数、空间邻域与形态，输出条件下的表型或表达分布。依据测量过程选择计数、连续或事件似然；不默认所有数据高斯，也不默认每个零值都是缺失。

scGPT 已研究单细胞多组学表征及扰动预测。另有独立基准指出，在所评估的基因扰动任务中，复杂方法并未超过简单线性基线。因此 SGD-Net 的图和记忆必须证明增益，不能以参数规模或可视化聚类代替证据。[^S04][^S05]

需特别增加：

- **条件干预表示**：区分对象、类型、时间、环境及测量终点；未知干预不是已知干预随机分帧。
- **批次与生物信号分解**：供体、批次、平台与处理条件分别建模；去批次过程不能同时去掉真实处理效应。
- **群体分布预测**：单细胞常为破坏性测量，应预测匹配条件下群体分布，而非臆造同一细胞的配对未来。
- **多尺度映射**：细胞到组织只保存任务所需统计量与条件；跨物种对应关系是待检验映射，不是同名基因直接等价。
- **因果证据接口**：观测关联、机制先验、干预结果及冲突分别保存；反事实推断须声明识别假设。

评价应留出供体、批次、干预及组合，报告相对于对照的变化、差异表达与功能终点。整体表达相关性可能主要反映共有背景，不能单独证明干预预测能力。完整“虚拟细胞”属于远期目标；近期只承诺限定体系中的扰动预测实验。

## 6. AI 材料：周期几何、能量力、工艺与多保真验证 <a href="#section-008" id="section-008"></a>

材料配置需要将晶格矩阵、分数坐标、元素占位、周期映像、缺陷及温压条件加入状态。相邻边必须携带周期平移；位置、晶胞变化与应变的关系要明确。分子几何模块不能只换数据文件就用于周期晶体。

MatterGen 提供条件材料生成的直接基线；UMA 提供原子体系预测的模型家族与工件。二者代表生成和原子性质计算两个环节，不能将任一环节的成功当作完成材料发现。[^S06][^S07]

建议形成“候选生成器→SGD 状态/图增强→廉价势函数→选定高保真计算→表征/实验”的分级路径。具体扩展包括能量、力、应力的一致性目标；晶体对称与周期约束；组成/结构域外检测；跨保真偏差模型；结构—工艺—性能条件关系。

零温结构能量低不等于指定条件下热力学稳定，更不等于可合成或目标功能达标。相稳定性需对照一致的参考相集合；动力学、缺陷、有限温度和工艺可能改变结果。带隙、离子传输、催化活性等终点要单独定义。

第一版选择一个组成家族及一种明确属性，比较现成势模型/生成器加主动筛选与 SGD 增强版。数据按组成家族、原型和时间隔离，避免同一材料的轻微结构扰动进入两侧。评价同时包含属性误差、候选通过率、DFT 调用量与实验可复现性。

## 7. 神经行为研究方向：化学传递—神经状态—行为的多速率模型 <a href="#section-009" id="section-009"></a>

项目已有人物事实校准稿（本包不附该材料）和研究落地建议（本包不附该材料）。公开 cCCTomics 论文明确涉及条件化学传递工具与节律行为，支撑本节的任务方向；本节不是教授团队已提出的合作需求。[^S08]

第一层接入姿态/身份模型、行为事件和神经信号编码器。第二层以 SSM 处理各实体真实时序，以图表达动物互动、细胞类型或化学传递先验。第三层预测行为转移、神经—行为关系和候选干预后的变化。**动物互动图与化学传递图是不同尺度对象**，需要中间观测与监督，不能把它们拼成一张图就获得分子到行为的机制。

必须新增的字段包括动物身份概率、实验日、遗传背景、昼夜相位、神经记录质量、干预事件及时间同步误差。缺失模态可以做独立任务，不能假设所有数据已经配对。

优先实验是“多动物行为/节律与神经信号的离线预测、跨实验日评估和影子触发”。姿态模型保持可替换；神经时序与 CEBRA、简单状态空间/HMM、线性模型对照。CEBRA 的联合表征是相关先例，不是因果证明。[^S09]

主要指标是身份交换率、行为事件精确率/召回率、跨动物和跨日预测、校准及模拟触发误报。下一步才研究已有干预数据中的预测价值。真实刺激需要对应平台和实验协议，本文不设刺激参数，也不声称已完成生物机制验证。

## 8. 信号突触研究方向：分子加工—信号—突触—疾病表型的分层模型 <a href="#section-010" id="section-010"></a>

proBDNF 向成熟 BDNF 转换相关论文，以及 APP 脑类器官研究，为加工、突触和疾病表型任务提供了直接研究背景。它们支持具体任务映射，不支持将蛋白结构分数直接映射为治疗结论。[^S10][^S11]

优先做“实验条件→时间依赖功能表型”的预测器。输入应区分 proBDNF、成熟 BDNF、受体/通路测量、样本类型、处理条件、观察时长和基线状态；输出按现有数据分别定义为信号读出、突触/形态、电生理或其他功能终点。避免把不同形态的分子测量合并为一个 BDNF 总量特征。

需要三种模型接口：结构模型提供候选与结构假设；条件动力学模型学习指定体系的信号—表型关系；主动学习器在允许的候选空间内建议下一批测量。与简单剂量—时间响应模型、混合效应模型和高斯过程比较，再判断是否需要 SGD 图记忆。

类器官、动物和人群分开建域与验证，必要时采用层级参数和任务适配器。可研究共享表型映射，但不能把共享潜空间视为跨物种因果迁移成功。Aβ/Tau、突触和认知等不同观测之间保留时间、测量和体系差异。

首个交付沿用既有建议：“历史功能实验的离线主动学习回放”。要求保留对照、重复、阴性结果与独立测试，比较同等质量下的样本效率。如果历史实验是强选择性采样，离线回放只支持该候选池内的比较；对未测区域的优势需要前瞻性验证。

本次比 34 号文档更具体地完成了课题映射；仍未知的是团队实际可用数据、平台配置、样本规模及实验目标，而非相关领域研究者的大致研究方向。

## 9. 训练与预算：不能把所有损失同时堆进主干 <a href="#section-011" id="section-011"></a>

建议按领域使用

$$
L_d=L_{\mathrm{observation},d}+\lambda_pL_{\mathrm{prediction},d}
+\lambda_sL_{\mathrm{structure},d}+\lambda_mL_{\mathrm{transfer},d}
+\lambda_cL_{\mathrm{calibration},d},
$$

只启用有标签、有定义、有独立验证的项。量纲、归一化与权重需记录；似然和结构损失下降不直接等价于任务收益。干预、生成与主动选择任务另行定义目标。无训练数据的目标不能由损失函数命名产生能力。

先冻结成熟编码器与基础模型，训练读出/适配器；再单独引入图与时序模块；最后验证局部细化和预算器。比较完全分域训练、部分共享及联合训练，报告负迁移。科学小样本任务可先用非深度学习基线，平台仍可提供数据与证据价值。

主动选择的候选包括“再计算、换更可信工具、补观测、做重复、暂停”；以预计任务收益和校准不确定性为依据，计入计算、排队、样本与测量成本。最大方差不一定最有价值，重复测量也不一定减少模型偏差。预算器的预测收益必须用后续结果核验。

## 10. 推进顺序与硬件影响 <a href="#section-012" id="section-012"></a>

| 阶段 | 交付物 | 通过条件 |
|---|---|---|
| P0 数据与基线 | 科学状态协议；各域一个任务卡；数据来源/许可；冻结切分 | 确认数据可得、指标可计算、基线可运行 |
| P1 单任务增强 | 固定图/固定预算版本；可替换编码器；分域模型头 | 对简单及成熟基线有可重复收益，或得到明确负结果 |
| P2 核心研究 | E05 状态迁移、E06 条件迁移、E08 多保真预算逐项消融 | 收益可归因，额外计算/实验成本可接受 |
| P3 前瞻验证 | 新本体、新批次、新组成或新干预的独立验证 | 覆盖和失效边界清晰；历史回放收益可部分复现 |
| P4 部署 | 实际算子轨迹、内存/带宽/时限剖面、运行时合同 | 软硬件优化保持科学与控制指标 |

若已有可用数据，优先保留三个互补切片：TC 物理任务、神经行为研究方向离线神经行为任务、信号突触研究方向实验回放。分子和材料先接入现成模型，待确认数据后各选一个窄任务。顺序由数据与基线可得性决定，不是要求同时启动全部研究线。

Aegis-X 近期应完善有界稀疏图、状态迁移、多速率时间戳、候选隔离与误差统计的执行支持。原子模型的能量梯度、组学大表、三维显微、长时轨迹和 DFT 工具属于不同负载；先保留 CPU/GPU/科学计算工具协作。数据类型、SPM、DRAM 和专用单元数值由实际剖面确定，不因“支持 AI 制药”而直接扩大 TOPS 或新增 ASIC。

项目主张应写为“可复用机制与领域增强路径”，直到获得统一协议下的结果。科学效用最终以可信预测、独立验证与实验效率衡量，而非模块数量。
