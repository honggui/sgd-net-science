## 1. 任务定义和最小模型 <a href="#section-001" id="section-001"></a>

首个模型以可追踪对象的交互序列为对象，输入历史观测、环境条件及给定动作，预测未来对象状态、接触事件和观测分布。模型回答“采取某动作后可能出现什么”，不直接决定执行该动作。先选短时机械/粒子环境，不将所有视频理解、长文本规划和开放世界任务纳入一次训练。

与 TC 共用动力学部分，但 WM 不要求本体动作解码或设备控制；也可服务仿真代理、场预测等任务。若只有无动作视频，得到的是观测预测模型，不能在无相应数据时声称学到了动作效应。

初始输入规格：历史 16 个观测事件，N≤128、E≤1024、d=s=128、4 块，预测 H=8。事件间隔用真实 Δt，不能把 8 步统一解释为固定秒数。物理状态示例为位置、速度、物体属性和接触模式；遮挡时位置估计与置信度分开。

## 2. 组件配置与专用单元 <a href="#section-002" id="section-002"></a>

常规数据/训练/运行单元遵循 36；模型选 B01/B03/B04/B06/B07/B08，C01—C05/C07/C08，D01—D07，E01/E02/E03/E08，F01/F02/F08。F03—F07 与 G04 为后续消融；D08、E04/E06/E07 初版关闭，周期环境才启用 C06。

| 本域单元 | 对应基础单元 | 输入→输出与组成 |
|---|---|---|
| WM01 对象槽及关联 | A03、B01、B07 | 图像局部特征→实体槽、可见性、匹配概率；首轮可直接用环境实体标签 |
| WM02 状态信念编码 | B08、D04/D05 | 历史测量→隐记忆与当前状态估计；对缺测保留掩码 |
| WM03 动作条件器 | B06 | 已知动作及持续时间→逐节点作用条件；世界坐标与本体坐标转换有记录 |
| WM04 条件转移分布 | E01 | h,z,动作→增量均值、正尺度与模式 logits |
| WM05 观测生成/似然 | E02 | 未来状态/潜表示→可观测变量分布；像素解码可选 |
| WM06 潜未来预测 | G04 | 上下文潜表示与动作→教师未来表示；训练辅助，不独立提供物理单位 |
| WM07 多步展开 | F08、E01 | 状态快照与动作序列→H 步独立假想轨迹 |
| WM08 任务/终止读出 | E08 | 未来状态→任务代价、终止或失效概率；必须有对应标签 |

WM01 用实体真值可隔离感知与动力学问题；之后才替换成真实视觉追踪，分别报告感知误差对滚动的影响。

## 3. 前向与输出合同 <a href="#section-003" id="section-003"></a>

每个观测事件先更新对象身份、时间和当前图。四层时空块各推进一次记忆，WM02 输出当前信念。给定动作序列后复制状态，WM04 预测下一状态；将预测状态编码为下一假想步的输入，继续滚动。预测观测不伪装为真实观测创新，真实轨迹记忆不被覆盖。

可采用以下条件概率分解作为训练定义：

$$
p(x_{1:H},o_{1:H}\mid h_0,u_{0:H-1})
=\prod_{k=1}^{H}p_\theta(x_k\mid h_{k-1},u_{k-1})p_\psi(o_k\mid x_k,h_{k-1}).
$$

已知 x 时监督状态头；未知 x 时需选择明确的潜变量训练方法或仅训练观测头，不能假定潜状态具有真实坐标。连续变量首轮用对角高斯，尺度为 softplus 输出加正下限；旋转采用适当局部参数/流形误差，接触模式用分类分布。多峰动作结果出现时再比较混合分布或采样模型。

输出包含预测均值/尺度、接触概率、有效性、每步物理时间、图/模型版本和观测年龄。潜空间距离另列，不能与毫米、牛顿等误差混用。

## 4. 数据与训练步骤 <a href="#section-004" id="section-004"></a>

数据保存 episode、实体、动作、Δt、观测、状态可用性、环境参数和终止原因。完整留出环境参数、对象组合及交互序列；同一 episode 的邻帧不能跨训练和测试。先选可得到真实状态与动作的仿真数据，再加入感知噪声与真实数据。

1. 固定感知或使用实体真值，固定图和预算，训练一步转移与观测读出。
2. 用真实时间顺序做短序列训练；每批 episode 起点重置状态，连续片段的截断反传策略显式记录。
3. 加入多步展开损失，分别测教师强制和自由滚动，记录误差随跨度增长。
4. 需要视觉预训练时加入 WM06；教师未来视图只进目标支路，不能泄漏至当前输入。
5. 加入图细化和预算器，采用粗/细成对数据及离线收益标签，控制实际总成本。

损失为有效状态/观测的负对数似然、接触交叉熵、适用物理残差，加可选潜空间预测与状态迁移项。逐项列权重与训练集归一化常数。校准使用独立 episode，并在闭环选择后的分布重新检查。

## 5. 基线、消融与接受条件 <a href="#section-005" id="section-005"></a>

必需基线：持有上一状态、常速度、简单状态空间模型、固定图 GNN+GRU、同输入 GNN+SSM，以及可复现的相关世界模型。FACTS 已有图记忆与选择性状态空间结合，不能把这一组合本身当作新贡献。[FACTS](https://arxiv.org/abs/2410.20922)

消融 WM02 的时间记忆、动作条件、EGNN、观测校正、多步损失、P/Q 与预算器。指标包括逐步状态误差、分布 NLL/覆盖率、接触分类、长期漂移、动作反应差异及端到端成本。对状态预测任务，视频观感不作为主要指标。

若模型不优于简单动力学，先检查数据和任务；若无动作输入也同样准确，检查训练中是否缺乏动作变化或存在泄漏。初版通过意味着在预先冻结任务上得到可重复预测收益，不能称为通用世界模型。

## 6. 向其他世界模型扩展 <a href="#section-006" id="section-006"></a>

连续场采用网格/粒子编码、边界条件、场读出与求解器接口，不能沿用对象槽直接输出 PDE 解。可保留时序和预算机制，将领域已知部分交给数值核心。NeuralGCM 是混合动力学建模的参考，但其领域结论不外推为本模型的能力。[NeuralGCM](https://www.nature.com/articles/s41586-024-07744-y)

语言语义目标由冻结编码器提供条件；若需要规划，另接 [38 物理 AI](38-SGD-Net物理AI与灵巧手模型构建详解20260912.md) 的候选与控制层。保存数据切分、配置、权重、校准包及完整滚动回放，才构成可复现交付。

## 数学任务合同与扩展优先级（2026-09-12） <a href="#section-008" id="section-008"></a>

以给定历史与动作条件下的未来轨迹或条件分布为目标；分别登记预测时域、状态误差、事件概率校准和闭环损失。部分可观测环境不强设唯一未来，延迟查询失败先检查信息与记忆容量。

采用 [48 号数学评估](48-SGD-Net函数空间算子逼近与约束解空间评估20260912.md)区分表达、学习和数值求解能力；按 [49 号任务卡](49-SGD-Net能力优先路线与数学评估任务卡20260912.md)先做固定结构基线，再加入证据支持的单项扩展。无需先模拟其它模型的完整计算。
