## 1. 先确定预测对象，再组装网络 <a href="#section-001" id="section-001"></a>

建议首版选择具有可靠实验标签的蛋白—配体候选排序任务。固定一种测量终点与实验体系，输入结构候选、序列和实验条件，输出该终点预测及不确定性。若研究抗体，应另设蛋白—蛋白及功能终点配置，不能直接套用小分子亲和力权重。

保留三种不同模型任务：静态结构/性质预测、真实轨迹动力学预测、候选生成。第一种不启用时间 SSM；第二种需要真实轨迹与环境条件；第三种有独立去噪/流时间，不将其解释为动力学时间。

AlphaFold 3 和 Boltz 提供可接入的结构与相互作用模型来源。首版读取其输出，冻结上游，在下游增加可检验的 SGD 图增强，而非未经代码、权重及许可确认就插入其内部层。[AlphaFold 3](https://www.nature.com/articles/s41586-024-07487-w)、[Boltz 官方仓库](https://github.com/jwohlwend/boltz)

## 2. 组件配置与专用单元 <a href="#section-002" id="section-002"></a>

启用 B02/B03/B06/B07、C01/C02/C03/C05/C07/C08、D01/D02/D03/D06/D07、E05/E06/E08、F01/F02/F08；有直接状态标签才用 B08。D04/D05 初版关闭。F04 的 candidate 模式用于候选排序；图细化实验才用 C04/F05/F06/F07。E07 是后续生成分支。

| 单元 | 对应基础单元 | 输入→输出和内部责任 |
|---|---|---|
| MOL01 化学实体解析 | A01/A02、B03、C02 | 原子、键、形式电荷、立体化学、链与残基→有类型节点/边 |
| MOL02 序列与口袋编码 | B02/B06/B07 | 蛋白序列、候选结合区域→条件特征；上游冻结版本 |
| MOL03 化学几何块 | C05/C07、D02/D07 | 键图与空间邻域→几何增强节点；手性模式明确 |
| MOL04 构象集合读出 | E08 | 多构象表示及条件→集合特征/分布；不默认均匀权重为热平衡分布 |
| MOL05 属性/终点头 | E05/E06 | 分子与实验条件→所选终点均值/尺度，终点间独立头 |
| MOL06 结构合法性检查 | F01、H04 | 候选坐标→键、clash、手性与约束状态 |
| MOL07 局部候选精化 | F04/F07 或 E07 | 受约束区域与全局上下文→新候选；保留全局复核 |
| MOL08 多保真排序 | F02/F03、G08、H01 | 模型、物理工具与实验结果→下一批评估建议 |

MOL05 中亲和力、选择性、表达性、功能、暴露或毒性需分终点定义。测量条件不同的数据不能直接合并；pLDDT 等结构置信度只作结构相关特征，不能作为药效真值。

## 3. 参考张量与前向 <a href="#section-003" id="section-003"></a>

小型调试实例以单个口袋及配体图为单位，N≤512、E≤8192、d=128、4 个几何块、最多 4 个构象。超过范围时显式裁剪/分块并记录全局上下文，不声称已经覆盖完整大分子；口袋外作用可能构成模型限制。不存在受证据支持的精确口袋时，应将定位不确定性带入结果。

前向为解析→序列/原子编码→键边和空间边→几何块→节点/集合池化→实验条件头。广延能量头采用原子贡献求和；整体终点可用合适的集合读出。每个构象的结构置信与实验终点不确定性分别输出。

若对真实能量训练，可使用 $$E_\theta(X,Z,c)$$ 和 $$F_i=-\nabla_{x_i}E_\theta$$ 的一致性路径。任意亲和力回归头的梯度不是原子力；静态几何坐标修正也不是 MD。无对应能量/力标签时关闭这一物理头，使用外部工具作为独立评估。

## 4. 训练数据、损失和顺序 <a href="#section-004" id="section-004"></a>

每条实验记录保存化学实体、蛋白构建体、测量类型、单位、实验条件、批次、检测限、来源与时间。删失结果使用合适的区间/删失似然；不能把“小于检测限”当作精确数值。未测试候选不是阴性样本。

静态首版损失为目标终点 NLL/回归损失，加有监督条件下的排序项。结构约束为可选项，须说明约束梯度会修改哪些坐标；局部精化还需全局结构与分布评价。动力学版本另加真实轨迹损失；生成版本使用选定扩散/流目标，不能把几个损失名称当成已具备训练数据。

步骤：

1. 清洗标签、单位、重复与批次，建立指纹/描述符加简单回归基线以及上游模型原始排序。
2. 冻结序列与结构来源，只训练 MOL03—MOL05；同一数据预算比较是否有收益。
3. 留出校准集，检验新化学骨架/新蛋白家族的域外退化。
4. 有失败结构与可信参考时引入局部精化；同等候选数/算力下比较全局重采样。
5. 再加入多保真筛选；独立高保真计算或实验评价最终候选，避免模型只优化自己的评分。

数据切分同时考虑配体骨架、蛋白序列/家族相似性和时间；重复结构、同源复合物和上游预训练数据重叠需记录。标签稀少时先比较冻结特征加简单头，不默认联合微调更好。

## 5. 接受条件与跨领域连接 <a href="#section-005" id="section-005"></a>

指标按终点定义，包括 MAE/相关性、排序富集、校准、有效候选比例、域外表现与实际总成本。采用按靶标/骨架或批次分组统计；高预测亲和力不能代替功能验证。

必做消融：无 SGD 增强、普通 GNN 对比几何块、无序列条件、单构象对比集合、无局部精化、固定保真策略。若简单重排序已达到同等效果，保留简单模块。

进入信号突触研究方向时，将候选结构特征作为 [43 信号—突触模型](43-SGD-Net信号突触模型构建详解20260912.md) 的可选输入，功能预测需要该体系自己的数据。模型不能跨过结构、结合、激活和疾病表型的证据层级。

交付应包含任务定义、数据/许可清单、固定上游版本、域图 schema、训练与校准配置、权重和独立候选评估报告。当前文档尚未产生这些训练工件。


## 李亚普洛夫配置补充（2026-09-12） <a href="#section-006" id="section-006"></a>

## 数学任务合同与扩展优先级（2026-09-12） <a href="#section-007" id="section-007"></a>

结构、能量、力与实验终点分别定义目标和数据域。能量数值拟合准确不保证导数准确；用力标签或适当导数范数验证。多构象应保留条件分布或选择规则，结构输出不等于药效证据。

采用 [48 号数学评估](48-SGD-Net函数空间算子逼近与约束解空间评估20260912.md)区分表达、学习和数值求解能力；按 [49 号任务卡](49-SGD-Net能力优先路线与数学评估任务卡20260912.md)先做固定结构基线，再加入证据支持的单项扩展。无需先模拟其它模型的完整计算。
