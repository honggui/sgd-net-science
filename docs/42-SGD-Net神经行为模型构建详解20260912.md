## 1. 选定首个科学问题 <a href="#section-001" id="section-001"></a>

先研究“历史行为和可用神经观测是否能提高下一时间窗口的行为状态/事件预测，并能跨动物和实验日泛化”。化学传递、遗传背景与干预记录作为条件或先验，逐步验证增量。公开 cCCTomics 工作支持化学传递与节律行为的研究方向，但不意味着我们已获得对应原始多模态记录。[cCCTomics](https://elifesciences.org/articles/91927)

模型分两版：N0 行为视频与身份的离线预测；N1 在有真实同步神经数据时增加神经编码。N0 不声称解码神经机制。后续干预效应任务需要对应对照与实验记录，不从预测准确率推出因果效应。

## 2. 组件与专用单元 <a href="#section-002" id="section-002"></a>

选 A01—A08、B01/B03/B04/B06/B07、C01/C02/C03/C05/C07/C08、D01—D06、E02/E06/E08、F01/F02/F08。D07 仅用于有明确空间意义的几何分支；无真实位置的神经关联图使用普通消息块。图细化与收益预算为后续项，D08/E04/E07 默认关闭。

| 单元 | 基础映射 | 输入→输出与处理 |
|---|---|---|
| NEU01 姿态及身份前端 | B01、A03 | 视频→关键点、身份概率、遮挡；可接现成模型 |
| NEU02 身体/互动图 | C02/C03/C05 | 身体关键点及多动物关系→空间与互动消息 |
| NEU03 神经信号前端 | B04、A04/A05 | 电生理/钙信号→有效事件特征及观测模型 |
| NEU04 多速率实体记忆 | D04/D05 | 新事件与旧状态→时间更新和校正；有实体级时钟 |
| NEU05 神经—行为融合 | B07、G04可选 | 对齐观测→联合表示；缺神经时走行为分支 |
| NEU06 条件/传递图编码 | B06、C01/C02 | 背景、相位、审查过的分子/细胞先验→条件上下文 |
| NEU07 行为/事件分布头 | E02/E06 | 历史表示→未来事件概率、状态或持续时间 |
| NEU08 影子触发回放 | F02、H03—H05/H08 | 概率与已定义规则→模拟触发、拒绝理由和延迟 |

NEU06 的细胞/递质图与 NEU02 的身体图分别编码，经条件汇聚连接。没有分子到行为中间监督时，该连接只是条件预测机制，不能称为发现化学通路。

## 3. 一个可实现的张量实例 <a href="#section-003" id="section-003"></a>

N0 可从两只动物、每只 16 个关键点起步，共 32 个身体节点，历史 32 个事件、d=s=128、4 块。关键点数量依实际标注调整；以根节点相对位置与速度编码几何，保留场地坐标及光照/节律等有意义条件。异常身份不允许直接继承另一动物记忆。

N1 另有神经通道或区域节点，与动物/会话显式绑定。不同模态不能仅因采样下标相同就视为同步；对时钟偏移、曝光和测量延迟建模。钙信号需匹配慢观测动力学，不能当作即时放电计数。

前向：姿态/神经事件→合法时间对齐→分别构图/编码→跨模态融合→逐实体 SSM→未来事件头。输出事件类型、预测窗口、概率、身份/观测质量、模型版本。影子回放只模拟规则，不连接真实刺激执行。

## 4. 训练目标与研究步骤 <a href="#section-004" id="section-004"></a>

行为头可采用状态交叉熵、多标签事件 BCE 或持续时间/风险函数目标，依据标注定义选择。脉冲计数可用适合的计数/点过程观测模型；连续钙信号需独立似然。几何误差和事件损失分开归一化。

训练顺序：固定姿态前端→简单姿态特征分类基线→加入身体/互动图→加入时间状态→仅在同步数据上加入神经融合→加入背景条件→影子回放。任何阶段可以因数据不足停留在较简单版本。

对自监督表征可比较 CEBRA；它是神经与行为联合表示的直接相关基线，而非“神经因果解码器”。[CEBRA](https://www.nature.com/articles/s41586-023-06031-6)

拆分按动物、实验日、会话及必要的遗传背景分组。时间窗口重叠不能跨切分；事件标签盲评并记录标注分歧。若身份识别已使用测试主体标签，必须披露适配范围。置信区间按动物/实验重复，不把帧当独立重复。

## 5. 消融和进入下一步的条件 <a href="#section-005" id="section-005"></a>

比较简单特征+分类器、HMM/状态空间、CEBRA 特征+头、无图、无神经、时间打乱、无背景条件等基线。时间打乱用于检查模型是否真正利用时序；标签置换可用于发现泄漏，不作为正常训练方案。

报告身份交换、遮挡恢复、事件精确率/召回、每单位记录时间误报、跨日校准、预测提前量，以及影子触发的总时延和误触发。行为准确率提高但身份变差时应分开分析。

有可靠干预记录后，增加条件效应评估和竞争解释比较。观测相似与跨日预测不构成干预可识别性；相关混杂与实验设计需记录。新采集或实际设备实验属于后续平台工作，本稿不设生物干预参数。

交付包括标签字典、实体/时钟协议、训练/测试主体列表、姿态模型版本、神经观测模型、预测权重、校准和可回放影子结果。模型带来的科研助益首先以测量可靠性、标注效率及跨日预测衡量。


## 李亚普洛夫配置补充（2026-09-12） <a href="#section-006" id="section-006"></a>

稳定性针对神经/行为观测器及数值计算；不把正常节律和状态转移抹平。触发设备条件仍由独立执行路径处理。 L01/L08 记录适用性、假设及证据；数学与单元接口见 [44 李亚普洛夫稳定性详解](44-SGD-Net李亚普洛夫稳定性组件与领域适用条件20260912.md)。这是待实现设计，不是稳定性验证结果。


## 数学任务合同与扩展优先级（2026-09-12） <a href="#section-007" id="section-007"></a>

把神经活动、化学传递和行为的观测空间及时间尺度分开登记；预测准确不直接证明因果机制。主体外、干预条件外验证分别报告；部分观测下用可辨识的统计目标，不强行重建唯一隐含回路。

采用 [48 号数学评估](48-SGD-Net函数空间算子逼近与约束解空间评估20260912.md)区分表达、学习和数值求解能力；按 [49 号任务卡](49-SGD-Net能力优先路线与数学评估任务卡20260912.md)先做固定结构基线，再加入证据支持的单项扩展。无需先模拟其它模型的完整计算。
