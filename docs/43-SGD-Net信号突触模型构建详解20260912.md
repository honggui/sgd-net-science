## 1. 首个模型回答什么 <a href="#section-001" id="section-001"></a>

以指定实验体系为范围，预测“样本基线和已记录处理条件如何影响后续信号及功能表型”。区分 proBDNF、成熟 BDNF、受体/通路读出、突触形态和功能终点，不将它们压成单一 BDNF 总分。

相关研究涉及 proBDNF 加工与表型，以及 APP 脑类器官中的疾病相关病理。这些工作提供任务背景，不能用结构预测代替相应功能测量。[proBDNF 研究](https://www.nature.com/articles/s41380-024-02595-5)、[脑类器官研究](https://www.nature.com/articles/s41422-024-00957-w)

首版 S0 为历史样本级功能实验的条件回归与主动学习回放；有真正纵向记录时增加 S1 时间模型；S2 才研究动物、类器官等多域共享。三者分别验证。

## 2. 组件配置与本域单元 <a href="#section-002" id="section-002"></a>

S0 选 B03/B04/B06/B07、C01/C02/C08、D01/D02/D03/D06、E02/E06/E08、F01/F02、G01—G03/G05/G07/G08、H01/H02/H04/H08。影像和组学存在时分别加 B01/B05；S1 才开 D04/D05。无真实几何时关闭 C05/D07，不用分子坐标表达全部信号通路。

| 单元 | 基础映射 | 输入→输出与限制 |
|---|---|---|
| SYN01 样本/批次编码 | A01/A03/A06/A08 | 样本、孔位、批次、物种/体系→身份及条件；身份键不作通用生物特征 |
| SYN02 加工与信号表征 | B03/B04、C01/C02 | 区分形式的分子/通路测量→有类型节点及条件图 |
| SYN03 形态/功能编码 | B01/B04/B05 | 显微、电生理、组学→模态特征与 QC；无配对不强行融合 |
| SYN04 条件响应/时间块 | B06、D06或D04/D05 | 基线、条件、观察时间→预测表示；横截面与纵向分开 |
| SYN05 多终点读出 | E02/E06/E08 | 表示→各功能终点均值、尺度或分布 |
| SYN06 跨体系适配 | B06、G06 | 共享特征加域参数→体系特定输出；保留分域基线 |
| SYN07 实验选择器 | G08、F02/F03 | 已知记录与候选池→下一批建议，含重复/对照成本 |
| SYN08 回放与结果追踪 | H02/H04/H08 | 选择过程、真实结果→收益、偏差和失败记录 |

结构/分子模型可由 [39 SGD-Mol](39-SGD-Net制药与分子模型构建详解20260912.md) 提供额外候选特征，组学可接 [40 SGD-Cell](40-SGD-Net生物与细胞模型构建详解20260912.md)。没有配对功能标签时，这些特征仅用于候选假设，不能完成端到端功能预测。

## 3. 最小数据模式、张量和前向 <a href="#section-003" id="section-003"></a>

每条记录包含样本体系、基线、处理标识及其已审定条件、观察时间、终点定义/单位、检测限、批次、QC、重复与原始数据引用。前后重复测量和不同样本的同一时间点分开登记。

S0 可用 N≤32 的审查过测量/通路节点、d=128、2—4 个普通图块、样本 batch≤32 作为调试配置。节点是变量/测量，不是新增细胞。仅少量记录时，从高斯过程或混合效应模型开始；深度配置不是必选。

前向为样本条件校验→各模态编码→有类型通路消息→条件融合→多终点分布头。S1 按同一可追踪实体的真实时间更新；破坏性测量只能做条件群体预测。只有时间标签而无配对，不能训练成同一实体轨迹。

SYN02 的先验边保留“文献先验/本实验支持/待检验”类型。可学习边权是预测参数，不直接解释为反应速率或因果边。若需要机理 ODE，另定义状态、反应项、单位、观测映射与可识别参数，再与数据驱动模型比较。

## 4. 训练目标与逐步构建 <a href="#section-004" id="section-004"></a>

初版按终点分别采用连续回归/NLL、分类或计数似然；删失测量使用区间信息，缺测不当零。用基线和批次条件建模，但若处理与批次完全混杂，应报告不可分，不用算法保证消除混杂。

先构建常数、基线校正、条件响应、混合效应与高斯过程基线。然后固定预处理训练 SYN04/SYN05；有足够信息时加入 SYN02 图与 SYN03 多模态。S1 再与无时间记忆版本比较。S2 比较完全分域、共享骨干加 adapter、联合模型，独立报告负迁移。

损失由有效终点 NLL、可测时间一致性及有依据的结构约束组成。不能随意强制所有响应单调：只有领域支持且验证的终点才施加单调性约束。不同终点的权重与实验可靠性预先定义，不能在看测试表现后改主指标。

切分按批次、供体/动物、实验体系与时间，必要时留出处理条件。技术重复不能当作独立生物重复。校准集与测试集分开，模型选择只用验证集。

## 5. 主动学习回放如何成立 <a href="#section-005" id="section-005"></a>

在历史已测候选池内，用固定初始集合启动；随机选点、空间填充/规则、高斯过程和 SGD 选择器分别选择下一点，只有被选中后才揭示历史标签。全部方法采用相同预算、候选池、初始集合和质量规则，重复多个随机种子。

保留对照和必要重复，预算包含测量失败与样本成本。不能从剩余标签预先挑“最有希望”的初始集合。若某些候选结果缺失，不能用当前模型预测充当真值来证明自己的选择优势。

选择目标可为减小预先指定终点误差、提高已验证候选命中或区分竞争假设。信息增益/不确定性只是选择依据，其实际价值由揭示后的真实结果评价。历史池存在选择偏差，离线收益不能外推到未测空间，后续需要前瞻验证。

## 6. 验证与科研产出 <a href="#section-006" id="section-006"></a>

报告分终点误差、跨批次校准、与简单模型差异、模态缺失退化和达到同等精度所需测量数。消融图先验、多模态、时间记忆、域适配及主动选择。模型预测的信号变化不直接等于突触改善，更不等于疾病治疗获益。

跨动物、类器官和人群使用不同域与输出定义。共享潜表示只支持表征复用假设，不能证明因果迁移。对疾病机制的竞争解释，应记录后续独立证据与冲突，而不是输出唯一“根因”。

交付包括实验数据字典、终点/单位协议、先验图来源、分域配置、训练/校准权重、冻结测试与主动回放报告。实际设备编排遵守已有平台协议；本研究文档不定义加样或生物干预参数。


## 李亚普洛夫配置补充（2026-09-12） <a href="#section-007" id="section-007"></a>

稳定性用于拟合/估计与有定义的纵向误差，不预设 BDNF、突触或疾病表型具有统一下降势函数。 L01/L08 记录适用性、假设及证据；数学与单元接口见 [44 李亚普洛夫稳定性详解](44-SGD-Net李亚普洛夫稳定性组件与领域适用条件20260912.md)。这是待实现设计，不是稳定性验证结果。


## 数学任务合同与扩展优先级（2026-09-12） <a href="#section-008" id="section-008"></a>

对信号、突触与类器官终点区分条件预测、动力学与干预响应；proBDNF 与成熟 BDNF 等状态及观测映射须明确。稳态、瞬态和终点误差分别定义，未测隐状态不能仅靠增大网络保证恢复。

采用 [48 号数学评估](48-SGD-Net函数空间算子逼近与约束解空间评估20260912.md)区分表达、学习和数值求解能力；按 [49 号任务卡](49-SGD-Net能力优先路线与数学评估任务卡20260912.md)先做固定结构基线，再加入证据支持的单项扩展。无需先模拟其它模型的完整计算。
