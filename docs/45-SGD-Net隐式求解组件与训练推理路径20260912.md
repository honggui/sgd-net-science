## 1. 核对结论 <a href="#section-001" id="section-001"></a>

世界模型送审稿（本包不附该材料）第 4.2 节已有后向欧拉、求根状态和受限慢环。[27 混合训练](27-SGD-Net混合求解训练体系与世界模型研究路线.md)已有近端/分裂等求解框架。36 号文档仅有通用工具、精化和优化接口，没有完整显式登记隐式前向与隐式梯度，因此不能说此前总架构已经完整引入。

17 号中的“隐式快速机制”指经验内化/蒸馏，不等于这里的隐式方程求解。SSM 递归、GNN 多层传播、训练期 SGD 也不自动成为隐式模型。

## 2. 三种模式分别配置 <a href="#section-002" id="section-002"></a>

| 模式 | 定义 | 基础单元落点 |
|---|---|---|
| 平衡表示 DEQ | z*=fθ(z*,u,G)，在同一物理时刻求表示平衡 | D02/D03/D06 组成权重共享块，经 F07 求解 |
| 隐式物理步进 | x⁺=x+Δt fθ(x⁺,a,c)，求下一物理状态 | E01/E05、H01；必须有物理时间和动力学语义 |
| 隐式约束/优化层 | 解声明的约束问题或近端子问题 | L05、G03、H01；只有满足条件时可隐式求导 |

DEQ 是直接相关先例，不主张把求固定点作为本项目首创。[Deep Equilibrium Models](https://proceedings.neurips.cc/paper/2019/hash/01386bd6d8e091c2ab4c7c7de644d37b-Abstract.html) 多分辨率平衡也已有 MDEQ，不能将多尺度隐式层本身作为创新。[MDEQ](https://proceedings.neurips.cc/paper/2020/hash/3812f9a59b634c2a9c574610eaba5bed-Abstract.html)

初版建议将平衡模块放在显式时空块后的局部慢环，先保持可运行显式基线；证明收益后可以改为选定块的替代路径，而不必永远停留在外部工具。物理隐式步进则按任务选择，不强制替换所有 E01。

## 3. 六个内部子单元 <a href="#section-003" id="section-003"></a>

这些是已有基础单元的内部细化，不新增顶层组件计数。

| 子单元 | 父单元 | 输入→输出 |
|---|---|---|
| IM01 方程装配 | F07、E01、H01 | 模式、输入、冻结图/参数→R(z;u,θ,G)=0及维度 |
| IM02 初值和预条件 | F07、F08 | 显式结果或合法历史快照→初值与预条件器 |
| IM03 有界前向求解 | F07、H01/H03 | 残差算子→近似解、迭代数、残差及终止原因 |
| IM04 残差与条件诊断 | F01、L03/L08 | 迭代轨迹→容差判定、数值状态与适用的误差界 |
| IM05 梯度接口 | G01/G03 | 近似根、损失梯度→隐式或展开梯度及其精度记录 |
| IM06 接受与失败路径 | F08、H04、L05/L08 | 近似解/诊断→接受、退回显式基线或 unknown |

求解器状态和动作检查状态分开。数值收敛不等于物理正确；失败后显式结果也必须经过自己的质量检查，不能自动标记成功。

## 4. 前向与反传 <a href="#section-004" id="section-004"></a>

对 DEQ 使用 R=z−fθ(z,u,G)。一次求解期间固定参数、图、掩码、真实记忆和目标条件；SSM 的真实时间状态不得在每次迭代重新推进。GNN/EGNN 可作为 f 的组成。若需要状态中的某部分共同求平衡，必须将它纳入 z 并重新定义方程，而非暗中更新外部 cache。

起始方案是阻尼固定点迭代；Anderson、Broyden、Newton/Krylov 作为独立对照。它们没有对任意非线性网络的统一收敛保证。记录最大次数、绝对/相对容差、残差归一化、墙钟期限、停滞及非有限值。可采用 `||R||≤atol+rtol·max(||z||,||f||)` 的尺度化终止，但变量单位必须先一致。

当 f 在相应域为 q<1 的压缩映射且近似解/真根满足该域条件时，可由残差给出 `||z−z*||≤||R(z)||/(1−q)`。一般情况下小残差不保证小解误差，需条件数或额外分析。

在可微、局部根唯一且 J_R 可逆等条件下，解伴随系统

$$
J_R^T\lambda=\nabla_z\mathcal L,\qquad
\frac{d\mathcal L}{d\theta}=\partial_\theta\mathcal L-\lambda^T\partial_\theta R.
$$

DEQ 中 J_R=I−∂f/∂z。使用 Jacobian-vector/vector-Jacobian 乘积可避免显式稠密 Jacobian，但伴随线性求解仍消耗时间与缓存。前向未充分收敛、线性系统病态或反向超时会影响梯度。截断展开通过已执行迭代反传，是另一种训练方法，不能混称精确隐式梯度。

图硬切分和专家增删是离散事件，首版在一次前向/反向期间冻结；结构选择放到外环，或采用明确的连续松弛并声明梯度近似。参数或图版本改变时，历史初值可试用但旧收敛记录和预条件器不能直接复用为证据。

## 5. 与等变、李亚普洛夫及生长的协调 <a href="#section-005" id="section-005"></a>

若 f、初值、求解操作与停止准则都符合相应对称性，才讨论有限容差求解的等变误差。硬选择、坐标轴相关预条件器或多根选择可能破坏一致性。只证明 f 等变不证明完整求解器输出等变。

数值迭代的残差/merit 函数与物理 Lyapunov V 分开。求解迭代收敛、隐式积分格式稳定、闭环控制稳定是三个对象，44 号的 L01 必须注明当前检查哪一个。后向欧拉的特定数值稳定性质也不保证大步长准确或接触事件未被跳过。

发生生长时：结束或放弃当前求解→F05/F06/状态扩维映射→L06 检查切换→重建方程与预条件→在新版本上求解。禁止边做 Broyden/Newton 更新边任意改未知数维度或图拓扑。

## 6. 领域选择与验收 <a href="#section-006" id="section-006"></a>

世界模型可试平衡表示或刚性动力学；灵巧手可试有限预算慢环但保留独立控制；分子/材料可试结构或约束求解；细胞/神经/信号模型仅在有明确方程与数据时使用。静态回归不因“隐式更高级”而强制加入。

先验证可解析线性系统、已知非线性小系统和梯度有限差分，再比较固定层数、权重共享展开、有界求根。报告任务质量、前后向残差、失败率、显存、完整训练与推理时间；不能只报有效深度或理论内存优势。

不收敛时记录 `MAX_ITER/TIMEOUT/STAGNATED/NON_FINITE/STALE_VERSION` 等明确原因，是否输出近似结果由任务合同决定。数据、对称性、稳定性、结构切换与硬件预算验证完成后，才可报告该隐式配置在特定任务上有效。
