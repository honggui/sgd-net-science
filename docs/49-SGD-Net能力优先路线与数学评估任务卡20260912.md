## 1. 按共识调整优先级 <a href="#section-001" id="section-001"></a>

| 优先级 | 工作 | 完成判据 |
|---|---|---|
| 主线 | 图—时序建模、预测与实际结果反馈、局部容量选择、稳定的状态迁移 | 在任务质量与完整成本上有可归因收益 |
| 任务触发 | 全局交互、可寻址记忆、高阶表示、场查询与算子模块 | 简单配置存在对应能力瓶颈，加入后解决该瓶颈 |
| 有条件研究 | 隐式求解、复杂流形、持久结构演化 | 对适用任务有收益，数值/遗忘/资源代价可接受 |
| 工程支线 | 完整模型导入、原权重逐算子兼容、全部训练规则复现 | 仅在迁移工具或芯片/编译器需求出现时立项 |

47 的 U01/U08 不作为 SGD 模型研究前置项目；保留必要接口与单元正确性检查即可。U02/U03/U05/U06 依任务选择，不要求同时实现。Aegis-X 的执行兼容需求单独进入编译器/硬件路线。

## 2. 数学小任务：诊断机制，不替代科研验证 <a href="#section-002" id="section-002"></a>

| 任务卡 | 任务/空间 | 比较与诊断 | 主要指标 |
|---|---|---|---|
| M01 采样与插值 | 1D 平滑、局部尖峰、分段函数；L²、最大误差和适用导数误差 | 样条/核、MLP、固定专家和自适应专家；独立改变采样与容量 | 误差—采样数—参数曲线，别名/混叠失败 |
| M02 参数化解算子 | 一维扩散边值问题，已知正系数范围和边界；能量/H¹ 类误差 | 可信数值参考、DeepONet/图算子、固定/细化 SGD | 状态/导数误差、对偶残差近似、稳定常数与成本 |
| M03 接触/模式切换 | 小型分段动力系统及外部输入 | 显式、隐式、固定/自适应预算，区分模型偏差与求解误差 | 事件时刻、短/长时误差、失败率、时限 |
| M04 信息与记忆 | 有序延迟查询、部分观测动态系统 | SSM 摘要、精确工作记忆、全局交互 | 容量拐点、查询正确率、存储/时延 |
| M05 持续适应 | 已定义可切换函数/动力学家族 | 固定模型、仅记忆、固定容量学习、持久专家生长 | 新任务误差、旧任务遗忘、容量、错误接纳 |

M01 的不连续目标不要求导数范数；M02 的参考解需做独立网格收敛检验。每张任务卡分别控制输入采样密度、训练样本数、表示容量和求解迭代，避免多个变量同时变化后错误归因。

## 4. 统一实验记录与停止规则 <a href="#section-004" id="section-004"></a>

每次评估保存任务空间合同、数据切分、采样/重构、参考解精度、约束来源、模型配置、实际自由度、优化/调参预算及工具调用。预测值误差、导数误差、约束残差和任务结果分别报告。

先跑简单强基线，再加入一个 SGD 机制。多随机种子及主体/条件分组区间，比较质量—成本 Pareto 曲线；参数匹配和时间匹配分别解释。以达到同等质量的完整成本为主要决策依据之一，不强制一个指标覆盖所有领域。

如果参考解不够准，先改善参考；如果采样不足，优先补观测；如果学习受数据限制，不先无限生长；如果求解器成本无收益，停用隐式分支；如果新专家损害旧任务或只改善训练误差，不接纳。负结果同样应记录。

## 5. 实施顺序和当前状态 <a href="#section-005" id="section-005"></a>

第一步选一个数据可得的实际任务及对应数学小任务，冻结输入、约束、解/分布目标和成本。第二步建立基线与可靠误差指标。第三步测试固定图/状态版本，再逐项验证局部表示、预算或观测选择。第四步才验证持久生长和跨条件迁移，最后以实测负载决定硬件优化。

不要求先实现所有 M01—M05，也不要求同时启动七领域。已有 TC、神经行为、功能实验回放是候选切片，具体优先级以数据和验证条件决定。

本次完成路线与数学评估设计，未训练模型、未运行上述基准。总架构 72 个顶层单元不增加；FN01—FN05 是现有单元需要补全的任务/数值接口。
