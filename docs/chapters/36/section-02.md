# 1. 架构决策与阅读入口

沿用 **SGD-Science-Core** 作为共用架构名。将模型实例定义为“编码器集合＋领域图定义＋时空块＋领域头＋可选自适应推理”。SGD-Net-TC 是其中的物理交互配置，EGNN 是几何消息传递模块，JEPA 是可选表征学习路径，GLS/Aegis-X 是外部执行与部署系统。

三种方案中，单一全领域共享权重的方案存在尺度、对称性和目标冲突；完全独立七套系统会重复开发。选择共用组件库、显式领域配置、按实验选择参数共享。静态材料或横截面细胞任务可以绕过 SSM；无几何的基因关联图可以绕过 EGNN。组件可用不意味着每个模型必须全部启用。
