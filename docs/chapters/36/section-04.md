# 3. 系统连接图

```mermaid
flowchart TD
    A[观测 合同 单位 身份 时间] --> B[领域编码器和JSBO]
    B --> C[有类型的实体图与交互图]
    C --> D[重复L次的SGD时空块]
    D --> E[状态 观测 动作 领域属性头]
    D --> L[候选V与适用的稳定检查]
    E --> L
    L --> F[误差校准与有限预算]
    E --> F
    F --> R[图细化和P/Q状态迁移]
    R --> D
    F --> Q[补观测 或调用外部工具]
    Q --> A
    E --> H[领域检查 版本检查 提交]
    H --> O[预测报告 或设备执行]
    O --> J[原始结果和离线回放]
    J --> G[训练 适配 独立评估]
    G --> W[冻结的新权重版本]
    W --> D
```

图中反馈边具有不同时间含义：R 不推进真实时间；Q 可能等待新的物理测量；G 生成候选权重，经过约定验证与版本发布后生效；可包含受限在线适配和离线巩固。D/E 是神经前向；L 含可训练 V 及条件检查/修正，H 属于外部运行时。
