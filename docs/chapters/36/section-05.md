# 4. 组件与单元全集：9 组、72 个登记单元

标记：T 可训练；D 确定性运算；X 外部工具/系统；O 可选。含 T/D 的单元应在配置中固定实现选择。训练参数、运行状态与外部数据分别存储。表内“输入→输出”定义单元责任，张量规格见第 5 节。

## A 组：科学输入与实体管理 <a href="#section-001" id="section-001"></a>

| ID | 单元 | 输入→输出 | 类型与内部操作 |
|---|---|---|---|
| A01 | 合同解析 | 原始记录→带类型样本 | D；字段校验、模式版本 |
| A02 | 单位与坐标转换 | 数值/单位/坐标系→规范物理量 | D；转换与变换记录，保留原值 |
| A03 | 实体绑定 | 观测对象→稳定 ID/匹配置信度 | D/T；关联、出生消亡、遮挡标记 |
| A04 | 时间调度 | 多源时间戳→当前事件及 Δt | D；乱序策略、最大观测年龄 |
| A05 | 缺失与质量掩码 | 观测/QC→有效性/噪声提示 | D；无观测不填充真零标签 |
| A06 | 域与条件编码输入 | 本体/物种/样本/边界条件→条件字段 | D；隔离标识字段与可学习条件 |
| A07 | 有界打包 | 变长节点/边→张量、掩码、索引 | D；溢出拒绝或显式分块 |
| A08 | 来源绑定 | 样本及预处理→原始数据引用 | X；版本、切分、实验批次 |

## L 组：李亚普洛夫稳定性与修正 <a href="#section-009" id="section-009"></a>

补回原 Layer 8 的显式责任，扩展为训练、前向和验证协同路径。L01/L08 负责声明适用性与证据；其余单元按领域启用，并非所有预测都要求 V 下降。

| ID | 单元 | 输入→输出 | 类型与执行位置 |
|---|---|---|---|
| L01 | 稳定性合同与参考 | 任务/动力学/域→误差、假设和检查模式 | D；前向之前；无定义则标记不适用或未知 |
| L02 | V/存储函数头 | 误差、图、域→V及适用时的梯度 | T/D；与预测头并列，独立版本 |
| L03 | 漂移/下降评估 | 当前/候选状态、输入、V→条件残差 | D；时间更新、精化、切换分别检查 |
| L04 | 扰动与供给预算 | 输入/误差边界→允许供给及鲁棒裕量 | D/T；估计值与已验证上界分开 |
| L05 | 状态/动作修正 | 候选、约束、预算→修正或不可行状态 | D/T；线搜索、受约束优化或已验证求解器 |
| L06 | 拓扑切换兼容 | P/Q或模式重置→V可比性及切换结果 | D/T；图版本切换前；接 F05/F06/F08 |
| L07 | 稳定性训练与反例 | 数据/候选V→损失和反例样本 | T/X；接 G01/G03/G07，主要离线 |
| L08 | 证据与失效处置 | 条件残差、证明/采样记录→状态与回退 | D/X；接 H03/H04/H05/H08 |

数学定义、EGNN 对称性、SSM 反馈、图切换条件及七领域配置见 [44 稳定性详解](../../44-SGD-Net李亚普洛夫稳定性组件与领域适用条件20260912.md)。
