# 7. 初始配置与可复现前向顺序

共同调试配置：d=s=128、4 个块、边隐维 64、MLP 隐宽 128、dropout=0；激活 SiLU，标量 LayerNorm；按域启用向量分支。此为实验起点，不是已选最优超参。N/E/H 由各文档规定并可通过配置改变；变化要重新核算。不同层参数默认不共享，时间步共享参数。

单次推理顺序：A 校验与事件选择→B 编码和融合→C 构图→每层一次 D02/D03、需要时一次 D04/D05、D06/D07→E 输出→F 评估。在 H03 允许下执行有限空间细化或候选重算→H04 检查→H05 输出。候选 rollout 从 F08 的独立状态启动，由 E01 预测推进假想时间，使用预测观测或状态编码器输入；不能调用真实未来传感器。收到真实观测后从真实轨迹重新校正。

训练先固定编码器、图与预算，训练任务头及基础块；再训练本体/领域 adapter；然后训练 P/Q；最后训练收益选择器。每次增加模块都保留此前版本作为基线。静态模型不为满足总架构而伪造时序损失。

权重包包括：启用单元、参数字典、编码器版本、图定义、归一化常数、对称性模式、损失权重、训练切分、随机种子、校准与运行上限。数据 ID、当前记忆及候选状态存为运行包，不塞进模型权重。

## 7.1 训练参数和启用规则 <a href="#section-001" id="section-001"></a>

架构实现时先以 AdamW 作为可微参数的优化基线；初始探索可从新头学习率 1e-3、骨干微调 1e-4、权重衰减 1e-2、梯度范数上限 1 起步，均为待调参数，不是实验结论。归一化参数和偏置的衰减分组另行声明。冻结编码器没有优化器状态；含能量导数的训练需验证精度与二阶反传。训练轮数由验证表现和预先确定的预算控制，不以测试集调参。

A01—A08 为所有实例的数据框架；G01/G02/G03/G07 为训练基础；H03/H04/H07/H08 为部署基础。每个领域文档列出的 B—F 为该域组件选择，其他默认关闭。L01/L08 声明稳定性范围与证据，其余 L 单元按 44 号文档选择；预测模型与检查/修正模型分别记录。阶段性组件如生成头、预算器、P/Q 和 JEPA 先关闭，只有对应训练/消融阶段才启用。H05/H06 仅在需要设备/外部动作的路径启用；普通预测报告无需设备操作。

构建模型的最小顺序是：选任务和标签→选观测编码器→定义图及对称性→决定有无真实时序→选概率/属性头→固定预算训练→按证据加入自适应模块。领域文档中的独立终点头是 E 类单元的实例，不产生新的隐式基础层。

## 7.2 单元下面的基础运算 <a href="#section-002" id="section-002"></a>

| 运算族 | 具体运算 | 主要归属 |
|---|---|---|
| 稠密变换 | embedding、Linear/GEMM、bias、SiLU、sigmoid、softplus、残差加法 | B、D、E |
| 掩码与集合 | gather/scatter、segment sum/mean、masked softmax、concat、pooling | A07、B07、C08、D03、E08 |
| 几何 | 坐标差、内积/范数、标量乘向量、周期映像、晶胞变换 | C05/C06、D07、E05 |
| 时间 | Δt 更新、逐元素 exp/乘加、scan、状态 cache | A04、D04/D05、F08 |
| 结构适应 | index remap、split/merge、prolong/restrict、局部边界 gather | C04、F04—F07 |
| 概率与训练 | 分布参数变换、NLL、采样、自动微分、EMA、梯度裁剪 | E、F02、G |
| 数值与控制 | 有限迭代、可选投影/retraction、deadline 检查、版本比较 | D08、F03、H |

以上是算法算子分解，不等于芯片指令集；同一运算可由多个后端实现。完整算子实例、参数量与 FLOPs 只能在领域配置和上游编码器确定后从实际计算图提取。
