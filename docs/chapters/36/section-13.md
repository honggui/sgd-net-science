# 12. 能力优先与可选兼容扩展（2026-09-12 修订）

[47 通用性审查](../../47-SGD-Net通用性审查与可构造模型覆盖方案20260912.md)调整为表达边界与可选兼容附录。模型的主目标是达到任务所需能力；不要求先完成既有模型的逐算子、原权重复现。数据图消息与任意程序执行不同；固定记忆、对称性和一阶聚合的限制仍应通过任务反例检查。

U01—U08 是按需能力规格，不计为已实现功能，不增加 72 个顶层单元。注意力/顺序、寻址记忆、高阶表示与概率目标由任务瓶颈触发；完整计算图导入和符合性测试主要由编译器及 Aegis-X 迁移需求触发。任务模型可直接构建，不依赖兼容模型。

隐式求解、广义几何、持久演化独立评估；保留定义不代表每个领域必须启用。未改善预先确定的质量—成本指标时允许关闭。约束模式随任务声明，不强制所有物理动力学单调收敛。
