## 27.1 从张量规模核算而非只数模块 <a href="#section-001" id="section-001"></a>

忽略批量，若每条边有宽 d 的稠密两层消息 MLP，消息成本约 O(E d²)，节点投影/FFN 约 O(Nd²)，向量几何部分约 O(Eqn)；实际维数不同时按 GEMM 形状重算。D04 逐元素递归 O(Ns)，但输入/门控投影可为 O(Ns(d+d_m+d_c))，不能把整体时序块都称为 O(Ns)。L 层乘相应成本。

一阶局部图稀疏性需来自实际邻域，密集图 E 可达 O(N²)。C03 构图成本不能忽略。IM 的 K 次迭代约增加 K 倍相关块计算，还包括历史/预条件器和反向线性求解。U02 密集注意力约 O(N²d)，高阶图和多候选进一步增加工作集。

仅 z 的状态字节为 LNs·bytes；总容量还包括 h/v、边、输入编码、权重、梯度、优化器、候选、经验和临时求解量。36 号既有 128 KiB 示例仅表示特定 z，不是芯片总需求；并发峰值按张量生存期、共享和写时复制核算。

## 27.2 最小可复现研究顺序 <a href="#section-002" id="section-002"></a>

第一阶段固定结构训练一个任务，并检查单位、身份、掩码、时间和读出。第二阶段选择一个有证据的瓶颈，对应启用 IM、U 或临时细化；同等预算比较。第三阶段加入 EV 持续学习，独立测新任务收益和旧任务遗忘。第四阶段将真实算子轨迹用于硬件映射，不因算法名称新增硬核。

数学小任务采用 [49 任务卡](../../49-SGD-Net能力优先路线与数学评估任务卡20260912.md)：函数拟合与混叠、参数化扩散、分段动力学、延迟查询及概念变化。实际领域参照 37—43；小任务检验机制，不能代替真实世界或生物任务证据。

## 27.3 验收矩阵 <a href="#section-003" id="section-003"></a>

| 检查层 | 关键检验 | 能支持的结论 |
|---|---|---|
| 数据/结构 | 单位、身份、掩码、跨样本边、周期映像 | 输入语义和布局是否一致 |
| 神经前向 | 输出形状、有限值、置换/几何变换差分 | 选定配置的实现一致性 |
| 梯度/求解 | 有限差分、前后向残差、条件数、失败路径 | 选定局部计算的数值可信度 |
| 适应/迁移 | P/Q 读出、版本隔离、优化器槽、回退 | 结构变更是否保持约定语义 |
| 任务能力 | 独立数据、域外、校准、旧任务与消融 | 指定任务下的质量和学习收益 |
| 部署 | 并发资源、时限、总字节、峰值与能耗 | 指定后端/负载下的执行代价 |

数值例子通过不能证明模型优于 SOTA；采样等变测试也不替代形式推导。报告训练预算、数据来源、失败率与不可用能力，避免只选择成功案例。
