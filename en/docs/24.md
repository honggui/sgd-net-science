## 1. From Physical Constraints to Model Representations <a href="#section-001" id="section-001"></a>

Interactions, conservation relations, and symmetries can help select state variables, graph edges, and losses, but interaction types do not automatically define independent dimensions of a vector space; nor can conservation laws be broadly equated with algebraic rings or fields. Periodic crystals can be represented using lattices and periodic boundaries, while amorphous materials require appropriate local structures and statistical descriptions. “Complexity” does not imply that hidden periodicity must exist.

A task must declare its state space, units, group actions, and observation mapping. Positions, velocities, temperatures, concentrations, and latent features cannot simply be concatenated and arbitrarily rotated together without explanation. See [36 Overall Architecture](36.md) and [48 Mathematical Assessment](48.md) for definitions and function-space assessment, respectively.

## 2. The Mathematical Role and Limits of EGNN <a href="#section-002" id="section-002"></a>

Let coordinates be $$x_i\in\mathbb R^n$$, invariant scalar features be $$h_i$$, and invariant edge attributes be $$a_{ij}$$. A reference update is:

$$
m_{ij}=\phi_e(h_i,h_j,\|x_i-x_j\|^2,a_{ij}),\qquad
x_i'=x_i+\sum_{j\in\mathcal N(i)}(x_i-x_j)\phi_x(m_{ij}),
$$

$$
h_i'=\phi_h\!\left(h_i,\sum_jm_{ij}\right).
$$

If $$Q^TQ=I$$, the coordinate transformation $$x_i\mapsto Qx_i+t$$ preserves distances and scalar messages, and transforms the coordinate update into $$Qx_i'+t$$. This requires edge selection to satisfy the corresponding symmetry as well, and aggregation to be independent of arbitrary node numbering. The original EGNN already supports Euclidean spaces above three dimensions. This project should investigate contributions from combining it with states, constraints, and evolution, rather than call $$n\ge3$$ alone a new invention. [Original EGNN paper publication page](https://proceedings.mlr.press/v139/satorras21a.html)

Equivariance does not hold under “arbitrary affine transformations.” Positions undergo translation, while vectors such as velocities and forces undergo only the corresponding rotation; general scaling and shearing are outside the E(n) contract above. Ordinary GNNs can accept coordinates, but are not automatically equivariant without structural constraints. Chiral molecules and tasks with specific external fields also require an appropriate choice of SE(3), E(3), or restricted symmetry. Equivariance alone does not prevent atomic overlap, collisions, energy errors, or divergent dynamics.

AlphaFold's local rigid frames and IPA may inform geometric module selection, but do not justify claims of being “the most economical and effective” or “collision-free.” The original reference is retained as the [AlphaFold 2 paper](https://www.nature.com/articles/s41586-021-03819-2); the publication page could not be retrieved during this round, so the full text was not reverified and is not used as evidence for new performance conclusions.

## 3. Distinguishing SSMs, Implicit Solves, and Learning <a href="#section-003" id="section-003"></a>

An event recurrence can be written as:

$$
z_{t+1}=\bar A_tz_t+\bar B_tu_t,\qquad y_t=C_tz_t.
$$

Here the next state is computed directly from existing variables, making this an explicit recurrence. Mamba uses input-dependent selective state propagation and hardware-friendly recurrence algorithms; adopting this module does not mean historical information is unnecessary, nor does it directly establish control stability. [Original Mamba paper abstract and version history](https://arxiv.org/abs/2312.00752)

When a fixed-point representation or implicit physical time step is needed, separately define $$R(z^*;u,\theta,G)=0$$ and configure the solver, tolerances, failure semantics, and valid gradients; keep parameters and the graph fixed throughout each solve and its backward pass. This concept differs from a compressed hidden state. [Original DEQ paper](https://arxiv.org/abs/1909.01377), [45 Implicit Solves](45.md)

SSM state updates, tree routing, and memory retrieval can operate without weight updates; persistent parameter improvement generally requires an explicit learning mechanism, which may be gradient training or other validated update rules. “Having a physics residual” does not imply self-evolution without training.

## 4. How Four Module Types Form a Candidate Evolution Loop <a href="#section-004" id="section-004"></a>

| Module | Inputs and role | Indispensable conditions |
|---|---|---|
| EGNN / geometry module | Produces equivariant states or geometric predictions under the declared group action | Consistency of edges, metrics, scalar/vector channels, and external fields |
| SSM / state module | Maintains event memory at every layer and combines new observations to generate the next prediction | Separate real event time, imagined time, and solver iterations |
| Dynamic tree / EV module | Proposes growth/pruning candidates based on paired errors, attribution, complexity, and budget | Separate representation, expert, and candidate-experiment modes; migrate the complete state |
| Harness / L module | Checks applicable physical constraints, numerical conditions, and candidate execution boundaries | Residual checks are not universal proofs; separate model acceptance from permission to execute on physical systems |

First save the inputs and versions available at prediction time, then pair them with real outcomes arriving later. Persistent errors may arise from missing observations, noise, discretization, or insufficient capacity, and must not directly force a split. Train or refine candidates on isolated copies, migrate states at every layer, the optimizer, and the layout, then automatically accept at a window boundary after checking benefits, old-task regressions, and resources; retain the active version on failure. See [46 Continuous Evolution](46.md).

## 5. Physics and Stability Validation <a href="#section-005" id="section-005"></a>

Energy consistency can be checked for closed conservative systems; driven, dissipative, and collision systems should record work, dissipation, and mode transitions. Conservation of physical energy and decrease of a Lyapunov function are different propositions. Reducing a residual penalty does not automatically imply system convergence; a fixed “0.5%” can only be an example threshold for a calibrated task, not a universal rule. Specify the domain, positive definiteness, decrease/dissipation conditions, switching, and numerical error budget of a candidate V according to [44 Stability Conditions](44.md).

The first round should compare four configurations: a fixed graph, state-only adaptation, temporary refinement, and persistent learning. Measure held-out task errors, constraint violations, migration jumps, old-task regressions, and total cost including training/replay. All are experiments yet to be performed; this round has produced no model or chip performance results.
