## 1. Select the First Scientific Question <a href="#section-001" id="section-001"></a>

First study “whether historical behavior and available neural observations improve prediction of behavioral states/events in the next time window, with generalization across animals and experimental days.” Use chemical transmission, genetic background, and intervention records as conditions or priors, verifying incremental benefits step by step. Published cCCTomics work supports research on chemical transmission and rhythmic behavior, but does not imply that we have obtained the corresponding raw multimodal records. [cCCTomics](https://elifesciences.org/articles/91927)

The model has two versions: N0 provides offline prediction from behavioral video and identities; N1 adds neural encoding when real synchronized neural data are available. N0 does not claim to decode neural mechanisms. Later intervention-effect tasks require corresponding controls and experimental records; predictive accuracy does not establish causal effects.

## 2. Components and Specialized Units <a href="#section-002" id="section-002"></a>

Select A01–A08, B01/B03/B04/B06/B07, C01/C02/C03/C05/C07/C08, D01–D06, E02/E06/E08, and F01/F02/F08. D07 is used only in geometry branches with explicit spatial meanings; neural association graphs without real positions use ordinary message blocks. Graph refinement and benefit budgeting are later additions; D08/E04/E07 are disabled by default.

| Unit | Basic mapping | Input → output and processing |
|---|---|---|
| NEU01 Pose and identity frontend | B01, A03 | Video → keypoints, identity probabilities, occlusion; existing models can be connected |
| NEU02 Body/interaction graph | C02/C03/C05 | Body keypoints and relationships among animals → spatial and interaction messages |
| NEU03 Neural-signal frontend | B04, A04/A05 | Electrophysiology/calcium signals → valid event features and observation models |
| NEU04 Multirate entity memory | D04/D05 | New events and old states → temporal updates and corrections; entity-level clocks |
| NEU05 Neural–behavioral fusion | B07, optional G04 | Aligned observations → joint representations; use the behavioral branch when neural observations are missing |
| NEU06 Condition/transmission graph encoding | B06, C01/C02 | Background, phase, reviewed molecular/cellular priors → conditional context |
| NEU07 Behavior/event distribution head | E02/E06 | Historical representations → future event probabilities, states, or durations |
| NEU08 Shadow-trigger replay | F02, H03–H05/H08 | Probabilities and predefined rules → simulated triggers, rejection reasons, and delays |

Encode NEU06's cell/transmitter graph and NEU02's body graph separately, connecting them through conditional aggregation. Without intermediate supervision from molecules to behavior, this connection is only a conditional prediction mechanism, not discovery of a chemical pathway.

## 3. An Implementable Tensor Example <a href="#section-003" id="section-003"></a>

N0 can start with two animals, 16 keypoints each, totaling 32 body nodes, a history of 32 events, d=s=128, and 4 blocks. Adjust keypoint counts to actual annotations; encode geometry using root-relative positions and velocities, while retaining arena coordinates and meaningful conditions such as lighting/rhythms. Identity anomalies must not directly inherit another animal's memory.

N1 additionally has neural-channel or region nodes explicitly bound to animals/sessions. Modalities are not synchronized merely because their sample indices match; model clock offsets, exposures, and measurement delays. Calcium signals require matching slow observation dynamics and cannot be treated as instantaneous spike counts.

Forward pass: pose/neural events → valid temporal alignment → separate graph construction/encoding → cross-modal fusion → per-entity SSM → future-event heads. Outputs include event type, prediction window, probability, identity/observation quality, and model version. Shadow replay only simulates rules and is not connected to actual stimulation execution.

## 4. Training Objectives and Research Steps <a href="#section-004" id="section-004"></a>

Behavioral heads may use state cross-entropy, multilabel event BCE, or duration/hazard-function objectives, selected according to annotation definitions. Spike counts can use suitable count/point-process observation models; continuous calcium signals require a separate likelihood. Normalize geometric errors and event losses separately.

Training sequence: fixed pose frontend → simple pose-feature classification baseline → body/interaction graphs → temporal state → neural fusion only on synchronized data → background conditions → shadow replay. Any stage may remain at a simpler version if data are insufficient.

CEBRA can be compared for self-supervised representations; it is a directly relevant baseline for joint neural and behavioral representations, not a “neural causal decoder.” [CEBRA](https://www.nature.com/articles/s41586-023-06031-6)

Group splits by animal, experimental day, session, and genetic background where necessary. Overlapping time windows must not cross splits; evaluate event annotations blindly and record annotator disagreement. If identity recognition already uses test-subject labels, disclose the adaptation scope. Compute confidence intervals by animal/experimental replicate rather than treating frames as independent replicates.

## 5. Ablations and Conditions for Proceeding <a href="#section-005" id="section-005"></a>

Compare baselines including simple features plus classifiers, HMM/state-space models, CEBRA features plus heads, no graph, no neural input, shuffled time, and no background conditions. Time shuffling checks whether the model actually uses temporal structure; label permutation can expose leakage but is not a normal training scheme.

Report identity switches, occlusion recovery, event precision/recall, false alarms per unit recording time, cross-day calibration, prediction lead time, and total shadow-trigger latency and false triggers. Analyze improvements in behavioral accuracy separately when identity performance deteriorates.

With reliable intervention records, add conditional-effect evaluation and comparisons of competing explanations. Observational similarity and cross-day prediction do not establish intervention identifiability; record relevant confounders and experimental design. New data collection or actual device experiments are later platform work; this draft specifies no biological intervention parameters.

Deliverables include label dictionaries, entity/clock protocols, training/test subject lists, pose-model versions, neural observation models, prediction weights, calibration, and replayable shadow results. Initially measure scientific benefits through measurement reliability, annotation efficiency, and cross-day prediction.

## Lyapunov Configuration Supplement (2026-09-12) <a href="#section-006" id="section-006"></a>

Stability concerns neural/behavioral observers and numerical computation; do not smooth away normal rhythms and state transitions. Device-trigger conditions remain the responsibility of an independent execution path. L01/L08 record applicability, assumptions, and evidence; see [44 Lyapunov Stability in Detail](44.md) for mathematics and unit interfaces. This is a design awaiting implementation, not a stability validation result.

## Mathematical Task Contract and Extension Priorities (2026-09-12) <a href="#section-007" id="section-007"></a>

Register observation spaces and time scales separately for neural activity, chemical transmission, and behavior; accurate prediction does not directly prove causal mechanisms. Report held-out-subject and held-out-intervention-condition validation separately; under partial observation, use identifiable statistical targets rather than forcing reconstruction of a unique hidden circuit.

Use [48 Mathematical Assessment](48.md) to distinguish representational, learning, and numerical solution capabilities; follow [49 Task Cards](49.md) by starting with fixed-structure baselines and then adding individual extensions supported by evidence. There is no need to first simulate the complete computation of other models.
