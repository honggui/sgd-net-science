## 1. Review Findings <a href="#section-001" id="section-001"></a>

Section 4.2 of the world-model review draft (not included in this package) already contains backward Euler, root-solving states, and a bounded slow loop. [27 Hybrid Training](27.md) already contains solve frameworks such as proximal/splitting methods. Document 36 only has general tool, refinement, and optimization interfaces, without fully explicit registration of implicit forward passes and gradients, so the earlier overall architecture cannot be said to have fully incorporated them.

The “implicit fast mechanism” in 17 refers to experience internalization/distillation, not implicit equation solving here. SSM recurrence, multilayer GNN propagation, and training-time SGD do not automatically make a model implicit.

## 2. Configure Three Modes Separately <a href="#section-002" id="section-002"></a>

| Mode | Definition | Basic-unit placement |
|---|---|---|
| Equilibrium representation DEQ | z*=fθ(z*,u,G), solving a representation equilibrium at the same physical instant | D02/D03/D06 form a weight-shared block, solved through F07 |
| Implicit physical stepping | x⁺=x+Δt fθ(x⁺,a,c), solving the next physical state | E01/E05, H01; physical time and dynamics semantics are required |
| Implicit constraint/optimization layer | Solves a declared constrained problem or proximal subproblem | L05, G03, H01; implicit differentiation is available only when its conditions hold |

DEQ is a directly relevant precedent; solving fixed points is not claimed as this project's invention. [Deep Equilibrium Models](https://proceedings.neurips.cc/paper/2019/hash/01386bd6d8e091c2ab4c7c7de644d37b-Abstract.html) MDEQ already provides multiresolution equilibria, so multiscale implicit layers themselves cannot be claimed as novel. [MDEQ](https://proceedings.neurips.cc/paper/2020/hash/3812f9a59b634c2a9c574610eaba5bed-Abstract.html)

For the initial version, place the equilibrium module in a local slow loop after explicit spatiotemporal blocks, retaining a runnable explicit baseline first. After demonstrating benefits, it may become an alternative path for selected blocks rather than remaining an external tool forever. Select implicit physical stepping by task; replacing all E01 units is not required.

## 3. Six Internal Subunits <a href="#section-003" id="section-003"></a>

These refine existing basic units internally and do not add to the top-level component count.

| Subunit | Parent units | Input → output |
|---|---|---|
| IM01 Equation assembly | F07, E01, H01 | Mode, inputs, frozen graph/parameters → R(z;u,θ,G)=0 and dimensions |
| IM02 Initialization and preconditioning | F07, F08 | Explicit results or valid historical snapshots → initial guess and preconditioner |
| IM03 Bounded forward solve | F07, H01/H03 | Residual operator → approximate solution, iteration count, residual, and termination reason |
| IM04 Residual and conditioning diagnosis | F01, L03/L08 | Iteration trajectory → tolerance decision, numerical status, and applicable error bounds |
| IM05 Gradient interface | G01/G03 | Approximate root and loss gradient → implicit or unrolled gradients with accuracy records |
| IM06 Acceptance and failure paths | F08, H04, L05/L08 | Approximate solution/diagnostics → accept, return to explicit baseline, or unknown |

Separate solver status from action-check status. Numerical convergence does not equal physical correctness; explicit results after failure must also undergo their own quality checks and cannot automatically be marked successful.

## 4. Forward Pass and Backpropagation <a href="#section-004" id="section-004"></a>

For DEQ, use R=z−fθ(z,u,G). Fix parameters, graphs, masks, real memory, and target conditions during a solve; the SSM's real-time state must not advance again on each iteration. GNN/EGNN may form part of f. If some state components also need to reach equilibrium, include them in z and redefine the equation rather than silently updating an external cache.

Start with damped fixed-point iteration; use Anderson, Broyden, and Newton/Krylov as independent comparisons. None offers a universal convergence guarantee for arbitrary nonlinear networks. Record maximum iterations, absolute/relative tolerances, residual normalization, wall-clock deadlines, stagnation, and nonfinite values. A scaled termination rule such as `||R||≤atol+rtol·max(||z||,||f||)` may be used, but variable units must first be consistent.

When f is a contraction with q<1 in the corresponding domain and the approximate solution/true root satisfy the domain conditions, residuals give `||z−z*||≤||R(z)||/(1−q)`. In general, small residuals do not ensure small solution errors; conditioning or additional analysis is required.

Under conditions including differentiability, a locally unique root, and invertible J_R, solve the adjoint system

$$
J_R^T\lambda=\nabla_z\mathcal L,\qquad
\frac{d\mathcal L}{d\theta}=\partial_\theta\mathcal L-\lambda^T\partial_\theta R.
$$

For DEQ, J_R=I−∂f/∂z. Jacobian-vector/vector-Jacobian products avoid explicit dense Jacobians, but the adjoint linear solve still consumes time and cache. Insufficient forward convergence, ill-conditioned linear systems, or backward timeouts affect gradients. Truncated unrolling backpropagates through executed iterations and is a different training method; it must not be confused with exact implicit gradients.

Hard graph splitting and expert addition/removal are discrete events and remain frozen during each forward/backward pass in the initial version. Place structural selection in an outer loop, or use an explicit continuous relaxation and declare gradient approximations. When parameter or graph versions change, historical initial guesses may be tried, but old convergence records and preconditioners cannot directly be reused as evidence.

## 5. Coordination with Equivariance, Lyapunov Conditions, and Growth <a href="#section-005" id="section-005"></a>

Discuss equivariance errors in finite-tolerance solves only if f, initialization, solve operations, and stopping criteria all respect the corresponding symmetry. Hard selection, coordinate-axis-dependent preconditioners, or selection among multiple roots may break consistency. Proving f equivariant does not prove that the complete solver output is equivariant.

Separate numerical-iteration residual/merit functions from physical Lyapunov V. Solver-iteration convergence, stability of an implicit integration scheme, and closed-loop control stability are three distinct objects; L01 in 44 must specify which is currently checked. Particular numerical stability properties of backward Euler also do not ensure accuracy at large step sizes or that contact events have not been skipped.

When growth occurs: finish or abandon the current solve → F05/F06/state-dimension expansion mappings → L06 switching checks → rebuild equations and preconditioners → solve on the new version. Arbitrarily changing unknown dimensions or graph topology during Broyden/Newton updates is prohibited.

## 6. Domain Selection and Acceptance <a href="#section-006" id="section-006"></a>

World models may try equilibrium representations or stiff dynamics; dexterous hands may try bounded-budget slow loops while retaining independent control; molecules/materials may try structural or constraint solves; cell/neural/signaling models use them only with explicit equations and data. Static regression does not require an implicit branch merely because “implicit is more advanced.”

First validate analytically solvable linear systems, known small nonlinear systems, and gradient finite differences; then compare fixed layer counts, weight-shared unrolling, and bounded root finding. Report task quality, forward/backward residuals, failure rates, GPU memory, and complete training/inference time, rather than only effective depth or theoretical memory advantages.

On nonconvergence, record explicit reasons such as `MAX_ITER/TIMEOUT/STAGNATED/NON_FINITE/STALE_VERSION`; the task contract determines whether approximate results may be output. Only after validating data, symmetry, stability, structural switching, and hardware budgets can the implicit configuration be reported effective for a specific task.
