## 1. Adjusting Priorities According to Consensus <a href="#section-001" id="section-001"></a>

| Priority | Work | Completion criterion |
|---|---|---|
| Main track | Graph–temporal modeling, feedback from predictions and actual outcomes, local capacity selection, stable state migration | Attributable benefits in task quality and complete cost |
| Task-triggered | Global interactions, addressable memory, higher-order representations, field queries, and operator modules | A corresponding capability bottleneck in the simple configuration is resolved by the addition |
| Conditional research | Implicit solves, complex manifolds, persistent structural evolution | Benefits for applicable tasks with acceptable numerical/forgetting/resource costs |
| Engineering branch | Complete model import, operator-by-operator compatibility with original weights, reproduction of all training rules | Initiated only when migration-tool or chip/compiler needs arise |

U01/U08 in 47 are not prerequisites for SGD model research; retaining necessary interfaces and unit correctness checks is sufficient. Select U02/U03/U05/U06 by task; simultaneous implementation is not required. Aegis-X execution compatibility needs enter a separate compiler/hardware roadmap.

## 2. Small Mathematical Tasks: Diagnosing Mechanisms, Not Replacing Scientific Validation <a href="#section-002" id="section-002"></a>

| Task card | Task/space | Comparisons and diagnosis | Primary metrics |
|---|---|---|---|
| M01 Sampling and interpolation | 1D smooth, locally peaked, and piecewise functions; L², maximum error, and applicable derivative errors | Splines/kernels, MLPs, fixed experts, and adaptive experts; vary sampling and capacity independently | Error–sample-count–parameter curves, aliasing failures |
| M02 Parameterized solution operators | One-dimensional diffusion boundary-value problems with known positive coefficient ranges and boundaries; energy/H¹-type errors | Reliable numerical references, DeepONet/graph operators, fixed/refined SGD | State/derivative errors, approximate dual residuals, stability constants, and cost |
| M03 Contact/mode switching | Small piecewise dynamical systems with external inputs | Explicit, implicit, fixed/adaptive budgets; distinguish model bias from solve errors | Event times, short/long-horizon errors, failure rates, deadlines |
| M04 Information and memory | Ordered delayed queries, partially observed dynamical systems | SSM summaries, exact working memory, global interactions | Capacity transition points, query accuracy, storage/latency |
| M05 Continuous adaptation | Defined switchable function/dynamics families | Fixed models, memory only, fixed-capacity learning, persistent expert growth | New-task errors, old-task forgetting, capacity, erroneous acceptance |

Discontinuous targets in M01 do not require derivative norms; reference solutions in M02 require independent grid-convergence checks. Each task card independently controls input sampling density, training sample count, representational capacity, and solver iterations to avoid misattribution when several variables change together.

## 3. Task-Space Cards for Seven Domains <a href="#section-003" id="section-003"></a>

| Domain document | Input → target | Norms/evaluation and constraints | Mechanisms to test first |
|---|---|---|---|
| [37 World Model](37.md) | History, actions → future states/distributions | Physical-variable errors, probability calibration, multistep task losses | Memory, nonlocal interactions, observation correction |
| [38 Physical AI](38.md) | Embodiment, observations, goals → action effects | Tracking, contact events, feasibility, end-to-end time | Embodiment conditioning, local refinement, stable switching |
| [39 Pharmaceuticals](39.md) | Molecules/structures/experimental conditions → specified experimental endpoints | Separate structural and functional metrics; chirality and label consistency | Local structural enhancement, candidate/data selection |
| [40 Biology](40.md) | Control populations/intervention conditions → response distributions | Changes, population distributions, held-out donor/batch validation | Conditional representations; avoid blind capacity expansion with insufficient data |
| [41 Materials](41.md) | Periodic structures/conditions → energy, forces, or properties | Energy/derivatives/stress, periodic consistency, multifidelity bias | Geometric kernels, local and global interactions, reference-computation budgets |
| [42 Neurobehavioral Research Direction](42.md) | Behavioral/neural observations → events and conditional responses | Identity, events, real time, cross-animal/day generalization | Observation quality and temporal memory |
| [43 Signaling–Synapse Research Direction](43.md) | Sample baselines/conditions → signaling and functional endpoints | Endpoint-specific prediction, held-out batch calibration, experimental efficiency | Conditional models and active-experiment replay |

These define modeling targets, not the availability of real data. Retain probabilistic/empirical models for unidentified neural and biological mechanisms; do not force conservation equations merely to unify formulas.

## 4. Unified Experiment Records and Stopping Rules <a href="#section-004" id="section-004"></a>

For every evaluation, save the task-space contract, data splits, sampling/reconstruction, reference-solution accuracy, constraint sources, model configuration, actual degrees of freedom, optimization/tuning budgets, and tool calls. Report prediction-value errors, derivative errors, constraint residuals, and task outcomes separately.

Run strong simple baselines first, then add one SGD mechanism. Use multiple random seeds and subject/condition-grouped intervals, comparing quality–cost Pareto curves; explain parameter-matched and time-matched comparisons separately. Complete cost to reach equal quality is one primary decision criterion; do not force a single metric across all domains.

If the reference solution is insufficiently accurate, improve it first; if sampling is insufficient, prioritize observations; if learning is data-limited, do not first grow without bound; if solver costs yield no benefit, disable the implicit branch; if new experts harm old tasks or improve only training errors, reject them. Record negative results as well.

## 5. Implementation Sequence and Current Status <a href="#section-005" id="section-005"></a>

First select a practical task with available data and a corresponding small mathematical task, freezing inputs, constraints, solution/distribution targets, and cost. Second establish baselines and reliable error metrics. Third test fixed-graph/state versions, then individually validate local representations, budgets, or observation selection. Only fourth validate persistent growth and cross-condition transfer, and finally determine hardware optimization from measured workloads.

There is no requirement to implement all M01–M05 first or to start all seven domains simultaneously. Existing TC, neurobehavioral, and functional-experiment replay directions are candidate slices; specific priorities depend on data and validation conditions.

This round completes roadmap and mathematical evaluation design; it has not trained models or run these benchmarks. The overall architecture retains 72 top-level units; FN01–FN05 are task/numerical interfaces that existing units need to complete.
