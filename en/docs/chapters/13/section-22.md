# 20. Standard SGD-Net

The standard version should include:

- sparse `edge_index`;
- trainable SSM/Mamba;
- typed-edge GNN;
- soft/hard hybrid dynamic tree;
- multimetric posterior error;
- h/p/hp refinement;
- Lyapunov-style stability check;
- interpretable refinement logs;
- multitask output heads.
