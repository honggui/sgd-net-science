## 隐式求解与演化 <a href="#section-002" id="section-002"></a>

[机器可读 JSON](../../architecture/implicit_evolution_subunits.json)

| ID | 名称 | 输入输出或职责 |
|---|---|---|
| IM01 | 方程装配 | 模式、输入、冻结图/参数→R(z;u,θ,G)=0及维度 |
| IM02 | 初值和预条件 | 显式结果或合法历史快照→初值与预条件器 |
| IM03 | 有界前向求解 | 残差算子→近似解、迭代数、残差及终止原因 |
| IM04 | 残差与条件诊断 | 迭代轨迹→容差判定、数值状态与适用的误差界 |
| IM05 | 梯度接口 | 近似根、损失梯度→隐式或展开梯度及其精度记录 |
| IM06 | 接受与失败路径 | 近似解/诊断→接受、退回显式基线或 unknown |
| EV01 | 预测快照与创新 | 观测前预测＋后到结果→配对误差信号 |
| EV02 | 持续性/漂移诊断 | 多窗口误差与 QC→原因候选、置信与触发条件 |
| EV03 | 结构候选生成 | 原因与资源→分裂/增宽/加边/专家/不变等候选 |
| EV04 | 参数和状态迁移 | 旧结构→候选新参数、记忆、掩码与优化器状态 |
| EV05 | 局部训练与竞争 | 新结果与旧任务回放→父模型/候选性能比较 |
| EV06 | 稳定与等变审核 | 候选结构→结构、数值、对称性与任务证据 |
| EV07 | 持久接纳与监测 | 通过预定门槛的候选→新版本与退化监测 |
| EV08 | 修剪/合并/蒸馏 | 长期使用和效果记录→压缩版本或撤销候选 |

## 按需能力扩展 <a href="#section-003" id="section-003"></a>

[机器可读 JSON](../../architecture/generality_extensions.json)

| ID | 名称 | 输入输出或职责 |
|---|---|---|
| U01 | 有类型的计算图 | 区分数据图与算子图；Tensor/State/Control 边，shape/dtype、参数共享、分支/循环语义 |
| U02 | 全局关系与顺序 | 多头 QKV、逐行 softmax、因果/交叉掩码、位置编码、全局或稀疏连接 |
| U03 | 可寻址工作记忆 | 精确地址读写、内容检索、KV cache、栈/序列缓冲、生命周期与可扩容策略 |
| U04 | 稠密与离散原语库 | 目标模型所需激活、卷积、归一化、比较/选择、门控、张量重排 |
| U05 | 高阶与表示策略 | 点/边对/子图/超边的状态选择；标量/向量/张量及群作用 |
| U06 | 概率生成与目标库 | 自回归分布、噪声调度、采样、变分/对抗/价值与策略目标的专用配置 |
| U07 | 可调约束与执行语义 | 观测模式/修正模式；约束适用域；兼容路径不改目标输出；随机数和精度合同 |
| U08 | 构造导入与符合性检验 | 目标图/参数导入、算子覆盖、输出/梯度/状态差异、成本报告 |
