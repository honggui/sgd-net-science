## 1. 研究定位 <a href="#section-001" id="section-001"></a>

本方案将 SGD-Net 从“神经网络结构创新”扩展为“科研闭环智能体底座”。核心设想是构建 `SGD-Scientist`：一种面向材料、化学、生命科学实验闭环的多模态科研 Agent。

它不是单纯的聊天机器人，也不是单一生成模型，而是一个由三层能力组成的科研系统：

1. **SSM 长链路实验状态流**：记住从文献、假设、仿真、合成、表征到复盘的长期状态。
2. **GNN 多模态科研图谱**：表达材料结构、晶体拓扑、反应路径、实验设备、表征结果和论文知识之间的约束。
3. **动态树探索空间细化器**：对候选材料、工艺参数、实验路径进行自适应分裂、剪枝、回滚和局部精炼。

## 2. 一句话愿景 <a href="#section-002" id="section-002"></a>

> 让 AI 不仅“读论文、生成候选”，还能够像数值计算中的自适应网格一样，在真实科研空间中自动发现哪里值得继续细化、哪里应当停止、哪里需要回滚。

## 3. 目标场景 <a href="#section-003" id="section-003"></a>

### 3.1 材料自动生成与筛选 <a href="#section-004" id="section-004"></a>

典型任务：

- 固态电解质发现；
- MOFs / COFs 多孔材料设计；
- 催化剂活性位点筛选；
- 光伏/热电/储能材料优化；
- 高熵合金与复合材料配方搜索；
- 低维材料、二维材料与缺陷工程。

### 3.2 多模态表征闭环 <a href="#section-005" id="section-005"></a>

可接入数据：

| 模态 | 例子 | 图中表达 |
|---|---|---|
| 文献文本 | paper、专利、实验记录 | 知识节点、假设边 |
| 晶体结构 | CIF、POSCAR、空间群 | 晶格节点、周期边 |
| 仿真输出 | DFT/VASP、能带、DOS、形成能 | 物理属性节点 |
| 表征图像 | XRD、SEM、TEM、AFM | 谱峰/形貌节点 |
| 工艺参数 | 温度、压力、pH、前驱体比例 | 实验条件节点 |
| 湿实验结果 | 收率、纯度、稳定性、导电率 | 目标函数节点 |

### 3.3 自动化实验室 <a href="#section-006" id="section-006"></a>

系统可与机器人平台对接，形成如下闭环：

```mermaid
flowchart LR
    A[文献与知识库] --> B[假设生成]
    B --> C[候选材料/配方生成]
    C --> D[DFT/VASP/MD 快速筛选]
    D --> E[动态树选择下一批实验]
    E --> F[机器人合成]
    F --> G[XRD/SEM/电化学表征]
    G --> H[后验误差与模型更新]
    H --> B
```

## 4. SGD-Scientist 总体架构 <a href="#section-007" id="section-007"></a>

### 4.1 三层核心 <a href="#section-008" id="section-008"></a>

| 层 | 名称 | 功能 |
|---|---|---|
| 状态层 | `ScientificAgentStateTracker` | 记录长期科研任务状态、假设演化、实验历史 |
| 拓扑层 | `ResearchGraphEngine` | 统一表示材料、反应、设备、文献和实验约束 |
| 决策层 | `AdaptiveExperimentTree` | 根据后验误差进行候选分裂、剪枝、优先级排序 |

### 4.2 外围工具链 <a href="#section-009" id="section-009"></a>

| 工具/系统 | 用途 | SGD-Net 接口 |
|---|---|---|
| 文献检索系统 | 获取论文、专利、数据集 | 文献节点与证据边 |
| LLM / 科学模型 | 假设生成、代码生成、实验解释 | 语义状态输入 |
| VASP / Quantum ESPRESSO / GPAW | DFT 仿真 | 物理属性反馈 |
| RDKit / OpenMM / ASE | 分子与原子模拟 | 结构图输入 |
| XRD/SEM/TEM 分析工具 | 表征结果解析 | 多模态观测节点 |
| 机器人合成平台 | 自动执行实验 | 动作节点与执行日志 |
| ELN/LIMS | 实验记录与样品管理 | 数据闭环与审计 |

## 6. SSM 在科研 Agent 中的作用 <a href="#section-014" id="section-014"></a>

科研过程是长链路、非平稳、带反馈的序列过程。SSM/Mamba 可用于维护如下状态：

$$
h_{t+1} = A_t h_t + B_t u_t + \epsilon_t
$$

其中：

- $$h_t$$：当前科研项目隐状态；
- $$u_t$$：新的文献、仿真、实验、表征输入；
- $$A_t$$：任务阶段相关的状态转移；
- $$B_t$$：输入模态的选择性注入；
- $$\epsilon_t$$：不确定性与实验噪声。

与传统 RAG/Agent 相比，SSM 层提供：

- 更稳定的长期状态更新；
- 对超长实验日志的线性复杂度处理；
- 对阶段性研究目标的连续记忆；
- 与动态树的局部探索状态共享。

## 7. 动态树在 Active Learning 中的作用 <a href="#section-015" id="section-015"></a>

动态树可视为科研空间的自适应网格。

### 7.1 分裂条件 <a href="#section-016" id="section-016"></a>

节点分裂可由以下条件触发：

- 仿真预测不确定性高；
- 实验结果与预测偏差大；
- 文献证据互相矛盾；
- 某个候选接近目标性能阈值；
- 局部工艺参数敏感性强；
- 多模态数据存在冲突，例如 XRD 显示杂相但 DFT 预测稳定。

### 7.2 剪枝条件 <a href="#section-017" id="section-017"></a>

节点剪枝可由以下条件触发：

- 形成能明显过高；
- 合成窗口过窄；
- 毒性、成本、稀缺元素不满足约束；
- 多轮实验失败且不确定性下降；
- 与已知无效区域高度相似。

### 7.3 回滚与隔离 <a href="#section-018" id="section-018"></a>

对存在数据污染、仪器异常、样品混淆、仿真参数错误的分支，应执行隔离而非直接丢弃，保留可审计轨迹。

## 8. 后验误差定义 <a href="#section-019" id="section-019"></a>

材料任务中的后验误差可定义为：

$$
\eta = \lambda_1 \eta_{sim-exp} + \lambda_2 \eta_{physics} + \lambda_3 \eta_{uncertainty} + \lambda_4 \eta_{cost} + \lambda_5 \eta_{synthesis}
$$

| 误差项 | 含义 |
|---|---|
| $$\eta_{sim-exp}$$ | 仿真与实验偏差 |
| $$\eta_{physics}$$ | 违反物理、化学、晶体约束 |
| $$\eta_{uncertainty}$$ | 模型预测不确定性 |
| $$\eta_{cost}$$ | 成本、稀缺性、设备时间 |
| $$\eta_{synthesis}$$ | 可合成性、可重复性、安全性 |

## 9. 示例：固态电解质筛选 <a href="#section-020" id="section-020"></a>

### 9.1 目标函数 <a href="#section-021" id="section-021"></a>

目标：发现高离子电导率、宽电化学窗口、低界面阻抗、可合成、低成本的新型固态电解质。

目标函数：

$$
J = w_1 \sigma_{ion} - w_2 E_{barrier} + w_3 W_{stability} - w_4 C_{cost} - w_5 R_{toxicity}
$$

### 9.2 工作流 <a href="#section-022" id="section-022"></a>

1. 文献检索并构建候选化学空间；
2. GNN 根据已知材料图谱传播候选先验；
3. SSM 维护跨轮次实验状态；
4. 动态树将高潜力区域细分为掺杂、缺陷、合成条件子空间；
5. DFT/VASP 计算形成能、迁移能垒、带隙；
6. 机器人执行小批量合成；
7. XRD 判断相纯度，SEM 判断形貌，EIS 判断离子电导率；
8. 后验误差驱动下一轮分裂或剪枝。

- 边：配位键、孔道连通性、吸附位点、合成路线；
- 状态：吸附容量、选择性、稳定性、再生能耗。

- 后验误差综合 GCMC 仿真和实验吸附等温线。

## 12. 最小可行产品 MVP <a href="#section-027" id="section-027"></a>

### 12.1 MVP 范围 <a href="#section-028" id="section-028"></a>

- 只选择一个材料方向，例如固态电解质或 MOFs；
- 不直接控制机器人，先以“实验建议 + 数据回填”形式运行；
- 对接公开数据与本地仿真输出；
- 实现图谱构建、候选排序、动态树分裂、实验记录回写。

### 12.2 MVP 交付物 <a href="#section-029" id="section-029"></a>

1. 材料候选图谱构建工具；
2. 后验误差评估器；
3. 主动学习候选选择器；
4. 可解释实验推荐报告；
5. 失败实验剪枝与回滚记录。

## 13. 风险与治理 <a href="#section-030" id="section-030"></a>

| 风险 | 描述 | 缓解 |
|---|---|---|
| 数据质量 | 文献、实验记录、表征数据噪声高 | 建立证据等级与数据血缘 |
| 仿真成本 | DFT/VASP 计算昂贵 | 多保真代理模型 + 动态树局部加密 |
| 实验安全 | 自动化实验可能涉及危险化学品 | 人类审批、规则引擎、安全边界 |
| 幻觉假设 | LLM 生成错误科学假设 | 强制引用、图谱校验、实验可追溯 |
| 闭环过拟合 | 只在局部空间反复探索 | 不确定性采样与多样性约束 |

## 14. 与 SGD-Net 原理论的对应 <a href="#section-031" id="section-031"></a>

| 原理论 | 科研 Agent 对应 |
|---|---|
| FEM h-refinement | 候选材料/工艺参数局部细分 |
| BEM 边界约束 | 功能目标、设备、安全、合成窗口 |
| Lyapunov 稳定性 | 实验策略不发散，成本与风险受控 |
| 后验误差估计 | 仿真-实验-文献冲突驱动下一步 |
| 动态树剪枝 | 淘汰低价值或高风险探索区域 |
| SSM 状态演化 | 长周期科研项目记忆 |
| GNN 拓扑传播 | 多模态科研知识与物理约束传播 |

## 15. 结论 <a href="#section-032" id="section-032"></a>

`SGD-Scientist` 的关键不是“让 AI 一次性猜中答案”，而是让 AI 像自适应数值方法一样，持续判断科研空间中哪些区域值得加密、哪些区域需要剪枝、哪些区域需要重新测量。它将 SGD-Net 的理论优势从模型内部结构扩展到真实科研流程，是最具产业化想象力的方向之一。

## 16. 与双闭环控制的衔接 <a href="#section-033" id="section-033"></a>

根据 原始讨论材料（本包不附），`SGD-Scientist` 应从单纯的“后验误差驱动实验树”升级为“前馈预测 + 后验反馈”的双闭环科研 Agent。

| 控制模块 | 在科研 Agent 中的作用 |
|---|---|
| 前馈预测控制 | 根据历史实验和数字孪生，提前预测哪些材料区域可能出现高价值或高风险 |
| 后验误差反馈 | 根据真实仿真/实验结果修正模型，触发分裂、剪枝、隔离、回滚 |
| 控制仲裁 | 当前馈预测与真实反馈冲突时，以后验反馈为安全底线 |
| 来源监控 | 区分真实湿实验、仿真、文献、他人经验和模型预测 |
| 知识分类 | 将结果沉淀为经验、教训或待核实假说 |

科研 Agent 的控制循环可写为：

```text
predict next promising/risky regions
→ run simulation or experiment
→ collect multimodal evidence
→ compute posterior error
→ split/prune/isolate/promote/demote
→ update research graph and memory
```

## 17. 物理肉身与差分数字孪生 <a href="#section-034" id="section-034"></a>

`SGD-Scientist` 的成熟形态需要与 [SGD-Ecosystem物理具身数字孪生与双向流形折叠](15.md) 衔接。

### 17.1 物理肉身 <a href="#section-035" id="section-035"></a>

物理肉身包括：

- 自动化合成平台；
- 样品转移和管理系统；
- XRD/SEM/TEM/Raman/EIS 等表征仪器；
- ELN/LIMS 数据管理；
- 安全审批和人工接管机制。

这些设备不应只是外部工具，而应被封装为 `LabToken` 流，进入科研图状态。

### 17.2 差分数字孪生 <a href="#section-036" id="section-036"></a>

数字孪生用于在真实实验前做沙箱预演：

- DFT/MD/FEM 等高保真仿真；
- 代理模型和经验模型；
- 随机扰动注入；
- 多保真调度；
- 候选路径鲁棒性评分。

### 17.3 双向流形折叠 <a href="#section-037" id="section-037"></a>

当数字孪生预测与真实实验不一致时，不应只认为模型错了，也可能是数字孪生参数、边界条件或实验数据存在偏差。

因此应同时校正：

1. SGD-Net 内部动态树和科研图谱；
2. 数字孪生的物理参数和边界条件；
3. 实验数据的来源置信度和质量标签。

## 18. 知识状态管理 <a href="#section-038" id="section-038"></a>

材料科研中应显式区分三类知识：

| 知识状态 | 例子 | 动作 |
|---|---|---|
| 局部正确经验 | 某掺杂比例在特定温度窗口提高电导率 | 进入经验叶片，后续优先使用 |
| 局部错误教训 | 某烧结路线导致杂相或不可重复 | 进入反例禁区，后续阻断 |
| 待核实假说 | 文献提出但未复现实验的新结构 | 进入影子图-树，只在沙箱或低风险实验中使用 |

这能避免 Agent 把论文传闻、模型预测和真实实验混为一谈。
