## 1. 判断 <a href="#section-001" id="section-001"></a>

可以融合，而且三组材料有互补基础：SGD-Net定义可学习的时空结构内核；GLS研究区分模型预测、误差证据与动作执行；Aegis-X及HLO-OP-IR提供有界计算、数据生命周期和部署验证方法。建议将其收敛为 **SGD-Net-TC：拓扑与接触条件世界模型**，作为SGD-Net的研究变体，先研究跨手型操作，再验证向其他受约束动力学任务迁移的可能性。

但不能把“SSM＋GNN＋动态树＋JEPA＋安全门”再次组合就认定为新算法。SGD-Net旧稿已经提出大部分组件，外部也已有图记忆世界模型、图动力学、本体条件预测和自适应计算研究。新的贡献必须落实为可学习的状态变换、损失和决策规则，并通过直接竞争基线验证。硬件映射及审计合同有工程价值，但它们不能代替模型贡献。

推荐验证的中心问题是：**在本体不同、交互拓扑变化和算力受限时，模型能否迁移已有记忆，保持同一物理任务的动作语义，并正确选择增加计算、补充观测或停止当前候选？**

## 3. 哪些组合并非新的研究空白 <a href="#section-003" id="section-003"></a>

| 相关工作 | 已经覆盖的机制 | 对提案创新主张的约束 |
|---|---|---|
| Mamba、MaIL | 选择性状态空间、机器人模仿策略 | 用SSM替代Transformer本身不足以构成独创性 [^R01][^R02] |
| FACTS | 图结构记忆、路由与选择性状态传播的世界模型 | “图＋SSM＋世界模型”已有直接先例 [^R03] |
| Graph Network Simulator、EGNN | 图交互动力学与几何等变 | 图物理和等变也不是本项目首次提出 [^R04][^R05] |
| Scaling Cross-Embodiment World Models for Dexterous Manipulation | 以粒子状态/位移建立跨本体图世界模型和规划接口 | “世界模型统一不同手”已有直接竞争路线；已核验 arXiv v3 的表征与规划方法 [^R06] |
| GraphOp-WM | 与形态相关的结构算子及可复用动态基 | 形态与共享动力学分解已有先例；论文范围为相关机器人族的参数变化 [^R07] |
| GraspGraphNet | 显式URDF图、动态手—物边、原生抓取配置 | 本体图和动态边不能单独称为新贡献 [^R08] |
| CGP、T-Rex、RLDX-1 | 接触预测、触觉时序、多流与记忆 | 接触预测和快慢策略需要机制级对照 [^R09][^R10][^R11] |
| DPP | 人手/机器人关键点表示与视频迁移 | 中间关键点不等于新手型动态可执行性 [^R12] |
| V-JEPA 2、LeJEPA理论 | 预测表征、短程规划与有条件可识别性 | JEPA桥接需重新验证物理变量、误差及识别条件 [^R13][^R14] |
| Adaptive Computation Time | 让模型按输入分配计算 | 误差大就多算不能作为新机制的全部 [^R15] |

目前只能提出**候选组合贡献**，未证明文献首创，也未开展专利新颖性检索。R06 已补充核验 arXiv v3 正文的表征与方法部分；首轮实验前还需审核其完整实验协议和可用工件，避免绕开最接近的竞争方法。相关工作的“未描述某机制”不等于“确定没有该机制”。

## 4. 三种融合方案 <a href="#section-004" id="section-004"></a>

| 方案 | 内容 | 好处 | 代价与局限 | 判断 |
|---|---|---|---|---|
| A：外挂监督器 | 保持外部VLA，只增加SGD/GLS检查和记录 | 最快建立系统基线、可替换模型 | 主要是运行时贡献，未形成新的预测内核 | 必须作为对照与实施起点 |
| B：结构世界模型与动作分支共同训练 | SGD时空内核＋本体图＋接触预测＋有界细化，外部语言/视觉可冻结 | 能定位模型层收益，控制训练规模 | 需要真实动作/接触数据，机制耦合需消融 | **推荐研究主线：SGD-Net-TC** |
| C：从零训练全模态通用模型 | 自建VLM、视频世界模型、手策略、在线自进化和芯片 | 理论上控制全栈 | 数据/训练/验证预算巨大，难归因，尚无支撑 | 当前不选 |

方案B可以分阶段从方案A演进；研究成功也不要求替代优秀的预训练感知或语言模型。新模型应输出可检验的未来状态和动作，而不仅输出“证据字段”。

## 5. 候选创新收敛为三个可证伪命题 <a href="#section-005" id="section-005"></a>

**H1：图细化前后，记忆和任务输出的一致性约束能降低切换瞬间的预测跳变。** 原13号文档已有新节点状态初始化，但尚需定义限制/延拓算子、稳定实体ID和跨分辨率任务一致性。新提案学习状态迁移，并同时检查瞬间语义一致性和后续预测收益；无需假设每次细化都改善。

**H2：分解可计算误差、观测缺失和模型不确定性，比单一残差阈值更有效地分配推理预算。** 一个传感器遮挡无法通过多迭代凭空恢复真值。提案让预算器选择细化、增加候选、请求观测或结束候选，同时保留不可减少的动作检查与退化预算。收益必须在相同总计算预算下验证。

**H3：本体条件动作解码与短时接触预测的联合约束，比只对齐姿态更有利于新手适配。** 可迁移目标是任务相关的物体变化和接触效果，目标手仍需自己的运动学、传动、传感标定和控制器。联合损失可能减少不必要的适配数据，也可能增加训练冲突，不能预先承诺零样本。

H1不是单纯加一个图模块；H2不是取消固定预算的安全检查；H3不是把不同机械手强行映射到同一关节角。这三个命题与状态事务、编译预算形成共同设计，才是本提案值得试验的组合。

## 6. 必须先修正的概念冲突 <a href="#section-006" id="section-006"></a>

1. **三种拓扑不能混用。** 机械手连杆拓扑不能由预测器随意增删；当前接触边随物理状态变化；推理图细化只是表示分辨率变化。知识/任务图的边更不等同于因果边。
2. **三种时间不能混用。** 传感器物理时间、模型内部rollout时间和一次前向中的求解迭代分别编号。SSM不能因多算几步就把“想象”记成真实历史。
3. **状态变化不等于误差。** 旧稿的相邻隐状态差可能来自真实运动；在线残差必须对齐先前预测与当前观测。没有观测时只能估计不确定性。
4. **每步谱半径小于1不保证切换系统稳定。** 例如两个矩阵分别为`[[0,2],[0,0]]`与`[[0,0],[2,0]]`，各自谱半径为0，但交替乘积有特征值4。共同范数收缩等更强条件可限制内部递归，仍不证明机械系统安全。
5. **不能把所有节点都投影变小。** 关节测量、质量、能量和物体位置应保留物理单位；隐藏表示正则化与物理可行集合投影分别实现。
6. **图/SSM不天然满足全部对称性。** 时序scan沿时间运行，不能依赖任意节点编号顺序；机器人重力、关节轴和手性限制可用的旋转/反射对称性。
7. **稳定或保辛不能统一所有接触。** 摩擦、碰撞和耗散通常需要分段模式及外力输入，不能要求全局能量单调下降或全局辛结构。
8. **预算器不能降低必需检查。** 高风险时增加预测计算，反而可能挤占动作处理期限。最小检查与退化路径预留，预测超时则结束候选。

## 7. 当前前沿问题与覆盖边界 <a href="#section-007" id="section-007"></a>

| 前沿问题 | TC的拟解决机制 | 首轮能验证什么 | 首轮不能承诺什么 |
|---|---|---|---|
| 跨手型/少数据 | 本体图、任务效果接口和目标手解码 | 留出完整手型，适配曲线 | 任意手型零样本即用 |
| 接触与长时误差 | 多速率状态、接触预测与观测校正 | 固定短视界误差和滑移恢复 | 任意长序列成功 |
| 推理成本 | 分类型残差及预算选择 | 同质量时的延迟/内存/能耗 | 理论线性即实际高速 |
| 可验证执行 | GLS类型化误差与动作门 | 声明域下拒绝、退化和回放 | 高维全局物理安全 |
| 数据稀缺 | 预训练表征、人类示范、目标手少量适配 | 人类与机器人数据分别计费 | 合成数据等同真实接触真值 |
| 持续适应 | 状态估计＋窗口级受限参数/结构更新＋代际巩固 | 减少漂移且不增加回归 | 无限自进化或自动AGI |
| 科学计算 | 同类图/时间结构，更换物理头与约束 | 一个受控PDE/粒子域的独立实验 | 机器人权重直接用于神经科学发现 |
