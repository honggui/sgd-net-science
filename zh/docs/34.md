## 1. 首轮研究只回答三个问题 <a href="#section-001" id="section-001"></a>

第一，推理图发生细化后，学习到的状态迁移是否比复制、清零或重新计算更准确、更节省计算？第二，区分计算不足与观测不足的预算器，能否在相同端到端成本下改善任务结果？第三，本体图和任务效果表征，能否减少更换手型所需的数据？分别对应架构提案中的 H1、H2、H3。

这三个问题必须分别成立。模型成功不能自动归因于图细化，安全检查拒绝了大量动作也不能证明策略质量提升。应同时报告原始候选质量、检查后执行结果、拒绝率、完成时间与计算成本。

## 2. 基线与公平比较 <a href="#section-002" id="section-002"></a>

| 比较层次 | 必需基线或相关工作 | 控制变量与边界 |
|---|---|---|
| 原项目增量 | 忠实简化的原 SGD-Net：固定图、SSM、原误差反馈；逐项加入新机制 | 原设计尚无统一训练实现，必须保存实现取舍，不能把自建弱基线称为原模型实测 |
| 图与时序结合 | FACTS；同宽度 GNN+GRU、GNN+SSM、GNN+Attention | 同输入、训练数据与搜索预算；参数匹配和延迟匹配分别报告，不能互相替代 [^R03] |
| 跨本体世界模型 | Scaling Cross-Embodiment World Models for Dexterous Manipulation；GraphOp-WM | 前者是最直接的相关工作；后者公开摘要主要涉及形态参数变化，应区分肢体参数变化与全新手拓扑。无法复现时只做机制对照 [^R06][^R07] |
| 动作学习 | MaIL，以及可复现的点云扩散策略基线 | 同视觉编码器、历史窗口、动作空间与数据切分；视觉预训练数据差异单独披露 [^R02] |
| 接触与手型适配 | CGP、T-Rex、DPP、GraspGraphNet | 分别代表顺应控制、触觉多速率融合、人类示范迁移、图条件抓取；任务与传感器不同，不能混排成功率 [^R08][^R09][^R10][^R12] |

这里的“基线”分为直接运行、按论文重实现、仅机制对照三类。论文、代码、权重、数据及许可证必须逐项登记；有代码不等于具备完整复现条件。没有统一任务和评估协议，不声称击败“Top X”。

## 3. 数据切分：真正隔离跨手型泛化 <a href="#section-003" id="section-003"></a>

建议先采用三个训练手型、一个完全留出的测试手型；在仿真条件许可时轮换留出。测试手的几何描述和关节约束可作为输入，但其动作轨迹、接触标签、标定后的任务表现不能用于零样本训练或选模型。URDF 参数输入本身应明确计入允许的先验。

至少分开四种泛化：同手新物体、同拓扑新尺寸、删指或增加关节等拓扑变化、完整新手型。物体实例、任务组合及接触材质也应分别设置独立留出集。随机分割连续轨迹会泄漏时序与物体信息，不能用于证明迁移。

少样本阶段初拟使用 10、50、100 条示范，报告示范总时长、成功与失败占比、采集方式及调参次数，而不只报告条数。零样本、仅标定、适配解码器、适配全模型各自列结果；调整 IK、接触偏置、控制增益也必须登记。DPP 的“无需机器人示范”不等于无需人类数据、映射与控制设计。[^R12]

视觉、触觉、关节和电流数据保留各自时间戳、单位、缺失掩码和传感器版本。同步误差本身应成为压力测试变量；不能把插值后的高频序列当作实际高频观测。训练目标只使用当时可用的历史输入，未来观测仅用于离线监督和评估。

## 4. 消融与评价指标 <a href="#section-004" id="section-004"></a>

| 假设 | 最少消融 | 主要测量 |
|---|---|---|
| H1 状态迁移 | 清零、父节点复制、重新编码、仅重构损失、加入动力学一致性、加入动作读出一致性 | 同一物理时刻细化前后动作跳变；跨分辨率预测误差；额外计算；长时漂移 |
| H2 预算分配 | 固定步数；单一残差阈值；仅计算分配；加入补观测选项；完整分类预算器 | 相同时间/能耗预算下成功率；截止期违约；无效细化次数；补观测成本；检查与回退占比 |
| H3 跨手型语义 | 手型 ID；几何向量；本体图；仅原生动作；任务效果加原生动作 | 留出手零样本成功率；少样本学习曲线；不可达动作率；接触失效与物体损伤代理指标 |
| 接触预测 | 触觉只作输入；独立触觉预测；接触与动作效果联合监督 | 接触事件精确率/召回率、滑移预警提前量、标定误差及下游完成率 |
| 运行时保证 | 同一模型启用/关闭检查，先在仿真比较 | 危险候选检出、误拒绝、UNKNOWN 比例、干预率；不以检查后幸存样本掩盖策略失效 |

预测误差按位置、姿态、速度、力或接触状态分别报告，保留单位。不得把归一化加权和当成有物理意义的单一误差界。姿态使用适当的旋转距离；接触状态不平衡时不能仅报准确率。

初轮至少三个独立训练随机种子，按完整 episode 或物体/手型分组给置信区间；帧不是独立样本。先冻结主要指标、停止规则和超参预算，再看测试集。小样本未观察到事故不构成安全证明，仿真接触误差也不能被默认忽略。

## 5. 分阶段实施与退出条件 <a href="#section-005" id="section-005"></a>

**阶段 A：可控算例。** 使用带接触的低维质量—弹簧或刚体算例，获得可检查的参考状态。验证状态迁移、单位一致性、固定物理时刻的读出一致性、预算终止与回退。切换稳定性的反例、缺测与过期观测应在这里暴露。算例通过只证明实现符合预期，不能代替真实机器人验证。

**阶段 B：固定图离线模型。** 先训练共享时序骨干、动作解码器和世界模型，再引入细化与预算器。先证明世界模型比持有上一状态或简单运动模型更有用，并检查多步滚动偏差。不能让策略利用世界模型漏洞获得虚假回报；真实或独立仿真评估必须与训练世界模型分离。

**阶段 C：统一仿真跨手型实验。** 按第三节的留出协议测试 H1—H3。若复制状态与学习迁移无显著差别，保留简单实现；若固定预算更好，取消学习预算器；若新手收益只来自特定标定，收窄迁移结论。

**阶段 D：受控真机验证。** 在传感、执行、检查器和停止机制具备条件后，从低速、少任务开始，记录全部干预与失败。这里是后续研究门槛，当前文档不表示已具备真机验证条件。

**阶段 E：软硬件映射。** 算子图稳定后才提取真实轨迹，在通用 GPU/CPU 上建立参考，再进入 Aegis-X CModel、RTL 或板级评估。CModel 估算、周期模型、RTL 仿真与板上实测是不同证据等级。

研发周期取决于数据、仿真和人员条件，暂不承诺固定周数。成功门槛是至少一个假设产生可重复且有实际意义的收益，并且其额外成本可接受；统计显著与工程价值需要同时判断。

## 6. 首个可运行尺寸与存储核算 <a href="#section-006" id="section-006"></a>

建议从 batch=1、节点上限 128、边上限 1024、隐维 128、4 个时序块、预测跨度 8、最多 2 个候选滚动及 2 次图细化开始。均为可调整的实验上限。原生动作维度依据机械臂与手的实际自由度配置；如使用 32 维容量，不足时必须重新编译或显式拒绝，不能截断动作。边与节点溢出同样需要可见的降级语义。

以 BF16 缓冲估算：

| 对象 | 公式 | 大小 |
|---|---|---:|
| 单层节点隐状态 | 128 × 128 × 2 字节 | 32 KiB |
| 四层单轨迹状态 | 4 × 32 KiB | 128 KiB |
| 观测轨迹加两个独立候选状态 | 3 × 128 KiB | 384 KiB |
| 单份节点特征 | 128 × 128 × 2 字节 | 32 KiB |
| 单份边特征，边维 64 | 1024 × 64 × 2 字节 | 128 KiB |

以上不包含编码器激活、权重、优化器、梯度、双缓冲、索引、时间戳与细化映射。若保留全部预测步的中间状态，相关部分还会按跨度增长；流式滚动和重计算可以降低峰值，但会改变计算成本。此处为节点向量状态配置，若所选 SSM 使用额外状态轴，必须重新核算，不能照抄表格。

原 Aegis-X R1 文档给出的 12 MiB SPM 与 512 KiB SAFE 等属于设计规格；上述状态能否常驻仍依赖其他占用和并发调度。仅 1000 万 BF16 参数就约 20 MB，已超过 12 MiB，必须考虑分层加载或经验证的量化。SAFE 空间不是普通模型缓冲池。不得由理论 TOPS 推出端到端控制频率。

## 7. 映射到 Aegis-X 的边界 <a href="#section-007" id="section-007"></a>

| 模型工作 | 候选执行资源 | 必须测量或约束 |
|---|---|---|
| 编码、线性投影、动作/预测头 | Matrix 与 SRAM/DMA | 小矩阵利用率、权重搬运、激活峰值 |
| 时序更新、门控、归约 | Vector/Scan | 具体 SSM 状态布局和门控依赖；不能默认全部可并行扫描 |
| 图消息与聚合 | Sparse/Vector、分桶与有界索引 | scatter 冲突、度分布、索引带宽、排序及构图时间 |
| 图细化、P/Q 状态搬移 | Vector 与 DMA 配合 | 状态版本、有效掩码、最坏复制量、缓冲生命期 |
| 动作候选检查与提交 | 既有合同与独立检查路径 | 为检查、提交及回退预留时间；模型预算不能耗尽控制周期 |

在固定宽度与有界边数条件下，局部图传播可以控制规模；但线性层仍可能包含节点数乘隐维平方的代价，朴素邻居搜索可能是节点数平方。限制邻居数量不自动限制搜索成本。动态图构建和搬运必须纳入总延迟，不允许只测网络前向。

BF16 可作为初始神经网络精度；几何变换、关键归约、误差界和检查器是否需要 FP32 应通过数值实验决定。低比特量化需要重新评估预测区间与动作行为。现有面向特定解码场景的 TSPU 不能直接宣称支持图推理、流匹配或全部时序算子。

应为每次任务保留端到端 P50/P95/P99 延迟、最坏观测年龄、峰值内存、DRAM 字节数、节点/边峰值、候选数、细化次数与执行状态。候选世界模型状态和已提交观测状态必须分开；这可借鉴原数据面的 provisional/committed 思路，但两者的物理语义需要独立定义。

当前不建议为新模型增加专用硅模块。优先补充编译器和运行时的有界图、掩码、状态版本、候选隔离与预算统计；只有实际轨迹证明持续瓶颈，才讨论硬化。

## 8. 向科学研究迁移的第二条验证线 <a href="#section-008" id="section-008"></a>

可选用粒子系统或 PDE 网格细化来验证 H1：细化前后保留物理场、守恒量和边界条件，比较误差—成本曲线。图模拟器已经是明确先例，不能将“图网络模拟物理”作为新贡献。[^R04] 与灵巧手可以共享状态迁移原则，但应使用不同数据、损失与评价协议，不承诺共享一套权重。

对项目中神经行为研究者、信号突触研究者相关研究，当前能提出的是方法层面的助益：将观测残差与模型误差分开记录；为多尺度模型保存可追溯状态迁移；在固定算力下比较补观测与细化计算的价值。具体学科对象、可用数据与现有实验平台尚需对应到相关领域研究者的实际课题后确定，不能从模型提案推出已改善其科研结果。

分子任务需要处理手性，不能无条件使用反射不变表示；生物或神经时序的预测关联不能直接称为因果机制。耗散、碰撞和摩擦系统也不能仅凭“辛结构”标签声称保持正确物理。这些边界应在复用 JSBO 时保留。
