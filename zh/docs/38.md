## 1. 最小任务与模型边界 <a href="#section-001" id="section-001"></a>

从固定机械臂、若干手型的短时抓取/接触调整开始。输入视觉、关节、触觉、目标与本体描述，生成原生动作，并预测其效果。世界模型提供预测，策略提供候选，局部控制器执行；三个功能分别评价。

保持真实本体图、动态接触图与推理细化图三种结构。细化物体表面采样点不能增加真实手指，也不能改变执行器自由度。新手型既要有几何描述，还要明确控制模式、关节限制、传感器和时间延迟。

初始维度沿用 N≤128、E≤1024、d=s=128、4 块、H=8；最多两个候选和两次表示细化。原生动作维按机械臂加手的实际自由度配置，padding 配合动作掩码；不适配的控制模式应拒绝而非截断。

## 2. 可训练单元与控制单元 <a href="#section-002" id="section-002"></a>

在 WM 配置上启用 E03/E04、F03—F08，并接 H03—H08。B04 增加触觉/关节分支，B06 增加本体条件。E07 可在多模态策略实验中替换直接动作分布头；首轮不用 D08。

| 本域单元 | 基础单元 | 输入→输出与细节 |
|---|---|---|
| TC01 本体编码器 | C02、B03/B06 | 连杆、关节、限位和控制模式→本体节点及条件 |
| TC02 接触观测器 | B04、C03 | 触觉/相对几何→接触区域、有效性、滑移特征 |
| TC03 任务效果头 | E03 | 目标与当前状态→物体位姿变化/可行接触效果 |
| TC04 原生动作解码 | E04 | 效果、本体、状态→关节目标/力矩等选定模式的动作块 |
| TC05 接触世界模型 | E01/E03 | 动作、物体、本体→未来状态及接触分布 |
| TC06 局部触觉修正 | B04、E04、H05 | 新触觉与未提交动作后缀→受限修正 |
| TC07 候选规划器 | F03/F08、E08 | 候选动作与滚动代价→选中候选和预测理由 |
| TC08 独立执行接口 | H03—H06 | 已检查动作→控制器 ACK、执行状态；不是可训练层 |

原生动作字段必须固定物理含义。位置目标、速度目标、阻抗参数和力矩不能混用同一个未标记向量。首版优先使用已有低层控制器支持的一种模式。

## 3. 一次控制周期如何运行 <a href="#section-003" id="section-003"></a>

新事件到达后同步身份和时间，更新一次真实时序记忆。TC03/TC04 生成候选，TC05 在独立快照中滚动，TC07 依据任务、可达性和预测风险排序。F03 可选择局部图细化，但 H03 保留检查及回退时间。最后由独立检查与控制器接收动作。

动作块分为已提交前缀和可修改后缀。TC06 不能撤销已执行前缀；改变后缀需新版本和有效期。需要更高频触觉时，必须有真实传感器与时间戳支持，插值不会产生新信息。

策略与世界模型联合训练时，可增加效果一致性项：世界模型预测的物体效果接近目标效果。但需独立环境验证，防止策略利用世界模型错误。预测低方差不是安全证书；无足够边界信息时检查结果为 unknown。

## 4. 训练目标与数据准备 <a href="#section-004" id="section-004"></a>

核心损失为动作模仿或动作分布 NLL、未来物理状态 NLL、接触分类、效果误差与当前细化读出一致性。加入 P/Q 的共同尺度动力学损失，避免粗细坐标直接逐节点相减。未测触觉位置不作无接触标签。

先混合已知本体训练，完整留出新本体。分别测试新物体、同拓扑尺寸变化、拓扑变化、全新手型。零样本允许的 URDF/校准先验事前规定；使用新手示范、控制参数调优或接触偏置调整后归入相应适配档。

构建顺序：固定感知和低层控制器→训练固定图世界模型→训练动作解码→联合效果监督→粗细表示和状态迁移→离线收益预算器→受控闭环评估。第一轮仿真数据先覆盖动作结果与失败，不能只收成功示范后声称有风险识别能力。

接触/顺应控制可参考 CGP，异步触觉融合可参考 T-Rex；它们的传感器与控制假设需要独立核对。[CGP](https://arxiv.org/html/2603.05687v1)、[T-Rex 官方仓库](https://github.com/ZhuoyangLiu2005/T-Rex)

## 5. 公平对比与交付 <a href="#section-005" id="section-005"></a>

直接相关基线包含跨本体粒子世界模型，其状态与动作共享接口已有明确先例。[Scaling Cross-Embodiment World Models](https://arxiv.org/abs/2511.01177) 同任务还需固定图策略、仅本体 ID 条件、无触觉、无 P/Q、固定推理步数等消融。

分别报告原始候选有效率、检查后成功率、拒绝/干预比例、物体失稳或损坏代理、迁移数据曲线、任务时长及延迟尾部。检查器过滤大量错误候选后得到的成功率不能单独归因于策略。

先验证低维算例和仿真，再用实际平台协议进入真机。保存每次观测、候选、图版本、动作单位、提交前缀、控制器反馈和失败原因。向移动机器人、软体机器人或装配扩展时，重建本体/接触/动作模型，不只增大节点数。

局部闭环按 L01—L08 接入 CLF/CBF、输入/扰动预算及接触切换检查；松弛、不可行和采样延迟必须显式处理。 L01/L08 记录适用性、假设及证据；数学与单元接口见 [44 李亚普洛夫稳定性详解](44.md)。这是待实现设计，不是稳定性验证结果。


## 数学任务合同与扩展优先级（2026-09-12） <a href="#section-007" id="section-007"></a>

连续状态与离散接触模式分开评估；同时报告跟踪误差、约束违反、接触事件时刻及真实截止期。冲击附近不默认光滑，隐式残差需结合求解条件，不以较小单步残差替代闭环安全验证。

采用 [48 号数学评估](48.md)区分表达、学习和数值求解能力；按 [49 号任务卡](49.md)先做固定结构基线，再加入证据支持的单项扩展。无需先模拟其它模型的完整计算。
