## 1. 两种数据对应两种模型 <a href="#section-001" id="section-001"></a>

横截面/破坏性测量任务输入对照群体、细胞类型、供体、批次和干预条件，输出处理后群体分布。不存在天然的逐细胞时间配对，因此不能将两份数据的相同行号作为前后状态。

若有真实纵向成像或追踪数据，可另建实体时序版本，输入同一可追踪实体的历史，输出后续表型。两种任务可共享编码器设计，训练目标和状态管理分开。

scGPT 是多组学及扰动表征的相关基线；独立研究提醒，在部分扰动任务中复杂模型尚未超过线性方法。因此以任务收益决定是否启用图、SSM 和更大预训练模型。[scGPT](https://www.nature.com/articles/s41592-024-02201-0)、[扰动预测基线研究](https://www.nature.com/articles/s41592-025-02772-6)

## 2. 组件与本域单元 <a href="#section-002" id="section-002"></a>

横截面版选 B03/B05/B06/B07、C01/C02/C08、D01/D02/D03/D06、E02/E06/E08、F01/F02、G01—G03/G05/G07/G08；B01 在有配对形态时启用。C03/C05/D07 只服务真实空间邻域，不给任意基因嵌入附加物理坐标。D04/D05 初版关闭，D08 关闭。

| 单元 | 对应基础单元 | 输入→输出与限制 |
|---|---|---|
| CELL01 测量编码 | B05、A05 | 原始计数/深度/QC→细胞表示；保留库大小与缺失语义 |
| CELL02 条件扰动编码 | B06 | 干预类型、目标、时间、条件→干预向量；未见目标有独立测试 |
| CELL03 基因/通路图 | C01/C02、D02/D03 | 经审查先验与表达特征→通路上下文；边带来源和置信度 |
| CELL04 对照群体汇聚 | E08 | 匹配条件的对照细胞集合→群体上下文及组成 |
| CELL05 条件响应模块 | D06、E06 | 对照上下文、细胞类型、扰动→处理后表示或分布参数 |
| CELL06 测量分布解码 | E02 | 处理后表示→基因计数/表型分布；统计模型依测量而定 |
| CELL07 空间/谱系扩展 | C03/C05、D07或D04 | 真实空间或谱系/纵向记录→空间作用或时序信息；分别配置 |
| CELL08 变化与功能评价 | G07、E06 | 预测/实测群体→差异、功能终点及校准报告 |

基因图、细胞空间图和谱系图具有不同节点身份与边含义。多尺度桥接需显式定义基因到细胞汇聚及细胞到组织统计，不把不同对象简单放进同一个邻接矩阵。

## 3. 最小前向与概率目标 <a href="#section-003" id="section-003"></a>

初始版固定一套由训练数据/先验确定的基因面板，例如 2048 个基因，记录未覆盖范围；每个条件批次可采 64 个细胞，d=128、4 个非几何图块。它们是调试尺寸，不是生物学充分性条件。以稀疏基因图分块，内存与 batch 大小实测。

CELL01 编码每个细胞；CELL04 聚合匹配对照群体；CELL02 加入干预；CELL03/CELL05 建模基因/通路条件响应；CELL06 输出处理群体的测量分布。无配对标签时，以集合或分布层面对齐，不逐行最小化前后细胞误差。

计数头的一种候选为

$$
Y_{cg}\sim\operatorname{NB}(\mu_{cg},\theta_g),\quad
\mu_{cg}=\ell_c\,\operatorname{softmax}_g(f_\theta(z_c,u,c))_g,
$$

其中 $$\ell_c$$ 为库大小/深度条件，$$\theta_g>0$$。这只是归一化计数模型选项；若需要预测绝对 RNA 含量，应另有测量及模型，不能由固定库大小输出推断。是否采用零膨胀由数据评估决定。

损失可包括测量 NLL、群体均值/分布距离、相对对照变化、受支持的功能终点。分布距离与均值相似不保证单细胞机制正确；无额外识别条件时不输出因果网络证书。

## 4. 训练流程与防泄漏 <a href="#section-004" id="section-004"></a>

先建立对照均值、细胞类型均值、线性/低秩扰动模型，再训练冻结组学特征的条件头；随后加入图先验，最后比较有无预训练与分域微调。真实纵向版本才引入 D04/D05，并按实体更新时间，不按伪时间排序当作真轨迹。

切分单独覆盖供体、批次、干预目标、未见组合与细胞类型。预处理、基因面板选择、归一化和批次校准仅在训练/允许的适配集合拟合。不能把测试处理结果用于批次对齐后宣称零样本预测。

若某条件只在一个批次出现，批次与处理效应可能不可分；模型复杂度不能修复设计缺陷。需报告该限制，而不是用去批次算法强行输出确定处理效应。

## 5. 评估、消融与下一层扩展 <a href="#section-005" id="section-005"></a>

报告相对对照变化、关键基因/通路、差异表达、群体分布和功能终点，另列全表达相关性。后者可能由大量不变基因主导。置信区间按供体/实验重复或条件分组，细胞数不能直接当独立生物重复数。

消融：无图、随机先验图、无条件编码、去掉批次输入、冻结特征对比微调、简单统计对比完整模型。空间分支要在独立切片/样本上验证；图注意力与边权不自动解释为基因调控作用。

向组织模型扩展时增加细胞组成、空间邻域、组织测量和对应标签；向蛋白层扩展需独立测量桥，不能从 RNA 直接假定蛋白活性。可为 [43 信号突触研究方向](43.md) 提供组学子模块，但不自动迁移整个细胞模型。

交付为数据模式、计数预处理、条件编码规则、先验图版本、分布头、训练/校准与跨条件报告。最小接受条件是在冻结任务上超过简单基线且改进与干预变化相关；未达到时保留简单模型与数据闭环。

## 数学任务合同与扩展优先级（2026-09-12） <a href="#section-007" id="section-007"></a>

区分细胞群体分布映射与单细胞真实时间轨迹；横截面观测不自动确定动力学。使用扰动/供体外切分、差异表达与分布指标，无法辨识时优先补观测或调整假设。

采用 [48 号数学评估](48.md)区分表达、学习和数值求解能力；按 [49 号任务卡](49.md)先做固定结构基线，再加入证据支持的单项扩展。无需先模拟其它模型的完整计算。
