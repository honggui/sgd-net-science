## 1. 先分开性质模型、动力学模型和生成模型 <a href="#section-001" id="section-001"></a>

性质模型输入晶体结构与条件，输出能量、应力或指定属性；动力学模型进一步预测真实时间演化；生成模型按目标产生结构候选。三者共享周期几何与元素表示，但损失、状态与验证不同。

首版建议构建现成势函数/材料模型上的窄域增强与候选筛选，先确认数据和误差来源。MatterGen 可作为条件晶体生成基线，UMA 可作为原子性质模型基线；不从头同时训练两套模型。[MatterGen](https://www.nature.com/articles/s41586-025-08628-5)、[UMA](https://arxiv.org/abs/2506.23971)

## 2. 组件和领域单元 <a href="#section-002" id="section-002"></a>

启用 B03/B06、C01/C02/C03/C05/C06/C07/C08、D01/D02/D03/D06/D07、E05/E08、F01/F02/F08、H01。静态势能版 D04/D05 关闭，E07 为生成扩展，F04 先使用 candidate 模式。不能为了动态树把一个真实原子直接拆成两个原子。

| 单元 | 基础映射 | 输入→输出及内部责任 |
|---|---|---|
| MAT01 周期结构编码 | A02、B03、C06 | 晶胞、分数坐标、元素/占位→周期原子图 |
| MAT02 周期邻域 | C03/C06/C08 | 晶体与截断半径→含平移映像的边和包络 |
| MAT03 几何交互块 | C05、D02/D07 | 周期相对向量→等变/不变表示 |
| MAT04 能量/属性头 | E05/E08 | 原子表示→广延能量或独立强度属性 |
| MAT05 力/应力接口 | E05、H07 | 可微能量→坐标/应变导数，单位与符号约定 |
| MAT06 结构候选头 | E07或H01 | 组成/目标条件→晶胞与原子候选；初版可用外部生成器 |
| MAT07 多保真修正 | B06、F02/F03 | 低保真结果、计算设置→高保真预测和偏差估计 |
| MAT08 工艺/实验读出 | E06、G08、H02 | 结构与工艺记录→指定实验属性/后续测量建议 |

MAT08 只在有结构—工艺—测量对应数据时启用。零温结构预测不自动包含实际样品缺陷、相组成与工艺历史。

## 3. 周期几何与可微能量 <a href="#section-003" id="section-003"></a>

约定晶格列向量组成 $$L$$，分数坐标 $$s_i$$，则 $$x_i=Ls_i$$，边为

$$
r_{ij,n}=L(s_j-s_i+n),\qquad n\in\mathbb Z^3.
$$

边记录 i、j 和 n；小晶胞下可能有多个有效映像，不能只留下任意一个最近图像。整体旋转时 L 和坐标同步变换。邻居搜索使用物理截断，跨截断能量/力需要足够光滑的包络。

参考能量分解为 $$E_\theta=\sum_i\epsilon_\theta(h_i,c)$$，保守力为 $$F_i=-\partial E_\theta/\partial x_i$$。定义小应变使 $$L'=(I+\varepsilon)L$$ 并固定分数坐标，本文采用拉伸为正的参考应力 $$\sigma=(1/V)\partial E/\partial\varepsilon$$；对接数据源时必须验证符号、分量排序及压力约定。选择其他约定需在 adapter 转换。

要保持原始坐标和自动微分链路，不能将上游几何 detach 后仍声称训练能量导数；图离散邻域变化的连续性需单独检查。D07 的内部计算坐标只是表征路径，不能未经求解器定义当作结构弛豫步。

静态调试配置可用 N≤256、E≤4096、d=128、4 个几何块，batch 按显存调整；边溢出须提高上限或明确失败，不静默删邻居。训练力需要对能量梯度再反传，其成本超过一次前向，必须实测。

## 4. 训练与生成扩展 <a href="#section-004" id="section-004"></a>

数据记录元素、晶胞、坐标、能量参考、力、应力、计算方法/泛函、温压、收敛状态及来源。不同计算设置先分域或建显式保真条件，不能简单拼接当一致真值。

初版以能量、力和应力的有监督误差组成目标，按单位与有效标签分开权重；只预测属性时关闭无标签项。训练集确定归一化，测试按组成家族、结构原型和时间切分，同一轨迹相邻构型不跨两侧。

顺序：现成模型基线→仅训练属性/偏差头→允许时微调几何块→有限域动力学检查→主动选择高保真点。力模型不仅评估 MAE，还需检查弛豫、稳定积分、罕见构型和域外行为。

若加入生成分支，明确生成变量为元素类型、晶胞与分数坐标。类别生成与连续坐标目标分别定义；约束晶胞体积/有效性，去重后经独立计算验证。局部再生成必须重新检查全晶胞和长程条件。不能因模型自己预测稳定就计为新材料发现。

多尺度路线可以细化连续场网格或粗粒度计算表示；原子到粗粒子的映射必须定义质量、电荷与任务读出，往返损失只约束可表达信息。未定义该映射时关闭 F05/F06。

## 5. 评价与实际交付 <a href="#section-005" id="section-005"></a>

基线至少包含原始外部模型、简单偏差回归、固定保真筛选与随机/空间填充选点。消融周期特征、几何块、保真条件、主动选择和局部精化。

报告属性误差、能量/力一致性、稳定模拟失败、域外误差、计算调用量与候选独立通过率。热力学稳定性需在一致参考相集合与条件下评估；带隙、导电性、可合成性分别验证。

工艺优化应另接 MAT08，并以实验批次和样品为单位统计。交付包含周期图定义、单位/应力 adapter、训练配置、参考计算设置、候选去重和验证记录。是否值得 Aegis-X 加速由邻域搜索、几何算子、自动微分和工具耗时占比决定。


## 李亚普洛夫配置补充（2026-09-12） <a href="#section-006" id="section-006"></a>

对弛豫、积分器或误差选择适用 V/存储函数；热浴与外部驱动需供给条件，静态属性头不强制动态下降。 L01/L08 记录适用性、假设及证据；数学与单元接口见 [44 李亚普洛夫稳定性详解](44.md)。这是待实现设计，不是稳定性验证结果。


## 数学任务合同与扩展优先级（2026-09-12） <a href="#section-007" id="section-007"></a>

周期晶胞、结构和组成的空间与对称性单独声明。能量、力、应力及稳定性分别评估；选择需要导数控制的范数。跨网格/体系尺度预测应核对归一化和积分权重，不从原子数变化直接推出尺寸泛化。

采用 [48 号数学评估](48.md)区分表达、学习和数值求解能力；按 [49 号任务卡](49.md)先做固定结构基线，再加入证据支持的单项扩展。无需先模拟其它模型的完整计算。
