## 2. 先验—后验到底比较什么 <a href="#section-002" id="section-002"></a>

在新观测到达之前保存预测 `p⁻(y_t|history)`；到达后用同一实体、时间、模型版本的 y_t 计算创新或预测评分。若模型另有明确定义的状态更新分布，可得到估计后验 q⁺。模型自身先验与后验差异是更新幅度，不直接等于真实错误；两者可能共同错误。

建议同时记录：有效观测创新、预测 NLL/校准、先验/更新分布差异（仅在可比概率空间中）、约束违反、重复出现频率、域外提示、数据质量及实际任务失败。普通 SSM 校正后的 h 不是自动获得的贝叶斯后验；没有概率模型时使用“预测—观测差异”称谓。

先检查身份/单位/时钟、噪声、缺观测与标签质量。单次误差高不自动分裂；持续可重复且有容量不足证据才考虑生长。否则应校准、补观测、调用更高保真工具或保留未知。漂移阈值在实际数据分布上验证，不把在线树的理论界无条件移植到相关神经轨迹。

## 3. 八个内部演化单元 <a href="#section-003" id="section-003"></a>

| 子单元 | 基础父单元 | 输入→输出 |
|---|---|---|
| EV01 预测快照与创新 | F01/F08、D05 | 观测前预测＋后到结果→配对误差信号 |
| EV02 持续性/漂移诊断 | F01/F02 | 多窗口误差与 QC→原因候选、置信与触发条件 |
| EV03 结构候选生成 | F03/F04 | 原因与资源→分裂/增宽/加边/专家/不变等候选 |
| EV04 参数和状态迁移 | F05/F06/F08、G06 | 旧结构→候选新参数、记忆、掩码与优化器状态 |
| EV05 局部训练与竞争 | G01/G03/G05 | 新结果与旧任务回放→父模型/候选性能比较 |
| EV06 稳定与等变审核 | C07/C08、L03/L06/L08、G07 | 候选结构→结构、数值、对称性与任务证据 |
| EV07 持久接纳与监测 | G06、H04/H08 | 通过预定门槛的候选→新版本与退化监测 |
| EV08 修剪/合并/蒸馏 | F04、G05/G06 | 长期使用和效果记录→压缩版本或撤销候选 |

EV 是内部流程单元，不把它们重复计算为新增顶层网络层。完整研究路径必须定义 EV01—EV08；某一候选是否被接纳由证据决定。

## 4. 生长对象必须具体 <a href="#section-004" id="section-004"></a>

| 生长动作 | 真正改变的对象 | 初始化、保留与约束 |
|---|---|---|
| 树叶分裂 | 节点/子图的特征空间分区及局部专家 | 新叶先复制父专家，新增残差头零输出；之后训练分化 |
| 多树集成 | 独立路由/专家成员 | 用重采样或子特征差异构造多样性，记录成本；不是复制相同模型冒充集成 |
| 图表示细化 | 计算节点/边和分辨率 | P/Q 迁移全层 h/z；质量、坐标及边界按域规则处理 |
| 学习关系增删 | 带类型的候选消息边 | 边门控初值可为零；与不可擅改的化学键/本体约束分开 |
| 隐状态增宽 | s 或特征容量 d、局部 adapter 容量 | 新维初值零、交叉连接初值零；保持旧路径后渐进训练 |
| 专家块新增 | 局部 GNN/EGNN/SSM 专家或残差块 | 类型与输入输出兼容；新块初始近似恒等/零残差 |

零初始化只是一种降低突变的方法，不是普遍函数保持证明。LayerNorm 维度、softmax、门控分母、随机状态、求解器和下游读出可能随增宽改变，必须检查。新参数的优化器槽应新建，旧槽按映射复制；旧形状检查点不可直接加载新形状。

图节点从数据中识别到新实体的“出生”，与计算表示分裂是不同事件。真实原子、手指、细胞数量不能由容量优化随意改写。等变树分裂优先使用相应群下不变量，不按绝对 x 轴阈值路由后宣称旋转等变。

## 5. 四个时间尺度构成持续演化 <a href="#section-005" id="section-005"></a>

**事件级：** 使用新观测更新记忆和误差信号；这是在线状态适应，不是参数学习。

**任务内：** 在预留容量中调整计算树、路由或图分辨率，使用冻结权重和有界预算；这通常是临时推理适应。

**会话/窗口级：** 在与关键执行隔离的候选副本中，依据真实反馈训练受限 adapter、树阈值或新专家；按预先定义的验证条件可自动接纳并持久保存。它才属于在线持续学习的一部分，不要求每次更新都由人工批准，但不能绕过规定验证或修改硬约束。

**代际：** 对骨干扩维、跨域合并与大量结构变化，使用更充分回放、独立验证及重新编译。通过后发布新版本并监测；将有效慢路径蒸馏为快路径，低价值分支修剪。离线巩固是在线演化的补充，不是唯一形式。

明确区分可学习的校准/告警参数和不可由任务模型自由降低的安全根规则。旧 27 号中的“风险阈值可在线变化”只能在已声明适用范围内解释，不能成为为了提高通过率而放松硬约束的接口。

## 6. 接纳依据与自我评估偏差 <a href="#section-006" id="section-006"></a>

对结构候选比较

$$
S=\widehat{\Delta Q}_{new}-\lambda_C\Delta Cost-\lambda_F Forgetting-\lambda_V Violations.
$$

这只是候选排序指标。正式接纳仍要求旧任务不低于预定容限、独立新数据有收益、校准/等变/稳定/资源检查通过，不能仅凭加权分数抵消硬违反。新领域没有真值时可以更新状态或做自监督候选研究，但不能宣称能力已提升。

使用先预测后揭示标签的顺序评价、延迟标签对齐、旧任务回放和独立的影子比较。持续反复使用同一留出集会对它过拟合；保留后续新时间段或轮换验证，并记录模型选择次数。模型生成的伪标签与真实结果分别统计，避免自我认可闭环。

生长有上限，也必须允许不生长、合并与回退。触发阈值、证据窗口、最大叶数、状态宽度、更新频率、资源和发布容限都写入任务配置；当前没有数据，不伪造这些值已经最优。

## 7. 与隐式求解和李亚普洛夫的统一路径 <a href="#section-007" id="section-007"></a>

```text
观测前预测快照 → 真实结果 → 多窗口原因诊断
  → 有限显式/隐式重算或补观测
  → 若仍有容量不足证据，提出树/图/状态/专家候选
  → 参数与状态迁移 → 局部训练和父子竞争
  → 等变、稳定、旧任务、域外及资源验证
  → 自动接纳为新版本 或 丢弃候选
  → 运行监测 → 修剪、合并、蒸馏与下一轮反馈
```

数值求根慢不一定容量不足，不能自动触发生长；生长也可能让方程更病态。[45 隐式求解](45.md)要求固定一次求解内的图和维度；跨版本重建残差算子。L06 检查不同拓扑上的 V 可比性和切换预算，不能无限累积容差。

## 8. 领域应用与验证计划 <a href="#section-008" id="section-008"></a>

灵巧手可增长本体条件局部专家与接触计算表示；分子/材料可增长局部残差专家或合法粗细表示；细胞与信号模型可增长条件专家但不自动宣布新因果边；神经行为可增加会话适配器和互动模式专家。每域使用自己的标签、对称群和批次/主体隔离。

实验对照固定模型、只更新记忆、固定容量持续学习、只临时细化和完整持久生长，分别报告新任务学习、旧任务遗忘、容量曲线、每次接纳收益、误触发生长及成本。只有持久版本在后续独立实际数据上有可重复收益，才可声称实现了受验证的持续演化；分支数增长本身不是智能提升。
