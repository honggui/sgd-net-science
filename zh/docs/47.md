## 1. 判断 <a href="#section-001" id="section-001"></a>

本项目的主目标是：在明确任务、观测与资源条件下，获得可验证的预测、推理、生成或控制能力。无需先复现所有既有模型的完整计算方法。组件覆盖、可构造兼容和通用逼近都不能直接保证任务效果。

本文保留表达边界、反例和兼容构造，作为按需查询的附录；不再作为近期必须完成的模型实现路线。主路线见 [49 能力优先任务卡](49.md)，数学评估见 [48 函数空间与约束解空间](48.md)。

优先研究图与时序表示、真实预测误差反馈、局部适应和适用范围明确的稳定性。注意力、寻址记忆、高阶表示按任务瓶颈启用；隐式求解、广义几何和持久演化分别验证收益。原模型导入与逐算子兼容主要属于编译器/Aegis-X 工程需求，有实际迁移任务时再实现。

## 2. 五种通用性不能混称 <a href="#section-002" id="section-002"></a>

| 层级 | 意义 | 当前情况 |
|---|---|---|
| 接口通用 | 能调用不同模型并传递数据 | 已有设计接口；调用外部模型不等于本模型内部模拟 |
| 表达通用 | 架构家族能表示或按指定误差逼近目标函数 | 有潜力，但固定图/记忆/对称性配置存在限制，未证明全覆盖 |
| 计算通用 | 可表示顺序、分支、循环、状态和扩展存储 | 当前缺明确程序语义、可寻址存储与执行构造 |
| 学习通用 | 能通过给定数据/优化过程获得所需能力 | 没有保证；不同目标与数据要求不可省略 |
| 实用通用 | 同等质量下成本、样本需求与延迟可接受 | 必须逐任务实测，无法由表达能力推出 |

已有 Transformer 通用逼近研究也具有连续函数、输入域、序列与逼近度量等条件；不是一组固定权重学习所有任务的证明。[Yun 等](https://arxiv.org/abs/1912.10077)

理想化可计算性通常讨论可增长资源；任何固定有限精度、有限存储、固定截止期的设备都不能精确解决任意规模任务。动态生长允许调整资源上限，但不会消除资源需求。

## 3. 具体限制与反例 <a href="#section-003" id="section-003"></a>

### 3.1 图消息不自动具备全部图推理能力 <a href="#section-004" id="section-004"></a>

对无额外位置/身份/高阶特征、相同初始节点特征、共享一阶邻域聚合的配置，六节点环与两个互不连接的三角形中，每个节点都有两个同类邻居。逐层所有节点得到相同表示，六节点的同类池化输出也相同；但二者三角形数量不同。因此该配置不能完成这个区分。

这是受限消息传递配置的反例，不是对整个含外部工具的 SGD 系统的不可能性证明。GNN 表达力研究明确指出邻域聚合的限制。[Xu 等](https://arxiv.org/abs/1810.00826) 加大隐维或重复相同聚合不自动修复；需要结构特征、高阶关系、子图运算或其他计算路径。

### 3.2 固定状态无法无损保存任意长历史 <a href="#section-005" id="section-005"></a>

假设所有可用历史记忆共 B 比特、没有外部存储或重读输入，只将过去压缩入 SSM。长度 T>B 的任意二进制历史有 2^T 种，而记忆状态最多 2^B 种；至少两段不同历史映到同一记忆。若后续要求查询二者不同的某一位，模型无法对所有输入都精确回答。

这是有限精度的信息容量限制。无限精度实数状态的理论构造不能作为实际 BF16 芯片能力。需要可增长、可寻址记忆或允许重读，而不是只增加训练时间。神经控制器与外部可读写记忆已有研究先例。[Neural Turing Machines](https://arxiv.org/abs/1410.5401)

### 3.3 对称性和稳定性既有益也有限制 <a href="#section-006" id="section-006"></a>

严格旋转不变的标量头无法同时输出依赖固定世界 x 轴的任意标量；无位置编码的集合处理不能直接区分所有有序序列。相关输入条件可以改变任务的对称性，但必须显式定义。高维欧氏等变仍是一种特定约束，不等于无约束函数表达。

同样，强制所有内部更新压缩或所有物理状态 V 下降，会排除某些记忆、振荡、混沌或扩张动力学。44 号已经要求稳定性对象分层；通用模式应约束数值与执行条件，而不是任意改变目标模型的函数。不适用的 V 检查仍可记录为不适用，不强加投影。

### 3.4 当前“可选 attention”不足以构成 Transformer 兼容规格 <a href="#section-007" id="section-007"></a>

B07 的交叉注意力提及和 B02 的外部编码器接口，没有定义完整多头自注意力、因果掩码、位置编码、归一化、逐层残差、token logits 与 KV cache 的组合。现有 D03 的固定 sum/mean 也不是 QK 条件化的行归一化注意力。

### 3.5 生长、隐式与高维不自动补齐缺失原语 <a href="#section-008" id="section-008"></a>

树只能在它会构造的子单元空间内搜索；没有随机访问存储或注意力原语，就不能凭生长名称保证发现它们。隐式层还要求方程、求解与选择根的语义。更大状态、更深迭代和更一般度量扩大某些能力，但不能代替构造与验证。

## 4. 扩展建议：八个内部能力包 <a href="#section-009" id="section-009"></a>

U01—U08 为按需选用的内部能力规格，保持 72 个顶层 ID；不是八个已训练的新网络，也不是全部必须实现的清单。下表验证针对选中能力，不代表主路线的先后顺序。

| 能力包 | 父单元 | 选用时应明确的内容与接口 | 首个验证 |
|---|---|---|---|
| U01 有类型的计算图 | C01/C08、F04、H07 | 区分数据图与算子图；Tensor/State/Control 边，shape/dtype、参数共享、分支/循环语义 | 把小 MLP 原权重逐算子装配后比较输出 |
| U02 全局关系与顺序 | B02/B07、D02/D03、E08 | 多头 QKV、逐行 softmax、因果/交叉掩码、位置编码、全局或稀疏连接 | Transformer 块与顺序敏感任务 |
| U03 可寻址工作记忆 | D04、F08、H02/H07 | 精确地址读写、内容检索、KV cache、栈/序列缓冲、生命周期与可扩容策略 | 延迟复制、索引查询、长序列回读 |
| U04 稠密与离散原语库 | B、D06、F04、H07 | 目标模型所需激活、卷积、归一化、比较/选择、门控、张量重排 | CNN、LSTM、硬树逐层语义对照 |
| U05 高阶与表示策略 | C01/C05/C07、D02/D07/D08 | 点/边对/子图/超边的状态选择；标量/向量/张量及群作用 | 受限 GNN 反例、手性与张量输出测试 |
| U06 概率生成与目标库 | E02/E07、G01/G03 | 自回归分布、噪声调度、采样、变分/对抗/价值与策略目标的专用配置 | 小扩散、概率回归及策略目标复现 |
| U07 可调约束与执行语义 | L01—L08、H03/H04 | 观测模式/修正模式；约束适用域；兼容路径不改目标输出；随机数和精度合同 | 同权重兼容模式输出不被附加层改变 |
| U08 构造导入与符合性检验 | G07、H07/H08 | 目标图/参数导入、算子覆盖、输出/梯度/状态差异、成本报告 | 有界模型覆盖清单和逐项通过记录 |

U03 中模型工作记忆不同于 G05 的离线回放库，也不同于 H02 调用外部完整模型。读写规则可先确定性实现，学习寻址后续验证。单一摘要 token 或向量数据库近似检索不保证任意精确索引查询。

U05 不应强制所有图都使用高阶状态；代价可能随阶数迅速增长。增加节点 ID 可打破部分对称性，但要明确是否破坏任务要求的重标号不变性。高阶张量与更高坐标维 n 不是同一概念。

## 5. 如何构造已有模型，而非只说“能模拟” <a href="#section-010" id="section-010"></a>

| 目标模型族 | 构造路径 | 还需明确的限制 |
|---|---|---|
| MLP/残差网络 | U01/U04 配置线性、目标激活与残差；旁路图/时间/投影 | 默认 SiLU 不等于所有目标激活的精确替代 |
| CNN/U-Net | 网格与位移类型共享卷积核，或原生卷积；配置 padding/stride/skip/重采样 | 图消息可以表达局部线性卷积，不代表执行效率相同 |
| RNN/LSTM/SSM | 有序状态更新、相应门控与缓存；共享时间参数 | 当前简化对角 SSM 不是任意 LSTM 的原参数导入器 |
| Transformer/ViT/LLM | U02+U03 配置位置、QKV、掩码、逐层 FFN/归一化、logits 与缓存 | tokenizer、位置与数值语义必须匹配；外部 B02 调用不计内部兼容 |
| GNN/EGNN/高阶图 | 选择相应数据图、消息、归约和类型表示 | 一阶图不足以替代所有高阶图网络 |
| 树/随机森林/MoE | 比较路由、分支专家、采样/集成、top-k 与权重合并 | 森林集成与神经 MoE 的训练规则不同 |
| 扩散/流/VAE/GAN | 显式登记生成变量、调度/采样和所需网络/损失 | 输出一个噪声向量不等于完整生成算法 |
| 神经 ODE/DEQ/优化层 | 45 号方程、求解、梯度合同与固定版本 | 以求解容差/分布而非随意位级相等评价 |
| 核方法/近邻/概率图 | 核与支持样本、检索或因子消息及算法控制 | 需要显式样本/因子存储，不能都压进固定 SSM |

此表是可选兼容工程的候选覆盖范围，不是主模型开发要求，也不是现有支持清单。“所有模型”应被替换为版本化目标集合；新模型含未实现算子或新状态语义时，记录 unsupported，并扩展构造器，而非继续宣称覆盖。

### 5.1 Transformer 的可检查构造示例 <a href="#section-011" id="section-011"></a>

设 H 为有序 token 特征，在选定头中计算

$$
Q=HW_Q,\quad K=HW_K,\quad V=HW_V,
$$
$$
A=\operatorname{softmax}_{row}(QK^T/\sqrt{d_k}+M),\quad Y=AV.
$$

把 token 看作节点、允许注意的位置对看作边、A 看作边权，可以在图式计算框架中构造该操作。但必须有全局连接、逐行归一化、多头拼接及位置/掩码语义；这不是当前固定 sum/mean 的直接等价物。随后按目标顺序完成投影、残差、归一化和 FFN。[Transformer 原论文](https://arxiv.org/abs/1706.03762)

目标若使用其他位置编码、归一化或注意力变体，逐项导入其定义。等变几何分支关闭；稳定检查在不改变输出的诊断模式。训练 dropout 和采样按随机状态对齐。全连接注意力可能保留二次交互成本；不能因为使用“图”或“SSM”包装就宣称线性复杂度。

## 6. 能够证明到什么程度 <a href="#section-012" id="section-012"></a>

可尝试证明一个有限构造命题：给定目标模型的有限计算图，若每个原语、参数、状态更新、分支/循环及数值语义都有对应实现，则按相同依赖顺序执行，可由逐节点归纳建立整体语义对应。浮点舍入、近似原语、随机过程和求解容差需要单独纳入误差分析。

这证明的是规定模型集合的可构造兼容，不是新网络自动学会目标模型，也不是效率定理。若引入任意程序解释器，获得的首先是计算系统能力，不能将其包装成 SGD 学习算法本身的独创通用智能。

针对连续函数的逼近命题还需固定输入空间、函数类、误差度量和可增长的模型规模。连续神经网络不能在包含跳变点的连续域上任意精确地一致逼近所有不连续硬决策函数；精确硬树行为应使用比较/分支原语，或明确只在有限输入集合/适当分布误差下近似。

即使每个目标模型都有某个配置，也不推出存在同一组固定权重同时实现所有目标。需要任务条件、足够容量、训练数据和选择规则；自动发现适合的配置属于 46 号演化机制的额外研究目标。

## 7. 与现有核心如何共存 <a href="#section-013" id="section-013"></a>

**任务配置为主：** 从输入、输出、约束和误差度量直接构建模型。先建立固定图/状态的最小基线，再按证据选择等变先验、注意力、工作记忆、隐式精化或专家生长。每项比较质量与总成本，不要求从兼容模型开始。

**兼容配置按需：** 只有迁移已有权重或验证执行后端时，才按原算子、参数与状态构造目标模型，并避免附加操作改写语义。该工程成功不等于 SGD 学习机制创新，未实现兼容也不否定其任务能力。

动态树应在登记且可训练的候选子图中选择；扩大候选库必须同时计算搜索、训练、迁移与旧任务退化成本。无限时间和无限生长不属于实际部署条件。

## 8. 验证路线：能力优先，兼容测试按需 <a href="#section-014" id="section-014"></a>

1. 选一个真实任务及相应数学小任务，明确可观测信息、约束、解的选择规则、质量范数与资源预算。
2. 建立有可信参考解或冻结测试集的基线。区分观测/离散、表示、学习与数值误差，避免将所有误差归因于容量不足。
3. 每次增加一个对应瓶颈的能力，按相同数据划分和调参预算比较质量—成本；使用本文件的结构反例检查该扩展针对的限制。
4. 固定结构能力充分后，再比较局部精化、持久生长、回放与修剪的净收益，并检查长期遗忘和稳定性。

近期优先级由任务误差诊断决定。精确长时回读才触发 U03；全局关系/顺序瓶颈触发 U02；一阶图不可辨识触发 U05；多解或分布任务触发 U06。约束适用性 U07 应随任务明确。U01/U04/U08 的完整模型导入属于有需求才开展的工程支线。

若确有兼容任务，单独记录 model_id/version、支持原语、输入上限、精度、参数/状态映射、输出/梯度误差、未支持算子与成本。固定权重逐层比较可作为工程验收；不将其作为科学任务训练的前置门槛。

## 9. 研究主张与限制 <a href="#section-015" id="section-015"></a>

SGD-Net 的研究定位是按任务选择空间关系、记忆、约束与自适应计算的模型家族。核心假设是：以可信预测误差和成本反馈驱动结构或计算调整，能够在部分任务上产生可重复收益。该假设尚待实现和实验验证。

表达边界用于决定哪些能力值得补充；函数/算子空间与数值误差分析用于决定怎样补充。质量、可学习性、跨任务泛化和执行效率分别举证，不以模型模拟数量或组件数量代替。没有证据时，不宣称覆盖全部 AI 架构或普遍优于既有方法。
