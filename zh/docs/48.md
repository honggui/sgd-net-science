## 1. 结论与术语 <a href="#section-001" id="section-001"></a>

2026-09-13 补充：[图记忆、模型等价性与计算基础](../guide/mathematical-computing-foundation.md)将本框架用于 SGD-Net/Transformer 的任务与成本比较，并延伸到软件和芯片规划；区分持久图、压缩状态与参数记忆。

从函数空间、泛函分析和数值逼近角度评估模型是合理且更贴近任务的路线。架构规定了可选择的表示集合、交互方式、归纳偏置与计算算法；这些决定它对某类任务的表达效率、学习难度和数值表现。通用逼近只说明一定条件下存在足够大的近似器，不说明小样本可训练或成本可接受。

需区分：函数 f 将输入映到输出；泛函 J 将函数/轨迹映到标量，如能量或任务代价；算子 S 可将一个函数映到另一个函数，如“材料系数字段→解场”。所谓“泛函空间视角”在本文具体指函数空间、算子映射、约束集合和评价泛函的联合分析。

该思路已有神经算子和 DeepONet 等研究基础，不能把“从函数空间理解 AI”本身当新贡献。本项目的候选增量在于如何利用可信误差证据，选择局部表示、时间记忆、隐式计算或新观测。[神经算子](https://www.jmlr.org/papers/v24/21-1524.html)、[DeepONet](https://doi.org/10.1038/s42256-021-00302-5)

## 2. 将每个任务写成数学任务合同 <a href="#section-002" id="section-002"></a>

设输入 a∈X，输出 u∈Y。X/Y 可为有限维空间、L²、Sobolev 空间、轨迹空间、图上的信号空间或概率分布空间。条件 c 包括几何、本体、实验条件和边界。先定义

$$
\mathcal K(a,c)=\{u\in Y:C_j(a,u,c)=0,\;G_k(a,u,c)\leq0\},
$$
$$
\mathcal S(a,c)=\{u\in\mathcal K(a,c):F(a,u,c)=0\},
$$

或在合适任务中定义 `argmin_{u∈K} J(a,u,c)`。这些约束集合和解集合一般不构成线性空间，不能因为称为“解空间”就假设可以自由线性叠加。它们也可能为空、多解或对输入不连续。

只有在已声明条件下存在唯一解，或选定了明确解支，才将 S 当作单值解算子。多解/随机任务可以学习条件分布或集合，不能用一个平均解代替所有模式；平均值也可能不满足约束。

| 合同字段 | 必须回答 |
|---|---|
| 输入和可观测性 | 真实输入是什么？传感器/采样给了哪些量？哪些变量未知？ |
| X/Y 及正则性 | 有限维还是函数？平滑、分段光滑、含跳变还是随机？ |
| 约束与解选择 | 哪些是精确定律、哪些是近似先验？解唯一吗？ |
| 对称性与表示 | 置换、欧氏/流形变换、手性、周期边界如何作用？ |
| 误差度量 | 状态值、导数、事件、分布、约束或最终任务代价哪个重要？ |
| 分布和域外范围 | 哪些输入来自训练分布，哪些属于新参数/新条件？ |
| 资源与证据 | 采样、标签、算力、延迟和存储如何计费？参考解可靠到何种程度？ |

生物机制不完全已知时，只写有证据的测量约束和条件概率目标，不臆造完整 F 或统一能量函数。有限实验数据中的条件关联也不能自动升级为干预解算子。

## 3. 拟合、插值、外推和求解是四种问题 <a href="#section-003" id="section-003"></a>

拟合是在数据及损失下估计函数；插值要求经过指定样本；外推涉及未覆盖区域或不同条件；数值求解是计算所定义方程的解。它们可以组合，但不能互相替代。

例如在 x_j=j/m 采样，零函数与 sin(2πmx) 在所有采样点都相同。只给这些样本，模型不能判断哪个是真实函数；增加树叶或隐维不能自动找回丢失信息。需要额外正则性假设、频率限制或新观测。

带噪测量下精确插值可能拟合噪声；预测误差低也不表示导数准确。结构坐标或能量拟合良好，不自动说明力、应力和动力学正确。对于力 F=−∇E，必须评价适当导数范数或实际力误差。

因此，插值能力只是一种表达测试，不能单独作为智能、泛化或科研效用指标。训练数据量增加、采样变密、提高模型容量与延长求解是不同操作。

## 4. 误差分解：决定下一步应做什么 <a href="#section-004" id="section-004"></a>

设 P_h:X→X_h 为采样/观测离散化，R_h:Y_h→Y 为有界线性重构，S_h 为选定离散参考映射，Mθ 为学习器。部署输出是 R_h\widetilde MθP_h。对给定输入分布及相容范数，选择同一假设类中的参考参数 θ*，三角不等式给出

$$
\|S-R_h\widetilde M_{\hat\theta}P_h\|
\leq \underbrace{\|S-R_hS_hP_h\|}_{\text{观测/离散表示误差}}
+\underbrace{\|R_h(S_h-M_{\theta^*})P_h\|}_{\text{表示逼近误差}}
$$
$$
\quad+\underbrace{\|R_h(M_{\theta^*}-M_{\hat\theta})P_h\|}_{\text{学习与优化误差}}
+\underbrace{\|R_h(M_{\hat\theta}-\widetilde M_{\hat\theta})P_h\|}_{\text{数值实现/求解误差}}.
$$

上述把 R_h 提到差值外的写法要求它线性；非线性重构应保留各重构输出之差，再按需要使用 Lipschitz 条件估计。这里的范数例如 L²(μ;Y)，必须确保各项有定义、有限且在同一输出空间。θ* 可取最佳或近最佳近似器；该不等式是分析分解，不是四项已可在线测量的保证。学习项进一步分统计和优化误差需额外学习论假设；参考模型偏差、噪声与分布漂移也不能由这条式子自动分离。

随机系统或输入观测不足时，S 应改为适当的条件均值/分布/风险目标。不可约随机性与信息不足不应被错误归咎于模型容量。

| 主导误差的证据 | 候选措施 | 不应默认采用 |
|---|---|---|
| 采样不足、混叠或缺模态 | 增加观测、改采样/传感与重构 | 无限长推理 |
| 近似表示不足 | 增加局部专家、图分辨率、特征阶次或全局耦合 | 无条件增加所有模块 |
| 统计泛化不足 | 增加可靠数据、正则、域适配或降低容量 | 用训练集误差当泛化证据 |
| 优化不足 | 改训练条件、预条件或初始化 | 直接宣称架构不具表达力 |
| 求解/量化误差 | 调容差、精度、预条件或求解方式 | 凭小残差宣称物理正确 |
| 先验/模型失配 | 修订方程、约束、标签或条件变量 | 强制投影到错误可行域 |

神经算子/DeepONet 的误差理论已有专门研究，适用条件必须逐项检查，不能直接替代 SGD-Net 的分析。[DeepONet 误差研究](https://doi.org/10.1093/imatrm/tnac001)

## 5. 为什么必须评估条件数和残差可靠性 <a href="#section-005" id="section-005"></a>

对 A=diag(1,ε)、b=0，真解为 0。候选 x=(0,1) 的解误差为 1，残差为 ε；当 ε 很小时，极小残差仍对应大误差。一般“后验残差下降→真实误差同比下降”的说法不成立。

一个有条件的正例：在线性弱问题中，V 是 Hilbert 空间，a(·,·) 满足强制性 `a(v,v)≥α||v||²_V`，α>0；u 与近似 u_h 满足相同必要边界条件，误差 e∈V，残差 `r(v)=ℓ(v)−a(u_h,v)`。则

$$
\alpha\|e\|_V^2\leq r(e)\leq\|r\|_{V^*}\|e\|_V,
\quad\|e\|_V\leq\|r\|_{V^*}/\alpha.
$$

这说明残差所在的对偶范数、稳定常数、边界条件都重要。神经网络在有限配点上求的残差 MSE，并不自动等于 `||r||_{V*}`；还需离散化、求积与覆盖分析。非线性、非强制或多解问题需要不同的稳定/误差理论。

F01 应区分“有上界条件的误差估计器”“经验误差指示器”和“未知”；F03 才能据此选择生长或补观测。44 号的 Lyapunov 条件可以约束某些动态误差，但不普遍替代边值问题稳定常数或逆问题可识别性。

## 6. 从数学表示看各架构的能力 <a href="#section-006" id="section-006"></a>

以下是机制比较，不是统一排行榜；优势均依赖数据、目标类与预算。

| 架构/方法 | 主要表示与先验 | 常见适配问题 | 应检验的局限 |
|---|---|---|---|
| MLP/坐标网络 | 非线性复合函数族 | 有限维回归、连续坐标场 | 高频/局部奇异、导数误差、训练难度 |
| CNN | 局部共享核与多尺度层次 | 网格局部相关、图像/场 | 长程耦合、非规则几何、边界处理 |
| Transformer | 数据依赖的全局加权交互 | 非局部关系、上下文选择 | 采样/位置语义、交互成本、外推 |
| GNN/EGNN | 图局部作用及指定群下的函数子类 | 实体关系、几何物理、可变对象数 | 聚合表达力、信息瓶颈、错误对称先验 |
| SSM/递归模型 | 历史到状态的因果映射 | 长序列、衰减记忆、动态响应 | 有限状态的信息容量、刚性/长时误差 |
| 样条/有限元/核方法 | 局部基、试探空间或 RKHS 正则 | 小数据平滑问题、已知数值结构 | 维数、核/网格选择、非局部与复杂几何 |
| DeepONet | 输入函数编码与输出基函数组合 | 函数到函数的解映射 | 传感点、低秩结构、跨离散与误差条件 |
| Fourier/图神经算子 | 可学习积分核/谱表示的算子族 | 参数化 PDE、跨采样场预测 | 高频/界面、求积、边界与分辨率迁移 |
| 树/MoE | 分区后局部逼近与组合 | 异质、分段规律和不同工作区间 | 路由边界、连续性、稀疏数据过拟合 |
| SGD-Net | 图—时序—局部专家与自适应求解的组合类 | 混合结构、局部复杂和可获得反馈的任务 | 各组件误差与耦合成本；不天然优于上面所有方法 |

解集合可由少量模式近似时，低秩/基展开可能高效；移动界面、接触切换或复杂多峰解则可能需要局部分区或非线性表示。可测所需基数/容量随目标误差的增长；线性子空间的近似宽度不能直接当作任意非线性网络的下界。

比较应画误差—参数/有效自由度—训练样本—推理时间—内存曲线。单独比较参数量不公平：不同方法的参考计算、图构造、迭代、上下文和数据预训练成本不同。

## 7. 将 SGD 生长解释为自适应逼近，但不冒称有限元定理 <a href="#section-007" id="section-007"></a>

一种研究性的表示模板为

$$
\hat u(a,x)=\sum_{\ell=1}^{K}\pi_\ell(a,x)\,u_{\theta_\ell}(a,x),
\quad\pi_\ell\geq0,\quad\sum_\ell\pi_\ell=1.
$$

它描述局部专家的软组合；不要求所有 SGD 实例都使用该形式。硬路由可能在边界不连续，软组合也不保证守恒或满足约束。节点/专家数量不是唯一有效自由度。

- **h 类细化**：细化计算网格、区域或表示节点，配合 P/Q 状态迁移。它不增加真实原子或手指。
- **p 类增强**：增加局部基阶、特征/状态容量或更丰富局部算子。神经网络增宽只是类比，不等同有限元多项式升阶。
- **专家/字典扩展**：为不同物理模式或条件增加局部模型，并通过独立后验结果决定保留。
- **求解精化**：增加迭代、改预条件或精度，改善给定表示内的求解；不一定提高表示能力。
- **数据精化**：补充观测或可靠参考标签，解决信息不足；它不等于增加神经层。

经典 Galerkin 方法还包含弱式、试探/检验空间及稳定性等条件；没有这些定义，不能把图消息称为严格 Galerkin 离散，也不能继承其收敛阶。若有适用方程，可设计并验证一个具体的 Galerkin/混合子模块。

## 8. 真正需要补到模型里的五个内部接口 <a href="#section-008" id="section-008"></a>

不新增顶层单元数；以下落实到已有父单元。

| 内部接口 | 父单元 | 明确定义 |
|---|---|---|
| FN01 任务空间合同 | A01/A02/A06、L01 | X/Y、测量算子、约束、正则性、范数、适定性与目标 |
| FN02 采样和重构 | A07、B08、C04/C06、E08 | P_h/R_h、坐标、单元体积/求积权重、跨分辨率映射 |
| FN03 算子/查询读出 | D02/D03、E01/E05/E08 | 给定函数观测与查询位置输出场/轨迹；按任务加入局部或全局核 |
| FN04 残差质量与稳定因子 | F01/F02、L03/L04、IM04 | 残差范数、经验/可靠级别、条件数或稳定常数的来源 |
| FN05 误差—成本自适应 | F03—F07、EV02—EV08、G07 | 将候选动作映射到预期误差下降/代价，验证后再接纳 |

可用于场任务的消息形式为

$$
v'_i=\sigma\left(Wv_i+\sum_j w_j\kappa_\theta(x_i,x_j,a_i,a_j)v_j\right),
$$

w_j 为与离散采样一致的求积/体积权重。这为图消息与积分算子建立明确联系，但参数共享或增加权重本身不证明网格无关；还需核正则性、求积一致性、图支持域及跨分辨率误差验证。任意图的 mean 聚合不应自动解释成物理积分。JMLR 神经算子工作是该类设计的直接先例，不将这条形式主张为项目首创。

功能解释因此变为：GNN/EGNN 选择空间交互和对称函数子类；SSM 选择历史压缩；树选择局部表示；隐式层选择方程求解方式；Lyapunov/数值条件检查指定误差如何传播；后验闭环选择下一笔计算或观测投入。

## 9. 领域对应和理论目标 <a href="#section-009" id="section-009"></a>

世界模型评价条件轨迹/分布、预测跨度与闭环损失；物理 AI 评价跟踪、接触事件与可行性；分子/材料分开结构、能量、导数、属性和工艺终点；细胞/神经/信号任务关注群体或真实时序、条件变化、测量噪声与主体外泛化。没有必要将全部任务强行化成 PDE。

合理的第一批理论问题是：固定域和组件下的逼近误差；P/Q 在特定范数下是否稳定；已定义残差能否界定目标误差；局部细化是否改善误差—成本；时间/图切换误差是否可控；何时观测不足导致无法辨识。每个问题只针对明确配置，不一次证明整个 72 单元系统。

研究结论应以任务解集合上的误差和成本为中心。组件数学表达能力是基础，但只有与观测信息、约束适配、学习过程和数值稳定结合，才能判断能否解决问题。
