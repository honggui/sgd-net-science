# 5. 张量、状态和时钟合同

以单域批次为单位，B 为批量，N/E 为本批有效节点/边，d 为标量隐维，s 为 SSM 状态维，q 为向量通道数，H 为预测跨度。批内可使用 padding 或 packed 表示，但所有索引必须携带样本归属。

| 对象 | 形状/结构 | 语义 |
|---|---|---|
| 节点标量 h | B×N×d | 旋转不变的属性通道；几何模式下不直接装绝对 xyz |
| 向量 v、坐标 x | B×N×q×n、B×N×n | n 为所选欧氏坐标维度；3D 任务取 n=3；实测 x 与计算坐标 ξ 分开 |
| 边 | edge_index[2,E]、edge_attr[E,de] | 类型、样本、周期映像及有效性 |
| 记忆 z | 每块 B×N×s | 按稳定实体和物理时间维护；不是权重 |
| 条件 c | B×dc 或 B×N×dc | 本体、环境、任务条件；身份键不直接当泛化特征 |
| 预测 | B×H×N×dy 或域特定形状 | 均值/尺度/类别参数及掩码；不同头分开 |
| 状态包 | h,z,x,mask,IDs,versions | observation/candidate；物理时刻、rollout_step、refine_iter、generation_step |

实体退出后清理或冻结记忆，重新识别必须依匹配置信度决定是否复用。跨 batch、跨动物或跨样本不得共享残留状态。图节点重排应只重排输出，不改变预测内容。

静态配置令 D04/D05 关闭；可以在结构上重复 D02/D03/D06，但次数是空间消息深度。横截面细胞不按数据行号维护状态；分子序列由 B02 编码，不按原子索引模拟物理演化。

## 5.1 高维等变与广义几何：原路线的明确保留 <a href="#section-001" id="section-001"></a>

2026-09-12 核对补充：原 26 号文档已提出“高维等变＋非欧/多度量/准度量”的 G-GeoS 路线。本版前述 3D 应用示例不表示放弃这一范围。必须区分四个量：坐标维 n、标量特征维 d、向量通道数 q、约束数量 k；增加 d、q 或 k 不自动得到 E(n) 等变。

普通欧氏分支允许坐标属于 R^n；在标量特征满足不变性等前提下，使用 Q∈O(n)、b∈R^n 的共同变换 x→Qx+b，要求坐标输出同步变换，向量输出只乘 Q，标量输出保持不变。第 6.1 节的距离和相对向量公式可用于该 n 维欧氏分支。n 可取 2、3 或更高，并非原理上只能 n≥3；EGNN 原论文已明确支持高维空间，因此“3D 扩到 nD”本身不作为本项目首创。

非欧、Lorentz、混合曲率、准度量等不由更改 n 获得。D08 对这些分支要求独立声明空间、度量/配对、变换群、状态表示、映射与验证规则；不得把欧氏平方距离机械替换后继续沿用 E(n) 证明。准度量和非对称关系也未必具有相同的等距变换群。

建议配置字段为 geometry_mode、coordinate_dim、feature_dim、vector_channels、group_action、metric_type、signature、curvature、constraint_spec。欧氏高维分支主要落在 C05/C07、D02/D07；更一般几何落在 D08。分子、机器人和普通晶体仍以真实三维空间建模，高维属性保留其单位和变换语义，不能将温度、表达量、时间与 xyz 拼接后假设可任意互相旋转。

高维分支实施时增加 n=3 与 n>3 的置换、正交变换、平移一致性检查；非欧分支使用其声明的变换群和约束测试。n、q 改变后重新核算坐标、向量、几何归约及状态迁移成本。数学适用性不代表已有训练收益或硬件支持。
