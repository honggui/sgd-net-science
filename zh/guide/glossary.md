# 术语与阅读约定

| 术语 | 本书中的含义 |
|---|---|
| SGD-Net | State-space Graph-Dynamic Tree Network；此处不是随机梯度下降优化器的简称 |
| SSM | 状态空间模型；内部状态与真正隐式方程求解不同 |
| GNN / EGNN | 图消息传递与指定群作用下的等变图模型 |
| JEPA | 联合嵌入预测架构；潜表示预测不直接等于物理变量预测 |
| JSBO | 本项目讨论的 JEPA 到结构模型的候选桥接算子，尚待验证 |
| 隐式层 | 由方程或固定点定义输出，需要求解和有效梯度条件 |
| Lyapunov | 对指定状态、误差或参考轨迹分析稳定性的数学工具 |
| 观测创新 | 先前预测与随后配对观测之间的差异；不等于任意相邻状态变化 |
| 表示细化 | 改变计算表示，不等于增加真实原子、连杆或生物实体 |
| 候选版本 | 与活动版本分离的试验参数、状态或结构 |
| 领域单元 | 基础组件在某个任务中的配置或细化，不能重复计为顶层组件 |

顶层登记共 72 个单元；IM、EV、U、FN 共 27 个内部接口；七领域共 56 个领域单元。这些是设计数量，不是已经实现的神经层或工具数量。
