# 图记忆、模型等价性与数学计算驱动的软硬件规划

> 2026-09-13。对 SGD-Net 与 Transformer 比较的进一步修订。本文区分数据表示、学习模型和执行系统；提出研究合同及功能规划，不报告新的模型实验、通用性定理或芯片实现。已有顶层组件 ID 保持不变。

## 1. 修正：图也可以承载历史，SSM 不是唯一记忆 <a id="section-001"></a>

“图提供空间关系、SSM 提供历史”只适用于没有持久历史的简化配置，不足以描述完整 SGD-Net。更准确的分工是：**持久化时序图组织关系与历史；GNN/EGNN 在其上读取、推理和更新表示；SSM 提供可选的递归状态、压缩和动态预测。** 图结构未必具有几何，几何必须另由坐标、度量、类型与群作用定义。

| 记忆载体 | 可以保存什么 | 必要条件与限制 |
|---|---|---|
| 持久节点、边及属性 | 实体、事件、关系、状态快照、来源 | 明确写入与版本；当前邻接快照不自动保存过去 |
| 时间边与路径 | 事件顺序、状态转移、经历关联 | 时间方向、重复事件和身份必须定义；普通空间路径不等于历史，更不自动是因果链 |
| 节点/边递归状态 z | 任务相关历史摘要、动态响应 | SSM/RNN/门控均可；固定精度与容量通常无法无损保存任意历史 |
| 原始记录与索引 | 精确事件内容、按 ID/时间回读 | 必须实际保留记录；近似语义检索不保证精确查询 |
| 参数与结构更新 | 跨经历形成的规律和长期归纳偏置 | 学习与巩固另需数据及验证；不能当作逐条事件档案 |

时序图与记忆模块的组合已有直接先例，例如 TGN；不能把“图存储历史”本身当作新发明。[Temporal Graph Networks](https://arxiv.org/abs/2006.10637) SSM 也不是只能附着在 GNN 上的压缩器：它可独立建模序列、构成节点/边/全局动态状态；项目 D04 的简化实例不等于完整 Mamba。[Mamba](https://arxiv.org/abs/2312.00752)

一个反例：只保存“甲与乙当前连接”，无法区分“先连接、后断开、再连接”和“一直连接”。即使 GNN 足够深，输入没有保留的信息也不能由传播恢复。若每次事件变成带时间与来源的持久节点，两段经历就可以区分；是否能高效读出，还取决于索引与推理路径。

**更容易沉淀历史**应拆成三个命题：图可能更适合组织关系化经历；明确的检索可以让这些经历可访问；训练与巩固可能让经历转化为可泛化知识。第一项不自动证明后两项。

## 2. SGD-Net 的多层记忆合同 <a id="section-002"></a>

一种候选组织为：

$$
\mathcal M_t=(\mathcal G^{hist}_{\le t},Z_t,\mathcal R_{\le t},\theta_t,\nu_t),
$$
$$
z_{i,t}=\Phi_\theta(z_{i,t^-},\operatorname{Read}(\mathcal G^{hist}_{\le t},i),o_{i,t},\Delta t),
\qquad y_t=\Psi_\theta(q_t,\operatorname{Read}(\mathcal M_t,q_t)).
$$

Ghist 是持久历史图，R 是保留的原始记录，Z 是压缩状态，θ 是参数，ν 是版本闭包。Read 应声明精确索引、范围查询或近似检索。公式是系统组织模板，不意味着这些对象全驻留片上、全可微或已有实现。

在现有组件中分配责任：C01/C08 定义时序图 schema、类型和布局；C02/C03 的当前结构与历史事件视图分开；U03 定义模型可寻址工作记忆；H02 提供持久记录检索；D04/D05 进行状态预测与观测校正；G05/EV 负责回放与巩固；H08 保存操作证据。数据历史图、模型算子图和审计依赖图是三类不同对象，不能因为都叫“图”而互相替代。

建议的事件流程为：接收并标注来源 → 按保留策略写入事件/记录 → 对查询时刻可见的子图检索 → 更新图表示与可选 SSM 状态 → 输出带依据的结果 → 在独立候选版本中巩固、压缩或遗忘。观测前预测仍应先保存，再计算 D05 创新；候选想象轨迹不能回写为实际经历。

需要补齐的字段包括 entity_id、event_id、事件时间、系统接收时间、关系类型、来源、真实/预测标记、图/参数/状态版本、保留期限、索引模式及删除规则。事件时间与接收时间不同；“当时能够知道什么”的回放应同时满足当时可见性，而不是按后来补录的时间戳泄漏信息。此处只建议字段语义，不冻结二进制 ABI。

容量必须核算节点、边、属性、时间索引、原始记录、Z、参数、候选及临时工作集。若将任意 T 比特历史压入总共 B<T 比特的全部可用记忆且不能重读，至少两段历史会碰撞；把比特分布到拓扑中并不能绕过此限制。可增长图允许增长容量，但也增长存储、检索与维护成本。

## 3. 能否完成 Transformer 的任务：分层回答等价性 <a id="section-003"></a>

令 f 是有限输入域上指定的目标映射，H_S、H_T 分别为已指定资源与组件的 SGD/Transformer 函数族。讨论等价性之前必须固定输入信息、输出类型、历史访问、误差范数、精度与资源。

| 等价层级 | 可以说什么 | 不能推出什么 |
|---|---|---|
| 任务可替代 | 不同结构可能在同一任务达到要求误差 | 不需要中间张量相同；目前没有覆盖所有任务的实验 |
| 函数逼近 | 研究目标函数是否在给定函数族的闭包内 | 存在参数不等于有限样本能学到或成本合理 |
| 精确计算构造 | U02/U03/U04/U08 若完整承载目标算子、状态和顺序，可构造有限 Transformer 的对应执行 | 这是有条件兼容路径，不是当前已实现，也不是 SGD 主干独有优势 |
| 有限精度数值相容 | 按指定误差比较输出、梯度与状态 | 实数代数相同不自动给出浮点位级一致 |
| 学习与泛化 | 按任务比较样本、优化、域外风险 | 相同表达集合不等于相同优化或泛化行为 |
| 成本相当 | 在相同任务质量下比较时间、内存、能耗与训练摊销 | 能模拟不能推出高效；“通用”也不意味着全部负载最快 |

因此，答案是：**有可能完成许多 Transformer 能完成的任务；若完整实现兼容子集，还可按构造承载指定 Transformer；但固定局部 GNN+有限 SSM 的默认配置没有“所有任务覆盖”保证。**

有两个明确限制。第一，只有 k 层局部消息、没有全局边/读出/历史摘要旁路的节点，不能依赖图距离大于 k 的新信息；需要增加通信路径、层级、全局关系或迭代。第二，无身份/位置/高阶特征的一阶聚合可能无法区分某些不同图；加深或增宽不会自动解除结构不可辨识。[GNN 表达力](https://arxiv.org/abs/1810.00826) 长路径上的信息压缩还可能形成瓶颈。[Over-squashing](https://arxiv.org/abs/2006.05205)

Transformer 的通用逼近结果同样有连续性、域、位置编码、函数类与逼近度量等条件，不能升级为任意长度、有限资源下的全部问题求解保证。[Transformer 逼近研究](https://arxiv.org/abs/1912.10077) 将有限目标计算逐算子映射到更大系统的条件构造，也不证明一个固定参数模型同时解决全部任务。

## 4. 从拟合、插值与模拟理解两种架构 <a id="section-004"></a>

对模型族 H 和误差阈值 ε，可研究：

$$
e_{app}(f,\mathcal H)=\inf_{g\in\mathcal H}\|f-g\|_{\mathcal Y},\qquad
C_{\mathcal H}(\varepsilon;f)=\inf_{g\in\mathcal H:\|f-g\|_{\mathcal Y}\le\varepsilon}\operatorname{Cost}(g).
$$

空可行集时 C 为无穷；Cost 必须声明是参数、访存、时间还是加权指标。实际学习器还受观测、统计、优化与数值误差影响；表示误差不是总误差，详见 [48 数学评估](../docs/48.md)。

| 数学视角 | Transformer | SGD-Net 候选优势与局限 |
|---|---|---|
| 非局部数据依赖核 | 注意力按查询形成关系权重 | U02 可采用相同核；默认局部图更节省边，却可能漏掉远程作用 |
| 局部算子与组合 | 可通过掩码或训练表达局部关系 | 图结构直接指定邻域，适合实体局部作用；收益取决于图是否正确 |
| 对称函数子类 | 普通序列配置不自动保证物理等变，可另加结构 | EGNN 把表示限制到指定等变类，匹配任务时减少冗余；错误对称性会排除真解 |
| 历史函数 | 注意力访问显式上下文；读取仍非无损解码保证 | 图保留可查询事件，SSM 压缩任务状态；需支付存储与检索成本 |
| 分段或多尺度近似 | 可使用层级、专家或其他扩展 | C04/F/EV 可局部细化与专家分工；边界连续性、迁移与搜索成本需验证 |
| 插值 | 足够容量可能拟合有限样本 | 同样可能；谁的插值误差低不等于谁泛化更好 |
| 方程/动力学模拟 | 可学习代理或嵌入求解循环 | IM/L/领域头显式组织求解与约束；模型误差和稳定条件仍不可省略 |

自注意力与图消息有交集：注意力可看作在允许边集合上、由数据决定权重的消息聚合，GAT 是已有图注意力先例。[GAT](https://arxiv.org/abs/1710.10903) 但一般 GNN 的边 MLP、求和聚合、高阶状态与一个标准注意力层并不逐项相同；不能因此宣布两个模型族无条件相等。

有限样本 x_j 不能唯一决定未知函数：

$$
f_2(x)=f_1(x)+c\prod_{j=1}^{m}(x-x_j)
$$

在所有样本上与 f1 相同，在其他位置通常不同。两种架构都需要正则性、数据覆盖、结构先验或新观测来决定外推；更复杂的图不能凭空恢复不可识别的规律。带噪数据也不应把精确插值作为唯一目标。

函数到函数任务可以用采样、重构与算子族描述，已有神经算子研究是直接基础。[Neural Operator](https://www.jmlr.org/papers/v24/21-1524.html) 局部 PDE 的逆解算子仍可能全局耦合，例如椭圆边值问题；物理方程局部并不意味着固定少层局部 GNN 能准确得到全域解。可能需要多尺度、全局交互或迭代求解。

模拟任务还应评价导数、守恒误差、长期轨迹或分布。位置拟合好不自动意味着力正确；较小方程残差不自动意味着较小解误差，必须考虑稳定常数和条件数。混沌系统中逐点长期轨迹和统计量是不同验收目标。

## 5. 效率：从同等质量出发，而不是只比复杂度标签 <a id="section-005"></a>

标准密集注意力的交互约 O(T²d)，图消息可能为 O(Ed²)，SSM 状态更新以外还有投影、构图与读取；成本边界见[算子对比](transformer-comparison.md)。图变稠密、历史持续增长、求解迭代增多，都可能使 SGD 更昂贵。规则矩阵运算也可能比更少 FLOP 的不规则访问更快。

在限定工作负载与资源模型下，可用下列规划近似：

$$
t_{exec}\gtrsim\max(F/P_{eff},D/BW_{eff},t_{dep}),\qquad
E_{exec}\approx e_FF+e_DD+E_{control}+E_{idle}.
$$

F 为执行运算，D 为跨指定存储层的实际搬运字节，tdep 为依赖路径下限；有效速率与能量系数必须测量。该表达用于瓶颈分析，不是硬实时证明。[Roofline](https://www2.eecs.berkeley.edu/Pubs/TechRpts/2008/EECS-2008-134.html)

公平比较至少同时报告：任务误差、域外风险、约束违反率、训练数据与预训练来源、训练/搜索预算、端到端 P50/P95/P99、峰值全部状态、J/task、失败与退路。持久图和原始记录必须计入 SGD 内存；KV 与其他缓存也应计入 Transformer。外部检索与主机求解不能从账本消失。

## 6. 软件与芯片应从什么基础规划 <a id="section-006"></a>

需要从数学计算基础出发，但数学只是第一层。建议顺序为：**任务与可观测性 → 函数/约束/精度 → 表示与算法 → 数据结构和访问 → 编译计划 → 硬件原语 → 质量与成本证据。** 这种抽象方法有助于避免按模型名字堆硬件；还必须回到实际负载，否则容易得到功能很多却难以高效使用的设计。

软件应保留多层表示：任务合同；有类型模型/状态图；核与求解计划；布局/循环/通信；设备执行。每次降低层次都保留形状、轴含义、掩码、时间可见性、状态副作用、精度与失败语义。MLIR 提供了多层 IR 的已有基础，但采用框架不等于自动获得本项目所需语义。[MLIR](https://mlir.llvm.org/docs/Rationale/Rationale/)

| 数学/计算族 | 共同负载 | 功能规划重点 |
|---|---|---|
| 稠密收缩与投影 | FFN、QKV、消息 MLP、低秩映射 | GEMM/GEMV/batched matmul、累加精度和小矩阵利用率 |
| 稀疏关系与索引 | 图消息、稀疏注意力、历史检索 | gather/scatter、CSR/COO、分段边界、重复索引、布局转换 |
| 归约与非线性 | Softmax、归一化、概率与误差度量 | max/sum、exp/log、rsqrt、稳定计算与空集合规则 |
| 递推与状态变换 | SSM、滤波、前缀计算 | affine/associative scan、状态读写、时钟与版本；并非任意递归均可高效 scan |
| 可寻址持久记忆 | 事件图、KV、索引与回放 | 有界批量读取、追加/失效、分层存储、时间过滤、快照隔离 |
| 几何与张量运算 | 距离、内积、等变读出、场计算 | 类型相容收缩、范数、坐标/单位和退化输入处理 |
| 求解与微分 | 隐式层、物理校正、训练 | matvec、dot、AXPY、残差与迭代控制、JVP/VJP 的编译组合、精度回退 |
| 自适应控制与测量 | 专家路由、生长、候选执行 | 比较/选择、形状桶、候选资源、可观测成本与版本迁移 |

不应为“记忆”“反思”“世界模型”各自设置一个无法复用的模型名指令。图查询数据库语义、求解器选择、自动微分规则和图变更事务主要由软件承载；芯片提供可组合的批量计算、地址、搬运、同步和计量。对确实重复且占成本的融合核再做专门优化。

加法/乘法足以组合很多计算，但裸原语齐全不代表有效加速；全图指针追踪、同步与数据布局可能支配延迟。反过来，专用大核若固定掩码、头宽或状态布局，也可能限制泛化。应采取可编程共同原语加经负载验证的融合路径。

## 7. 对当前项目的具体改进与验证顺序 <a id="section-007"></a>

本轮将图记忆澄清归入 C/U03/H02/D04/G05/H08 现有职责，不新增顶层组件。候选规划为：

1. 明确持久历史图、原始记录、压缩状态与参数记忆的不同生命周期；先实现保留与精确回读，再研究压缩率与遗忘。
2. 用同一有类型关系接口承载固定图聚合、稀疏注意力和密集注意力，保留各自语义与不同后端。
3. 为递归、隐式求解和持久状态定义可微边界、更新次序、版本闭包与失败路径；有限预算不能隐式变成截断历史的语义变化。
4. 先测共同原语，再测图/注意力/SSM/求解的组合负载，最后测真实领域任务。根据有效字节、等待与质量决定芯片资源比例。

| 研究实验 | 能够区分的问题 |
|---|---|
| 同最终邻接、不同事件顺序；延迟精确索引查询 | 图快照、持久图、压缩状态分别保留了什么 |
| 改变远处新输入，扫图距离与层数 | 局部传播的可达性、全局关系与层级的收益 |
| 平滑/高频/带噪拟合，独立点与导数测试 | 插值、观测混叠、表示误差与泛化的差别 |
| 参数化场与非局部边值解；跨网格测试 | 离散化、全局耦合、算子泛化与求解误差 |
| 接触切换、稀疏事件与长期流式查询 | 动态图/SSM/注意力混合的净收益 |
| 固定任务质量下的不同状态布局和融合策略 | 数学等价、数值误差与硬件效率的差别 |

上述实验是计划，尚未执行。应比较固定图、持久图、图+SSM、图+注意力、完整选定混合以及适当 Transformer 基线；共享观测信息并计入检索、训练和维护成本。没有理由在实验前宣布某一架构普遍胜出。

**本项目的方向应是可组合、可验证、以误差和成本指导适应的科学计算模型与执行系统。** 这包含对计算对象、知识来源和能力边界的基础思考，也要求每项主张最终有数学条件、可执行合同和实验依据。它不是通用智能或普遍最优芯片的证明。
