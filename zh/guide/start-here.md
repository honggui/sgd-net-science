# 从这里开始

SGD-Net Science 是一组模型架构研究文档，讨论如何组合图结构、时间记忆、几何先验和自适应计算。当前公开的是设计与验证计划，尚无随书发布的模型实现或训练结果。

## 快速了解 <a href="#section-001" id="section-001"></a>

先读论文的摘要、研究问题和限制，再阅读通用性边界，最后看任务卡。首次阅读不必逐个研究全部组件；只有遇到具体问题时再查组件全集。

## 按目标选择路线 <a href="#section-002" id="section-002"></a>

| 你的目标 | 建议路径 |
|---|---|
| 理解整体设想 | 01 论文 → 32 创新边界 → 36 架构导读 |
| 检查数学可行性 | 48 函数空间 → 44 稳定性 → 45 隐式求解 |
| 研究持续学习 | 46 动态生长 → 50 复盘基础 → 17 详细机制 |
| 开始实验实现 | 49 任务卡 → 04 概要设计 → 05 详细设计 → 13 层算子 |
| 应用到科学任务 | 35 跨领域路线 → 对应领域篇 → 49 评价任务 |

## 阅读中需要保留的区别 <a href="#section-003" id="section-003"></a>

组件可用不代表必须全部启用。静态任务可能不需要时间状态，没有物理几何的图也不需要等变坐标。理论条件、训练目标、设计伪代码与实验结果分别理解。

阅读方法公式时检查变量、单位、范数和假设；读到生长或求解时查看失败条件与总成本；涉及生物机制时区分预测关联、模拟与真实干预证据。
